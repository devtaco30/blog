오늘은 **RNN(Recurrent Neural Network, 순환 신경망)**을 학습했습니다. 시퀀스 데이터를 처리하는 RNN의 기본 개념부터 시작하여, RNN의 한계를 극복한 LSTM과 GRU, 그리고 단어를 벡터로 표현하는 Word Embedding 기법들을 실습했습니다.

1️⃣ RNN (Recurrent Neural Network, 순환 신경망)

RNN의 개념

RNN이란?

  • 이전 데이터가 다음 데이터에 영향을 미치는 경우 활용
  • 과거를 기억하면서 데이터를 처리
  • 시퀀스 데이터(텍스트, 시계열) 처리에 특화

CNN vs RNN 비교:

구분CNNRNN
주 용도이미지, 영상텍스트, 시계열
핵심 특징공간적 특징 추출시간/순서 정보 기억
중요한 정보위치, 패턴앞뒤 관계
병렬 처리가능어려움
대표 예시얼굴 인식, 종양 분류문장 분류, 번역

RNN의 구조

입력 형태:

  • input_shape = (시퀀스 길이, 입력 특성 차원)
  • 실제 데이터: (배치 크기, 시퀀스 길이, 입력 특성 차원)
  • 예: (5, 4, 14) = 5개 샘플, 4개 글자, 14차원 원-핫 벡터

SimpleRNN 파라미터 계산:

입력 가중치: 입력 차원(14) × 출력 유닛(16) = 224개
순환 가중치: 출력 유닛(16) × 출력 유닛(16) = 256개
편향: 16개
─────────────────────────────────────────────
총합: 224 + 256 + 16 = 496개

왜 순환 가중치가 필요한가?

  • RNN은 이전 시점의 정보를 기억하기 위해 이전 출력을 다시 입력으로 사용
  • 이전 출력(은닉 상태)을 현재 출력으로 변환하는 가중치가 필요
  • 이것이 RNN이 "순환"하는 이유

SimpleRNN 실습

char 단위 학습 예시:

  • 4개의 글자가 들어가면 다음 글자를 맞추는 모델
  • 데이터: hello, apple, happy, drink, house
  • 단어사전(14개): h,e,l,o,a,p,y,d,r,i,n,k,u,s

모델 구조:

model = Sequential()
model.add(InputLayer(input_shape=(4, 14)))  # 시퀀스 길이 4, 특성 차원 14
model.add(SimpleRNN(16))  # 16개의 뉴런, 활성함수: tanh (기본값)
model.add(Dense(14, activation='softmax'))  # 14개 클래스 분류

return_sequences 옵션:

  • return_sequences=False: 마지막 시점의 출력만 반환 (기본값)
  • return_sequences=True: 각 시점의 출력을 모두 반환 (다음 RNN 층으로 전달할 때 사용)

2️⃣ RNN의 문제점

기울기 소실 문제 (Vanishing Gradient Problem)

원인:

  • 역전파 과정에서 기울기가 시퀀스 길이만큼 곱해지면서 0에 가까워짐
  • 예: 시퀀스가 10단계이고 각 기울기가 0.5라면 → 0.5¹⁰ = 0.00098 (거의 0)

결과:

  • 초반 시점의 가중치가 거의 업데이트되지 않음
  • 오래된 정보를 학습할 수 없음

장기 의존성 문제 (Long-term Dependencies)

원인:

  • RNN은 이전 시점의 출력을 다음 시점의 입력으로 사용
  • 시퀀스가 길어질수록 초반 정보가 반복 변환되며 희석됨

예시:

  • "나는 오늘 금요일이어서 정말 기분이 좋다"
  • '좋다'를 예측할 때 '금요일' 정보가 여러 단계를 거치면서 약해짐

수학적 원인

  • tanh 활성화 함수의 출력 범위가 [-1, 1]로 제한
  • 기울기가 계속 곱해지면 0에 수렴

3️⃣ LSTM (Long Short-Term Memory)

LSTM의 개념

LSTM이란?

  • 장기 의존성을 처리할 수 있는 순환 신경망
  • 기울기 소실 문제를 해결하기 위해 셀 상태와 여러 게이트를 사용
  • 정보를 선택적으로 기억하거나 잊음
  • 긴 시퀀스 데이터 처리에 유리

LSTM 셀 구조

입력과 출력:

  • 입력: x_t (현재 입력), h_{t-1} (이전 은닉 상태), C_{t-1} (이전 셀 상태)
  • 출력: h_t (현재 은닉 상태), C_t (현재 셀 상태)

주요 구성 요소:

  1. Forget Gate (f_t) - 망각 게이트

    • 역할: 이전 셀 상태 C_{t-1}에서 얼마나 정보를 버릴지 결정
    • 계산: f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
    • 출력 범위: 0 ~ 1 (0: 완전히 잊음, 1: 완전히 보존)

  2. Input Gate (i_t) - 입력 게이트

    • 역할: 새로운 정보 중 얼마나 셀 상태에 반영할지 결정
    • 계산: i_t = σ(W_i · [h_{t-1}, x_t] + b_i)

  3. Candidate Cell State (~C_t) - 후보 셀 상태

    • 역할: 현재 입력으로부터 만들어진 새로운 기억 후보
    • 계산: ~C_t = tanh(W_C · [h_{t-1}, x_t] + b_C)

  4. Cell State Update (C_t) - 셀 상태 업데이트

    • 역할: 장기 기억을 업데이트
    • 계산: C_t = f_t * C_{t-1} + i_t * ~C_t
    • 의미: 이전 기억을 선택적으로 유지하고 새로운 기억을 추가

  5. Output Gate (o_t) - 출력 게이트

    • 역할: 셀 상태 중 얼마나 은닉 상태로 출력할지 결정
    • 계산: o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
    • 최종 은닉 상태: h_t = o_t * tanh(C_t)

은닉 상태 vs 셀 상태

은닉 상태 (h_t) - 단기 기억:

  • 각 시점에서 모델이 출력하는 값
  • 다음 시점의 입력으로 사용
  • 다음 층으로 전달되어 예측에 사용
  • 매 시점마다 새로 계산됨

셀 상태 (C_t) - 장기 기억:

  • LSTM 내부에서 장기 기억을 저장하는 경로
  • 여러 시점을 거치며 정보를 유지
  • Forget Gate와 Input Gate로 선택적으로 업데이트
  • 직접 출력되지 않음 (상단의 수평선)

차이점 요약:

구분은닉 상태 (h_t)셀 상태 (C_t)
역할단기 기억, 출력장기 기억, 저장
업데이트매 시점마다 새로 계산선택적으로 업데이트
출력 여부다음 층/시점으로 전달내부에서만 사용
수식h_t = o_t * tanh(C_t)C_t = f_t * C_{t-1} + i_t * ~C_t

LSTM 모델링

from tensorflow.keras.layers import LSTM

LSTM_model = Sequential()
LSTM_model.add(InputLayer(shape=(10, 1)))  # 시퀀스 길이 10, 특성 차원 1
LSTM_model.add(LSTM(64))
LSTM_model.add(Dense(1, activation='sigmoid'))

LSTM_model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

4️⃣ GRU (Gated Recurrent Unit)

GRU의 개념

GRU란?

  • LSTM보다 간단한 구조의 순환 신경망
  • LSTM의 모든 기능을 포함하면서 더 가볍고 빠름
  • 셀 상태 대신 은닉 상태만 사용
  • 두 개의 게이트를 사용 (Reset Gate, Update Gate)

LSTM vs GRU:

구분LSTMGRU
게이트 수3개 (Forget, Input, Output)2개 (Reset, Update)
메모리 구조장기기억(C), 단기기억(h) 따로 저장장기기억과 단기기억을 h에 같이 저장
파라미터 수많음적음
학습 속도느림빠름
성능안정적LSTM과 비슷하거나 약간 낮을 수 있음

GRU 모델링

from tensorflow.keras.layers import GRU

GRU_model = Sequential()
GRU_model.add(InputLayer(shape=(10, 1)))
GRU_model.add(GRU(64))
GRU_model.add(Dense(1, activation='sigmoid'))

GRU_model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

5️⃣ Word Embedding (단어 임베딩)

Word Embedding의 개념

Word Embedding이란?

  • 단어를 고차원 벡터 공간의 점으로 표현하는 기법
  • 의미적으로 유사한 단어들이 벡터 공간에서 가까이 위치
  • 자연어 처리의 핵심 전처리 과정

Word2Vec (사전 학습된 임베딩)

Word2Vec 모델:

  • Google에서 개발한 단어 임베딩 모델
  • 대규모 텍스트 데이터로 사전 학습
  • 단어 간 의미적 관계를 벡터로 표현

사용 예시:

import gensim.downloader as api

# 사전 학습된 모델 로드
model = api.load('word2vec-google-news-300')

# 단어의 임베딩 벡터 가져오기
cat_vector = model['cat']  # 300차원 벡터

# 유사한 단어 찾기
model.most_similar('cat')
# [('cats', 0.81), ('dog', 0.76), ('kitten', 0.75), ...]

# 단어 연산 (king - man + woman = queen)
model.most_similar_cosmul(positive=['father', 'woman'], negative=['man'])
# [('mother', 1.03), ('daughter', 0.99), ...]

코사인 유사도:

  • 벡터 간 유사도를 측정하는 방법
  • -1 ~ 1 사이의 값 (1에 가까울수록 유사)
  • 벡터가 동일한 방향일수록 값이 1에 가까움

Embedding 레이어 (엔드투엔드 학습)

Embedding 레이어란?

  • 텐서플로우의 Embedding 레이어는 모델 내부에서 학습
  • 모델 훈련 과정에서 단어를 임베딩 공간에 매핑
  • 모델 훈련 중에 가중치를 업데이트하며 학습

사용 예시:

from tensorflow.keras.layers import Embedding

model_with_embedding = Sequential()
# Embedding(단어사전 크기, 임베딩 차원)
model_with_embedding.add(Embedding(5000, 50))  # 5000개 단어, 50차원 벡터
model_with_embedding.add(LSTM(64))
model_with_embedding.add(Dense(1, activation='sigmoid'))

입력 형태:

  • Embedding 레이어는 단어 인덱스가 담긴 정수형 2D tensor를 입력으로 받음
  • 형태: (배치 크기, 시퀀스 길이)
  • 예: (149995, 10) → 각 샘플은 10개의 단어 인덱스로 구성

장점:

  • 우리 데이터에 특화된 임베딩 학습 가능
  • 모델과 함께 최적화됨
  • 사전 학습 모델이 없어도 사용 가능

6️⃣ 실습: 네이버 영화 리뷰 감성 분석

데이터 전처리

  1. 특수 문자 제거 및 정규화

    import re
pattern = r'[^가-힣a-zA-Z0-9\s]'
text = re.sub(pattern, '', text).lower().strip()

  2. TextVectorization

    • 텍스트를 정수 시퀀스로 변환
    • 단어사전 구축 및 인덱싱

  3. 패딩/자르기

    • 시퀀스 길이를 통일 (예: 10개 단어)

모델 학습

SimpleRNN 모델:

model = Sequential()
model.add(InputLayer(input_shape=(10, 1)))
model.add(SimpleRNN(64, return_sequences=False))
model.add(Dense(1, activation='sigmoid'))

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

ModelCheckpoint 사용:

  • 학습 중 최고 성능 모델 자동 저장
  • save_best_only=True: 최고 성능일 때만 저장
  • 성능이 떨어진 후에도 최고 성능 모델 사용 가능
