EST AI - Machine Learning (Overview)

📚 오늘의 학습 내용

오늘은 머신러닝의 기본 개념을 학습했습니다. AI, ML, DL의 차이부터 머신러닝의 역사, 종류, 그리고 머신러닝 프로세스까지 전반적인 개요를 다뤘습니다.

📋 AI vs ML vs DL

Artificial Intelligence (인공지능)

  • 사고나 학습 등 인간이 가진 지적 능력을 컴퓨터를 통해 구현하는 기술
  • 가장 넓은 개념

Machine Learning (머신러닝)

  • 컴퓨터가 스스로 학습하여 인공지능의 성능을 향상시키는 기술 방법
  • 인공지능의 한 분야
  • 데이터를 기반으로 학습을 시켜서 예측하게 만드는 기법

Deep Learning (딥러닝)

  • 인간의 뉴런과 비슷한 인공신경망 방식으로 정보를 처리
  • 머신러닝의 한 분야

관계:

AI ⊃ ML ⊃ DL

📋 머신러닝이란?

정의:

  • 데이터를 기반으로 학습을 시켜서 예측하게 만드는 기법
  • 인공지능의 한 분야로 컴퓨터가 학습할 수 있도록 하는 알고리즘 기술을 개발하는 분야
  • 통계학, 데이터 마이닝, 컴퓨터과학이 어우러진 분야

핵심 개념:

  • Data: 데이터
  • Model (알고리즘): 모델
  • 데이터를 이용하여 스스로 특성과 패턴을 찾아 학습하고 예측을 수행하는 것

📋 ML의 역사

1950년 - 앨런 튜링

  • 논문 발표: "기계도 생각할 수 있을까? (Can Machines Think?)"
  • Turing Test (튜링 테스트): 기계가 인간과 비슷하게 대화가 가능하다면 기계에 지능이 있다고 인정하는 방식

1956년 - Dartmouth AI Project

  • 인공지능 용어 등장
  • 규칙 기반 시스템: 인간 전문가들의 지식을 하나하나 입력해 만든 시스템

현재

  • AI 부활
  • Deep Learning 발전
  • Machine Learning 활성화

📋 인공지능의 종류

약한 인공지능 (Artificial Narrow Intelligence)

  • 특정 분야를 위해 제작된 인공지능
  • 예: 체스, 퀴즈, 자율주행, 상품 추천, 번역 시스템, 알파고 (특정 임무 수행)

강한 인공지능 (Artificial General Intelligence)

  • 모든 방면에서 인간급의 인공지능
  • 사고, 계획, 문제해결, 추상화, 복잡한 개념 학습

초인공지능 (Artificial Super Intelligence)

  • 과학기술, 사회적 능력 등 모든 영역에서 인간보다 뛰어남
  • "충분히 발달한 과학은 마법과 구분할 수 없다" - 아서 C. 클라크

📋 Rule-based Expert System (규칙 기반 전문가 시스템)

정의:

  • "if"와 "else"로 하드 코딩된 명령을 사용하는 시스템

문제점:

  • 모든 경우의 수를 미리 정의해야 함
  • 새로운 상황에 대응하기 어려움
  • 유지보수가 어려움

머신러닝 등장 배경:

  • 규칙 기반 시스템의 한계를 극복하기 위해 데이터 기반 학습 방식 등장

📋 머신러닝의 종류

1. 지도학습 (Supervised Learning)

정의:

  • 정답(Label)이 있는 데이터로 학습
  • 입력과 출력의 관계를 학습
  • 답을 주고 학습시키는 방식

종류:

  • 분류 (Classification): 범주형 데이터 예측 (예: 스팸/정상 메일, 고양이/강아지, Normal/Obesity)
    • 이산적인 값, 범주형 값 예측
  • 회귀 (Regression): 숫자(연속적인 값) 예측 (예: 집 가격, 온도, 성적)
    • 연속적인 값, 숫자 예측

예시:

  • 다음 학기 성적을 예측하려면?
    • 직전 학기 성적, 알바 진행 여부, 연애, 잠자는 시간, 출석률, 학교와 집 사이 거리
    • → 회귀 문제 (연속적인 값 예측)

2. 비지도학습 (Unsupervised Learning)

정의:

  • 정답(Label)이 없는 데이터로 학습
  • 데이터의 패턴이나 구조를 찾아냄
  • 답을 주지 않고 학습시키는 방식

지도학습 vs 비지도학습:

  • 지도학습: 답을 주고 학습 (정답이 있는 데이터)
  • 비지도학습: 답을 주지 않고 학습 (정답이 없는 데이터)

종류:

  • 군집화 (Clustering): 비슷한 데이터끼리 그룹화
  • 차원 축소 (Dimensionality Reduction): 데이터의 차원을 줄임

3. 강화학습 (Reinforcement Learning)

정의:

  • 에이전트가 환경과 상호작용하며 보상을 통해 학습
  • 시행착오를 통해 최적의 행동을 학습

예시:

  • 알파고, 게임 AI, 로봇 제어

📋 머신러닝 과정 (7단계)

1. Problem Identification (문제 정의)

  • 비즈니스 목적 정의: 모델을 어떻게 사용해 이익을 얻을까?
  • 현재 솔루션의 구성 파악
  • 학습 방법 결정: 지도 vs 비지도 vs 강화
  • 문제 유형 결정: 분류 vs 회귀

2. Data Collect (데이터 수집)

  • File (CSV, XML, JSON)
  • Database
  • Web Crawler (뉴스, SNS, 블로그)
  • IoT 센서를 통한 수집
  • Survey

3. Data Preprocessing (데이터 전처리)

  • 결측치, 이상치 처리
  • Feature Engineering (특성공학):
    • Scaling (단위 변환)
    • Encoding (범주형 → 수치형)
    • Binning (수치형 → 범주형)
    • Transform (새로운 속성 추출)

4. EDA (Exploratory Data Analysis) (탐색적 데이터분석)

  • 기술통계, 변수간 상관관계
  • 시각화: pandas, matplotlib, seaborn
  • Feature Selection (사용할 특성 선택)

5. Model 선택, Hyper Parameter 조정

  • 목적에 맞는 적절한 모델 선택
  • KNN, SVM, Linear Regression, Ridge, Lasso, Decision Tree, Random Forest, CNN, RNN 등
  • Hyper Parameter: 모델의 성능을 개선하기 위해 사람이 직접 넣는 parameter

6. Model Training (학습)

# train 데이터와 test 데이터를 7:3 정도로 나눔
model.fit(X_train, y_train)  # train 데이터의 문제와 정답으로 모델 학습
model.predict(X_test)  # test 데이터의 문제를 넣고 정답을 예측

7. Evaluation (평가)

분류 (Classification) 평가 지표:

⚠️ 중요: 평가에서는 정확도(accuracy)만 보는 것이 아니라 재현율(recall)과 정밀도(precision)도 함께 봐야 합니다.

  • accuracy (정확도): 전체 중 맞춘 비율

    • 전체적인 성능을 보는 지표이지만, 클래스 불균형이 있을 때는 신뢰하기 어려울 수 있음

  • recall (재현율): 실제 진짜 중 모델이 진짜라고 잘 찾아낸 비율

    • Recall = TP / (TP + FN)
    • FN을 줄이는 것이 중요한 경우 (예: 암 진단, 스팸 메일)에 중요
    • FN이 발생하면 안 되는 경우: 재현율이 중요한 지표

  • precision (정밀도): 진짜라고 판별한 것 중 실제로 진짜인 비율

    • Precision = TP / (TP + FP)
    • FP를 줄이는 것이 중요한 경우 (예: 추천 시스템)에 중요

  • f1 score: 정밀도와 재현율의 조화평균

    • 정밀도와 재현율의 균형을 보는 지표

  • ROC 곡선의 AUC: ROC 곡선 아래 면적

회귀 (Regression) 평가 지표:

  • MSE (Mean Squared Error): 평균 제곱 오차
  • RMSE (Root Mean Squared Error): 평균 제곱 오차의 제곱근
  • R² (R Square): 결정계수

혼동 행렬 (Confusion Matrix) 용어:

  • TP (True Positive): 진짜를 진짜라고 맞춤
  • FN (False Negative): 진짜를 가짜라고 놓침 (예: 암인데 암 아니라고)
    • ⚠️ FN은 발생하면 안 되는 경우가 많음: 중요한 문제를 놓치는 것은 치명적일 수 있음
  • FP (False Positive): 가짜를 진짜라고 착각함 (예: 무죄인데 유죄라고)
  • TN (True Negative): 가짜를 가짜라고 맞춤

📋 머신러닝 관련 윤리적 고려사항

불쾌한 골짜기 (Uncanny Valley)

  • 인간이 로봇에 대해 호감도가 증가하다가 어느 정도에 도달하면 갑자기 강한 거부감을 느끼는 현상

지능, 윤리&도덕 관점

  • 단순히 똑똑한 것을 넘어서서 옳고, 그름을 판별할 수 있는 지능을 가지는 것이 인공지능 과제
  • 예: 자율주행차의 윤리적 딜레마

💡 핵심 정리

배운 것

  • AI, ML, DL의 관계: AI ⊃ ML ⊃ DL
  • 머신러닝의 정의: 데이터를 기반으로 학습하여 예측하게 만드는 기법
  • 머신러닝의 종류: 지도학습, 비지도학습, 강화학습
    • 지도학습: 답을 주고 학습 (우리가 주로 다룰 내용)
    • 비지도학습: 답을 주지 않고 학습
  • 지도학습의 종류:
    • 분류: 범주형 데이터 예측
    • 회귀: 숫자(연속적인 값) 예측
  • 머신러닝 과정: 문제 정의 → 데이터 수집 → 전처리 → EDA → 모델 선택 → 학습 → 평가
  • 평가 지표:
    • 분류: accuracy, recall, precision, f1 score (정확도만이 아니라 재현율, 정밀도도 함께 봐야 함)
    • 회귀: MSE, RMSE, R²
  • FN의 중요성: FN은 발생하면 안 되는 경우가 많음 (중요한 문제를 놓치는 것은 치명적)
  • scikit-learn: 파이썬 머신러닝 라이브러리

인사이트

  • 규칙 기반 시스템의 한계: 모든 경우의 수를 미리 정의해야 하는 한계로 인해 머신러닝이 등장
  • 데이터의 중요성: 머신러닝은 데이터를 기반으로 하므로 데이터의 품질이 모델 성능에 직접적인 영향
  • 문제 정의의 중요성: 비즈니스 목적을 명확히 하고, 분류/회귀 문제를 올바르게 구분하는 것이 중요
  • 평가 지표 선택: 문제의 특성에 따라 적절한 평가 지표를 선택해야 함

주의사항

  • ⚠️ 분류 vs 회귀 구분:
    • 분류: 범주형 데이터 예측
    • 회귀: 숫자(연속적인 값) 예측
  • ⚠️ FN 발생 주의: FN은 발생하면 안 되는 경우가 많음 (예: 암 진단에서 암을 놓치는 것)
  • ⚠️ 평가 지표 선택: 정확도만 보는 것이 아니라 재현율과 정밀도도 함께 봐야 함
  • ⚠️ Train/Test 분리: 학습 데이터와 평가 데이터를 분리해야 과적합을 방지할 수 있음
  • ⚠️ Hyper Parameter: 모델의 성능을 개선하기 위해 사람이 직접 조정하는 parameter
  • ✅ 지도학습 중심: 이 강의에서는 지도학습을 주로 다룸
  • ✅ scikit-learn 활용: 머신러닝 구현을 쉽게 할 수 있는 라이브러리 활용 권장
