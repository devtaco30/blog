📚 오늘의 학습 내용

📊 통계란 무엇인가?

핵심 개념:

  • 데이터를 요약하고, 차이를 확인하고, 설명하는 학문
  • 복잡한 데이터를 간단하게 요약해서 이해하기 쉽게 만드는 것

통계의 3단계 프로세스:

📥 수집 (Design)
    │
    ↓
📊 요약 (Description)
    │
    ↓
🔮 추론 (Inference)

통계의 역할:

  • 데이터 요약 및 시각화
  • 특성 파악
  • 의사 결정 지원
  • 결론 도출 및 검증

📦 데이터 이해하기

데이터의 분류:

                    데이터
                     │
        ┌────────────┴────────────┐
        │                         │
   양적 데이터              질적 데이터
   (Quantitative)          (Qualitative)
        │                         │
   ┌────┴────┐              ┌─────┴─────┐
   │         │              │           │
이산형      연속형        명목 척도    서열 척도
(Discrete) (Continuous)  (단순 분류)  (순서만)

1️⃣ 양적 데이터 (Quantitative Data)

  • 숫자로 셀 수 있는 데이터
  • 이산형: 셀 수 있는 정수 (자녀 수, 문제 수)
  • 연속형: 무한히 나눌 수 있는 실수 (키, 몸무게, 시간)

2️⃣ 질적 데이터 (Qualitative Data)

  • 범주형 데이터 (직업, 성별, 거주지)
  • 계산 불가, 분류만 가능

📏 척도 (Scale):

척도특징예시
명목 척도단순 분류만 가능성별, 직업
서열 척도순서만 가능만족도 등급
등간 척도간격이 의미 있음온도, IQ
비율 척도절대 0 + 간격 의미키, 몸무게, 점수

💡 핵심:

  • 명목/서열 척도 → 비모수 분석
  • 등간/비율 척도 → 모수 분석 (조건 만족 시)

🔍 데이터 수집 방법

전수조사 vs 표본조사:

항목전수조사표본조사
조사 대상모집단 전체모집단의 일부
정확도가장 정확함오차 가능
시간/비용오래 걸림, 비용 큼빠름, 경제적
현실성모집단이 크면 어려움현실적으로 가능

💾 빅데이터:

  • 거의 전수조사에 가까운 대용량 데이터
  • 기술 발달로 가능해짐
  • 하지만 완벽하지 않음 (비용, 데이터 변질, 출처 불분명 등)

🔑 핵심 개념: 모집단 vs 표본, 모수 vs 통계량

🌐 모집단 (Population):

  • 알고 싶은 "전체" 집단
  • 예: 전체 학년 300명

🎯 표본 (Sample):

  • 모집단에서 뽑은 "일부"
  • 예: 우리 반 30명

🔢 모수 (Parameter):

  • 모집단 전체의 특성값
  • 고정된 상수 (변하지 않음)
  • 기호: μ (모평균), σ² (모분산)
  • 일반적으로 알려져 있지 않아서 추정해야 함

📈 통계량 (Statistic):

  • 표본의 특성값
  • 확률변수 (표본에 따라 달라짐)
  • 기호: X̄ (표본평균), s² (표본분산)
  • 표본에서 계산 가능

🔑 핵심 차이:

모집단 (Population)          표본 (Sample)
      │                            │
      ↓                            ↓
   모수 (Parameter)            통계량 (Statistic)
   μ, σ²                        X̄, s²
   고정된 상수                  확률변수
      │                            │
      └──────────┬─────────────────┘
                 │
          추정 ↔ 추론

핵심:

  • 모평균 μ는 상수, 표본평균 X̄는 확률변수
  • 모수 = "진짜 값", 통계량 = "추정값"

📊 기술통계 (Descriptive Statistics)

목적: 현재 가지고 있는 데이터를 요약하고 설명하는 것

1️⃣ 대표값 (Measures of Central Tendency):

평균 (Mean):

  • 모든 값을 더해서 개수로 나눈 값
  • 극단값(이상치)에 민감함

중앙값 (Median):

  • 크기 순으로 나열했을 때 가운데 값
  • 극단값에 안전함

최빈값 (Mode):

  • 가장 자주 나타나는 값

💡 선택 가이드: 이상치가 많으면 평균 대신 중앙값 사용!

2️⃣ 산포도 (Measures of Dispersion):

분산 (Variance):

  • 데이터가 평균에서 얼마나 퍼져있는지
  • 공식: Σ(각 값 - 평균)² ÷ 개수
  • 모분산: n으로 나눔
  • 표본분산: n-1로 나눔

🤔 왜 표본분산은 n-1로 나눌까?

  • 표본 평균을 사용하면 분산이 작게 보임
  • n-1로 나누면 여러 번 반복했을 때 평균이 모분산에 수렴함
  • 수학적으로 증명됨 (불편추정량, 자유도 n-1)

표준편차 (Standard Deviation):

  • 분산의 제곱근
  • 분산보다 해석하기 쉬움 (원래 단위와 같음)
  • 예: 분산이 100이면 표준편차는 10

3️⃣ 다변량의 대표값:

공분산 (Covariance):

  • 두 변수가 함께 어떻게 변하는지
  • 공식: Cov(X, Y) = Σ(Xi - X̄) × (Yi - Ȳ) / (n - 1)
  • 양수: 같은 방향으로 움직임
  • 음수: 반대 방향으로 움직임

4️⃣ 거리의 대표값:

유클리드 거리:

  • 두 점 사이의 물리적 거리
  • 분산이 달라도 거리는 같음

통계적 거리:

  • 표준편차를 고려한 거리
  • 같은 물리적 거리라도 분산이 다르면 통계적 거리는 다름
  • 공식: SD² = ((Xᵢ - Xⱼ) / s)²

5️⃣ 분위수 (Quantiles):

사분위수 시각화:

┌───────────────────────────────────────┐
│  최소값  │  Q1  │  Q2  │  Q3  │  최대값  │
│        │  25% │  50% │  75% │         │
│        │      │(중앙값)│      │         │
└───────────────────────────────────────┘
              └─── IQR ───┘
    (중간 50% 데이터의 퍼짐 정도)

사분위수:

  • Q1 (1사분위수): 하위 25% 위치의 값
  • Q2 (2사분위수): 중앙값과 같음 (하위 50%)
  • Q3 (3사분위수): 하위 75% 위치의 값

IQR (사분위수 범위):

  • Q3 - Q1 (중간 50% 데이터의 퍼짐 정도)
  • 이상치 탐지에 활용: Q1 - 1.5×IQR 보다 작거나, Q3 + 1.5×IQR 보다 큰 값

6️⃣ 형태 (Shape):

왜도 (Skewness):

  • 데이터가 한쪽으로 치우쳐 있는 정도

설명:

  • 양의 왜도: 오른쪽으로 치우침 (오른쪽 꼬리가 길고, 평균 > 중앙값)
  • 음의 왜도: 왼쪽으로 치우침 (왼쪽 꼬리가 길고, 평균 < 중앙값)
  • 정규분포: 대칭적 (평균 = 중앙값)

첨도 (Kurtosis):

  • 데이터가 얼마나 뾰족한지(또는 평평한지)
  • 뾰족하면 첨도가 크고, 평평하면 첨도가 작음

7️⃣ 상관 (Correlation):

상관계수:

  • 공분산을 표준화한 값 (-1 ~ 1)
  • 1에 가까우면 강한 양의 상관관계
  • -1에 가까우면 강한 음의 상관관계
  • 0에 가까우면 상관관계 없음

🔮 추론통계 (Inferential Statistics)

목적: 표본으로 모집단을 추측하는 것

추론 과정 (4단계):

1️⃣ 모집단 정의
    │
    ↓
2️⃣ 표본 추출
    │
    ↓
3️⃣ 표본 분석
    │
    ↓
4️⃣ 모집단 추론

통계량의 역할:

  • 모수 추정: 표본 통계량으로 모집단 모수 추정
  • 가설 검정: 가설이 맞는지 확인

기술통계 vs 추론통계:

항목기술통계추론통계
대상전체 데이터표본데이터
목적현재 데이터 설명모집단 추정, 검정
확률개념없음포함

🔬 분석 방법 선택

모수 분석 vs 비모수 분석:

항목모수 분석비모수 분석
분포 가정정규분포 가정 필요분포 가정 불필요
척도등간/비율 척도명목/서열 척도 가능
표본 크기충분히 커야 함작아도 가능
검정력조건 만족 시 강력함상대적으로 낮을 수 있음

모수 분석:

  • 데이터가 정규분포이고, 표본이 충분히 크고, 등간/비율 척도일 때
  • 예: t-검정, ANOVA

비모수 분석:

  • 정규분포가 아니거나, 표본이 작거나, 명목/서열 척도일 때
  • 예: 윌콕슨 순위합 검정, 크루스칼-왈리스 검정, 카이제곱 검정

💡 핵심 정리

📖 주요 학습 내용

핵심 개념:

  • 모집단 vs 표본: "전체 vs 샘플"
  • 모수 vs 통계량: "고정된 상수 vs 변수"
  • 기술통계 vs 추론통계: "지금 데이터 설명 vs 전체 추측"

통계량:

  • 평균은 극단값에 민감, 중앙값은 안전
  • 표본분산은 n-1로 나눔 (자유도)
  • 표준편차는 분산의 제곱근 (해석하기 쉬움)
  • IQR = Q3 - Q1 (이상치 탐지에 활용)
  • 왜도: 좌우 치우침, 첨도: 뾰족함 정도
  • 상관계수: 두 변수의 관계 (-1 ~ 1)

분석 방법:

  • 모수 분석: 조건 까다로움, 하지만 강력함
  • 비모수 분석: 조건 덜 까다로움, 유연함

⚠️ 주의사항

  • 모집단의 범위를 명확히 정의해야 함
  • 표본분산은 n-1로 나눠야 모분산을 정확하게 추정 가능
  • 이상치가 많으면 평균 대신 중앙값 사용 권장
  • 데이터 종류와 척도에 따라 분석 방법이 달라짐
