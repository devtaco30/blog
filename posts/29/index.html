📋 1. 문제 정의

목표:

  • 500명의 키와 몸무게, 비만도 라벨을 이용해서 비만 정도를 판단하는 모델 만들기
  • 분류 문제: 라벨이 범주형 데이터 (Normal, Overweight, Obesity, Extreme Obesity, Weak, Extremely Weak)

📋 2. 데이터 수집

⚠️ 실제 프로젝트에서는: File, Survey, Database, IoT Sensor, Web Crawler 등을 통해 데이터를 직접 수집해야 합니다.

이번 실습에서는: 학습용 데이터를 제공받아 사용하므로 데이터 로딩 단계입니다.

데이터 로딩:

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.neighbors import KNeighborsClassifier
from sklearn import metrics

# 데이터 로드
tbl = pd.read_csv('../data/bmi_500.csv', index_col='Label')
data = pd.read_csv('../data/bmi_500.csv')  # 학습용 별도 로딩

데이터 구조:

  • 총 500개의 행
  • 컬럼: Gender, Height, Weight, Label
  • 결측치 없음

📋 3. 데이터 전처리

  • 이번 실습에서는 전처리가 필요 없는 학습용 데이터 사용
  • 실제로는 결측치, 이상치 처리, Encoding 등이 필요함

참고:

  • Gender는 명목형 데이터이므로 Encoding이 필요하지만, 이번 실습에서는 제외
  • '정답 데이터'(Label)는 보통 Encoding 하지 않음 (지도학습의 경우)

📋 4. 탐색적 데이터 분석 (EDA)

데이터 정보 확인

tbl.info()  # 500개 행, 결측치 없음
tbl.describe()  # 기술통계량
tbl.index.value_counts()  # 각 라벨별 개수 확인

라벨 분포:

  • Extreme Obesity: 198명
  • Obesity: 130명
  • Normal: 69명
  • Overweight: 68명
  • Weak: 22명

plt.scatter(tbl['Weight'], tbl['Height'])

  • 각 등급별로 클러스터가 형성되어 있음을 확인

📋 5. 모델링 (모델 선택, 학습, 평가)

5-1. 문제 데이터와 정답 데이터 분리 (X, y)

# 문제(X), 정답(y) 로 분리
y = data.loc[:, 'Label']  # 정답 (Series)
X = data.loc[:, ['Height', 'Weight']]  # 문제 (DataFrame)

print(X.shape)  # (500, 2)
print(y.shape)  # (500,)

특성 선택:

  • Height와 Weight는 '문제' 데이터
  • Label은 '정답' 데이터
  • Gender는 사용하지 않음 (명목형 데이터이므로 Encoding 필요)

5-2. Train/Test Set 분리 (7:3 비율)

# 원본 data의 열 인덱스 사용
# Gender(0), Height(1), Weight(2), Label(3)

# X의 Train, Test set
X_train = data.iloc[:350, 1:3]  # 행 0~349, 열 1~2 (Height, Weight)
X_test = data.iloc[350:, 1:3]   # 행 350~, 열 1~2

# y의 Train, Test set
y_train = data.iloc[:350, 3]    # 행 0~349, 열 3 (Label)
y_test = data.iloc[350:, 3]     # 행 350~, 열 3

5-3. 모델 생성

# KNN 모델 생성
# n_neighbors 값은 전체 학습 데이터 수의 제곱근 값을 기준으로 설정
knn_model = KNeighborsClassifier(n_neighbors=8)

KNN (K-Nearest Neighbors):

  • 가장 가까운 K개의 이웃을 찾아 다수결로 분류
  • n_neighbors: 고려할 이웃의 개수

5-4. 모델 학습

knn_model.fit(X_train, y_train)
  • fit(): 모델이 학습 데이터를 기반으로 패턴을 학습

5-5. 예측 및 평가

예측:

pred = knn_model.predict(X_test)  # 문제만 넘겨줌 (답을 주면 안됨!)

정확도 평가:

# 방법 1: accuracy_score 사용
metrics.accuracy_score(pred, y_test)
# pred: 모델이 예측한 값
# y_test: 실제 정답

# 방법 2: score 함수 사용 (간단)
knn_model.score(X_test, y_test)

분류 리포트:

from sklearn.metrics import classification_report

print(classification_report(y_test, pred))
# 주의: parameter 순서가 중요!
# 첫 번째: 실제 정답 (y_test)
# 두 번째: 모델이 예측한 값 (pred)

평가 결과 예시:

📋 평가 지표 이해

Precision (정밀도)

정의:

  • 모델이 특정 클래스라고 예측한 것 중에서 실제로도 그 클래스인 비율
  • 모델 기준: "내가 예측한 것 중에 얼마나 맞았나?"

공식:

Precision = TP / (TP + FP)

예시:

  • Weak의 precision 1.00: 모델이 저체중이라고 예측한 것 중에, 실제로도 저체중인 경우 (모두 맞춤)
  • 정밀도가 중요한 경우: 가짜를 진짜로 착각하는 것이 안 되는 경우 (예: 추천 시스템)

Recall (재현율)

정의:

  • 실제 특정 클래스 데이터 중에서 모델이 그 클래스라고 예측한 비율
  • 데이터 기준: "실제 데이터 중에 얼마나 찾았나?"

공식:

Recall = TP / (TP + FN)

예시:

  • Weak의 recall 0.64: 실제로는 저체중인 데이터 중, 모델이 저체중이라고 예측한 비율
  • 재현율이 중요한 경우: 진짜를 가짜로 착각하는 것이 안 되는 경우 (예: 암 진단, 스팸 메일)

BMI 케이스 적용:

  • 실제 저체중/비만이지만 정상이라고 잘못 판명나는 경우 → 재현율이 중요
  • 정상이지만 저체중/비만으로 잘못 판명나는 경우 → 덜 위험
  • 이 케이스에서는 재현율이 더 중요함

주의:

  • 어느 것이 더 중요한지는 케이스마다 다를 수 있음
  • 문제의 특성에 따라 precision과 recall 중 우선순위를 결정해야 함

💡 핵심 정리

배운 것

  • 머신러닝 7과정: 문제 정의 → 데이터 수집 → 전처리 → EDA → 모델 선택 → 학습 → 평가
  • 데이터 분리: X(문제), y(정답) 분리, Train/Test 분리 (7:3)
  • KNN 모델: K-Nearest Neighbors 분류 알고리즘
  • 평가 지표:
    • accuracy: 전체 정확도
    • precision: 정밀도 (모델 기준)
    • recall: 재현율 (데이터 기준)
    • f1-score: 정밀도와 재현율의 조화평균

인사이트

  • 평가 지표 선택의 중요성: 문제의 특성에 따라 precision과 recall 중 어느 것이 더 중요한지 결정해야 함
  • 데이터 시각화의 중요성: EDA 단계에서 시각화를 통해 데이터 분포를 직관적으로 파악할 수 있음

주의사항

  • ⚠️ Train/Test 분리: 학습 데이터와 평가 데이터를 분리해야 과적합을 방지할 수 있음
  • ⚠️ 평가 지표 순서: classification_report(y_test, pred) - 실제 정답이 먼저, 예측값이 나중
  • ✅ KNN의 n_neighbors: 전체 학습 데이터 수의 제곱근 값을 기준으로 설정
