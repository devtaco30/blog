EST AI - KNN Algorithm

모델이 훈련 데이터에만 맞춰지는 과대적합과 그 반대인 과소적합, 일반화의 의미부터 짚습니다. | KNN 알고리즘의 원리와 k 값을 다루고, Iris 데이터로 붓꽃 품종을 분류해 k에 따른 모델 복잡도 곡선을 그립니다.

📚 오늘의 학습 내용

오늘은 모델의 일반화 능력과 KNN 알고리즘에 대해 학습했습니다. 모델이 훈련 데이터에만 과도하게 맞춰지는 과대적합과 반대로 훈련 데이터에도 제대로 맞지 않는 과소적합의 개념을 이해하고, Iris 데이터를 활용하여 KNN 모델로 붓꽃 품종을 분류하는 실습을 진행했습니다.

1️⃣ 일반화, 과대적합, 과소적합

모델 학습의 목표

모델을 선언만하면 아무것도 할 수 없다. 이 모델에게 학습을 시켜줘야 한다.

과대적합 (過大適合, Overfitting)

모델이 훈련 데이터에 과도하게 맞춰져 일반화가 떨어지는 현상.

과대적합은 두 가지 경우에 발생할 수 있다:

  1. 데이터의 다양성이 부족한 경우

    • 예를 들면, 훈련 세트가 '축구공'뿐이라서, 모델이 축구공에 대해서만 자세히 학습되어 다른 공(야구공, 농구공 등)을 구별하지 못하게 된다.

  2. 모델이 너무 복잡한 경우

    • 다양한 공(축구공, 야구공, 농구공 등)을 보여줬는데, 모델이 특정 축구공의 세부 특징(흠집, 특정 패턴, 특정 브랜드의 로고 등)까지 학습해서 새로운 공을 구별하지 못하게 된다.

특징:

  • 학습 데이터에 너무 과도하게(세세하게) 학습이 되었다.

과소적합 (過少適合, Underfitting)

반대로 '공이라는 것은 둥글게 생겼다' 정도로만 학습한다면, train 데이터가 부족하거나 모델이 너무 단순해서 충분히 반영되지 못해 예측성능이 저하되는 현상이 발생한다.

특징:

  • 모델이 훈련 데이터에도 제대로 맞지 않는 상태

일반화 (Generalization)

그래서 우리가 해야하는 것은 '일반화 (Generalization)' 이다. '적절한' 데이터로 학습시킨 모델로 예측해야 한다.

일반화를 위한 해결책:

  • 데이터의 양이 많으면 일반화에 도움이 됨
  • 훈련데이터의 다양성이 보장되어야 함

2️⃣ K-Nearest Neighbors (KNN) 알고리즘

개념

  • **유유상종(類類相從)**의 개념과 유사
  • 새로운 데이터 포인트와 가장 가까운 훈련 데이터셋의 k개 데이터 포인트를 찾아 예측

작동 원리

  1. 새로운 데이터 포인트와 모든 훈련 데이터 간의 거리를 계산
  2. 가장 가까운 k개의 이웃을 선택
  3. 분류: k개 이웃 중 다수결로 클래스 결정
  4. 회귀: k개 이웃의 평균값으로 예측

k 값 (하이퍼파라미터)

  • k 값에 따라 가까운 이웃의 수가 결정됨
  • k 값은 홀수가 좋다: 반대되는 특성이 '반반으로 나눠질' 수 있기 때문 (동점 방지)
  • k 값이 너무 작으면 → 과대적합 (너무 세밀하게 학습)
  • k 값이 너무 크면 → 과소적합 (너무 일반적으로 학습)

특징

  • 분류(Classification)와 회귀(Regression)에 모두 사용 가능
  • 지도학습(Supervised Learning) 알고리즘

장단점

장점:

  • 이해하기 매우 쉽다
  • 큰 조정 없이도 '나쁘지 않은' 성능을 발휘하는 기초 모델

단점:

  • 새로운 test data set이 들어오면 train data set와의 거리를 계산해야 하므로, train data set가 크면 (특성, 샘플의 수) 예측이 느려짐
    • 인간은 눈으로 보고 찾을 수 있지만, 모델은 예측할 데이터와 주변의 데이터 거리를 매번 계산해야 한다
  • 거리를 측정하기 때문에 데이터의 scale 조정이 필요할 수 있음
  • 직접적인 예측에 사용되기보다는 데이터를 파악하기 위한 용도로 가볍게 사용

3️⃣ Iris 데이터 분류 실습

1. 문제 정의 (Problem Definition)

목표:

  • 특성 4개를 통해 붓꽃의 품종을 예측하는 모델 구축

사용 모델: K-Nearest Neighbors (KNN)

  • 개념: 유유상종(類類相從)의 개념과 유사
  • 작동 원리: 새로운 데이터가 들어왔을 때, 거리 계산을 통해 가장 가까운 k개의 이웃 데이터를 찾아 예측
  • 하이퍼파라미터 튜닝: neighbor (k) 값 조정

데이터셋: 붓꽃 (Iris)

  • 특성 (Features) - 4개 (문제 데이터, X)

    • 꽃잎의 길이 (Petal Length)
    • 꽃잎의 너비 (Petal Width)
    • 꽃받침의 길이 (Sepal Length)
    • 꽃받침의 너비 (Sepal Width)

  • 정답 (Target) - 3개 클래스 (정답 데이터, y)

    • setosa (세토사)
    • versicolor (버시컬러)
    • virginica (버지니카)

Train/Test 분리:

from sklearn.model_selection import train_test_split

X = iris_df
y = iris_data['target']

# train_test_split() : 자동으로 훈련용 / 테스트용 데이터를 나누어주는 도구 (랜덤 샘플링)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=38)

train_test_split() 기능 2가지:

  1. train, test를 분리해준다.
  2. random sampling을 해준다.

random_state의 중요성:

  • random sampling이 반복되면, 학습 데이터가 매번 변경되므로, hyper parameter 조정의 의미가 없어진다.
  • random seed (random_state)를 고정하여 수행 시 동일한 결과를 얻기 위해 사용
  • random seed의 숫자 자체는 의미가 없고, 알고리즘 내부적으로 규칙을 가지는 숫자이다.

5. 모델링 (모델 선택, 학습, 평가)

from sklearn.neighbors import KNeighborsClassifier

iris_knn_model = KNeighborsClassifier(n_neighbors=8)

2. 모델 학습:

iris_knn_model.fit(X_train, y_train)

3. 모델 평가:

# 예측
predict = iris_knn_model.predict(X_test)

# 정확도 확인

6. 하이퍼파라미터 튜닝 (반복문 활용)

목적

KNN 모델의 하이퍼파라미터인 n_neighbors (k 값)을 여러 값으로 테스트하여, train과 test 데이터 모두에서 좋은 성능을 보이는 최적의 k 값을 찾는 것.

구현 방법

train_list = [] # train 데이터의 '정확도' 가 들어갈 빈 리스트 정의
test_list = [] # test 데이터의 '정확도' 가 들어갈 빈 리스트 정의

# 반복문 수행
# n_neighbors 의 결과값을  1~49 반복
for i in range(1, 50, 1):
    # 모델 정의
    knn_model = KNeighborsClassifier(n_neighbors=i) # 하이퍼파라미터값이 1부터 49까지 들어가도록
    # 모델 학습
    knn_model.fit(X_train, y_train)
    
    # 훈련데이터의 정확도 담기
    train_score = knn_model.score(X_train, y_train)
    train_list.append(train_score)

    # 평가데이터의 정확도 담기
    test_score = knn_model.score(X_test, y_test)
    test_list.append(test_score)

코드 설명

  1. 빈 리스트 생성: train과 test 데이터의 정확도를 저장할 리스트를 미리 생성
  2. 반복문: k 값을 1부터 49까지 1씩 증가시키며 반복
  3. 모델 생성 및 학습: 각 k 값마다 새로운 KNN 모델을 생성하고 학습
  4. 정확도 계산: train과 test 데이터에 대한 정확도를 각각 계산하여 리스트에 저장

7. 모델 복잡도 곡선 시각화

시각화 코드

# 시각화 해서 해석해보자
# 각각의 hyper parameter 에 따른 정확도, 테스트 데이터의 정확도를 그려서
# 일반화가 되고 있는 지점(hyper parameter 의 최적값)을 확인

plt.figure(figsize=(13, 5))
plt.plot(range(1, 50, 1), train_list, label='Train Data Accuracy')
plt.plot(range(1, 50, 1), test_list, label='Test Data Accuracy')

plt.grid()
plt.legend()

plt.xticks(range(1, 50))

plt.show()

모델 복잡도 곡선이란?

  • x축: 하이퍼파라미터 k 값 (1~49)
  • y축: 정확도 (Accuracy)
  • 두 개의 선:
    • Train Data Accuracy (훈련 데이터 정확도)
    • Test Data Accuracy (테스트 데이터 정확도)

곡선 해석 방법

  1. Train 정확도가 Test 정확도보다 높은 경우: 모델이 훈련 데이터에 과도하게 맞춰진 상태 (과대적합 가능성)
  2. Test 정확도가 Train 정확도보다 높은 경우: 운이 좋게 잘 맞춘 것 (신뢰성 낮음)
  3. 두 정확도가 모두 높고 차이가 작은 경우: 일반화가 잘 된 상태 (최적의 하이퍼파라미터)

8. 모델 복잡도 곡선 분석 결과

하이퍼파라미터 k 값에 따른 정확도 비교

모델 복잡도 곡선을 확인해본 결과, hyper parameter가 7, 8, 10일 때 test data의 정확도가 가장 높다.

k = 8 또는 k = 10

  • test의 정확도가 train보다 높다
  • 이는 때려 맞춘 것 (운이 좋게 잘 찍었다)
  • 신뢰성이 떨어지는 정확도
  • 일반화가 제대로 되지 않은 상태

k = 7

  • test와 train 정확도가 둘 다 높다
  • 차이도 가장 작다 (일반화가 잘 된 상태)
  • 가장 적합한 hyper parameter는 7이다

주의사항

  • random_state가 바뀌면, data set 자체가 바뀌기 때문에 다른 해석이 나올 수 있다
  • 따라서 random_state를 고정하여 일관된 결과를 얻는 것이 중요하다

📝 핵심 정리

  1. 과대적합: 모델이 훈련 데이터에 과도하게 맞춰져 일반화가 떨어지는 현상

    • 데이터의 다양성 부족 또는 모델이 너무 복잡한 경우 발생

  2. 과소적합: 모델이 훈련 데이터에도 제대로 맞지 않는 상태

    • 데이터가 부족하거나 모델이 너무 단순한 경우 발생

  3. 일반화: 적절한 데이터로 학습시킨 모델로 예측하는 것

    • 데이터의 양과 다양성이 중요

  4. KNN 알고리즘: 유유상종의 개념으로, 가장 가까운 k개 이웃을 찾아 예측

    • k 값이 너무 작으면 과대적합, 너무 크면 과소적합 발생
    • 홀수 k 값을 권장 (동점 방지)

  5. train_test_split: 훈련/테스트 데이터 분리 및 랜덤 샘플링

    • random_state를 고정하여 재현 가능한 결과 확보

  6. 하이퍼파라미터 튜닝: 반복문을 사용하여 여러 하이퍼파라미터 값을 테스트하고 성능을 비교

    • 모델 복잡도 곡선을 통해 최적의 하이퍼파라미터를 찾을 수 있음
    • Train과 Test 정확도가 모두 높고 차이가 작은 지점이 최적값
