📋 mpg 데이터 소개 및 탐색

데이터 소개:

  • mpg (mile per gallon, 연비): 미국 환경 보호국에서 공개한 데이터
  • 1999 ~ 2008년 출시된 자동차 234종 정보

데이터 로드 및 샘플 확인:

📋 다중 조건 필터링

특정 제조사들의 데이터만 추출하기:

  • toyota, ford, audi, hyundai, honda

방법 1: pd.concat() 사용

hw_method_1 = pd.concat([
    mpg[mpg['manufacturer'] == 'toyota'],
    mpg[mpg['manufacturer'] == 'ford'],
    mpg[mpg['manufacturer'] == 'audi'],
    mpg[mpg['manufacturer'] == 'hyundai'],
    mpg[mpg['manufacturer'] == 'honda']
], axis=0)

방법 2: 다중 조건 (| 연산자)

# ⚠️ 각 조건을 괄호로 묶어야 함!
hw_method_2 = mpg[
    (mpg['manufacturer'] == 'toyota') | 
    (mpg['manufacturer'] == 'ford') | 
    (mpg['manufacturer'] == 'audi') | 
    (mpg['manufacturer'] == 'hyundai') | 
    (mpg['manufacturer'] == 'honda')
]

⚠️ 주의: pandas에서 | 연산자를 사용할 때는 각 조건을 괄호로 묶어야 합니다. 괄호 없이 사용하면 연산자 우선순위로 인해 에러가 발생합니다.

방법 3: isin() 사용 (권장)

# 가장 간결하고 읽기 쉬움
hw_method_3 = mpg[mpg['manufacturer'].isin(['toyota', 'ford', 'audi', 'hyundai', 'honda'])]

📋 groupby를 활용한 집계 분석

카테고리별 도시 연비 평균:

# 카테고리별 cty 평균
cty_mean = mpg[['category', 'cty']].groupby('category').mean()
cty_mean.sort_values('cty', ascending=False)

# 회사별 hwy 평균 (상위 3개)
mpg[['manufacturer', 'hwy']].groupby('manufacturer').mean().sort_values('hwy', ascending=False).head(3)

다중 기준 groupby:

여러 컬럼을 기준으로 그룹화하여 더 세밀한 분석을 수행할 수 있습니다.

제조사와 자동차 종류별 고속도로 연비:

# 5개 제조사 데이터 (위에서 추출한 데이터)
total = hw_method_1  # 또는 hw_method_2, hw_method_3

# 제조사와 자동차 종류별로 그룹화하여 고속도로 연비(hwy) 평균 계산
subset = total[['manufacturer', 'category', 'hwy']]

# 방법 1: 단계별로 수행
grouped_by_mf_cty = subset.groupby(['manufacturer', 'category'])
grouped_by_mf_cty.mean()

# 방법 2: 한 줄로 수행 (권장)
total[['manufacturer', 'category', 'hwy']].groupby(['manufacturer', 'category']).mean()

# 평균 연비 기준으로 내림차순 정렬
total[['manufacturer', 'category', 'hwy']].groupby(['manufacturer', 'category']).mean().sort_values('hwy', ascending=False)

구동방식과 연료종류별 연비:

# drv: 구동방식 (f=전륜구동, r=후륜구동, 4=4륜구동)
# fl: 연료종류 (c=압축천연가스, d=디젤, e=에탄올, p=프리미엄, r=일반)
# hwy: 고속도로 연비
# cty: 도시 연비

subset = mpg[['drv', 'fl', 'hwy', 'cty']].groupby(['drv', 'fl']).mean()
subset

결과 해석:

  • 다중 기준 groupby는 여러 컬럼을 동시에 기준으로 그룹화하여 더 세밀한 분석이 가능합니다
  • 결과는 MultiIndex 형태로 반환되며, 각 그룹별 집계 결과를 확인할 수 있습니다

📋 데이터 시각화

1. Countplot (카운트 플롯)

제조사별 자동차 종류 시각화:

# countplot: 범주형 데이터의 개수를 시각화
# data: 데이터프레임
# x: x축에 표시할 컬럼
# hue: 분할 기준 (나타내고자 하는 것)
sns.countplot(data=total, x='manufacturer', hue='category')
plt.show()

countplot 옵션 설명:

  • data: 시각화할 DataFrame
  • x: x축에 표시할 컬럼 (제조사)
  • hue: 분할 기준 (자동차 종류별로 색상 구분)

💡 결측치 처리 참고:

만약 데이터에 결측치가 있을 경우, 다른 컬럼을 참고하여 채울 수 있습니다. 예: 자동차 종류(category)에 결측치가 있다면, 제조사(manufacturer)를 참고하여 추론 가능

  • audi → compact일 확률이 높음
  • 일반적으로 결측치를 채울 때는 평균, 중앙값, 최빈값 등을 사용하거나, 다른 컬럼을 참고하여 채움

2. Violinplot (바이올린 플롯)

Violinplot이란?

  • 수치형 데이터의 분포를 확인할 때 사용하는 그래프
  • 데이터가 많으면 두꺼워지고, 데이터가 적으면 얇아짐
  • 박스플롯과 유사하지만 분포의 형태를 더 잘 보여줌

제조사와 자동차 종류에 따른 고속도로 연비 분포:

plt.figure(figsize=(15, 6))
sns.violinplot(
    data=total, 
    x='manufacturer',      # x축: 제조사
    y='hwy',               # y축: 고속도로 연비
    hue='category',        # 분류 기준: 자동차 종류
    inner='stick',         # inner 옵션: violin 내부에 stick(막대) 표시
    palette='Pastel1'      # 색상 팔레트
)
plt.ylim(0, 50)  # y축 범위 설정
plt.show()

inner 옵션 설명:

  • inner='stick': violin 내부에 각 데이터 포인트를 막대(stick)로 표시
  • inner='box': violin 내부에 박스플롯 표시
  • inner='quart': 사분위수 표시
  • inner=None: 내부 표시 없음

3. Heatmap (히트맵) with Pivot Table

목표:

  • 제조사별, 모델별 생산연도에 따른 연비를 히트맵으로 시각화
  • 자동차 종류(category)도 함께 표시

데이터 준비 및 그룹화:

# 필요한 컬럼만 추출
sample_base = mpg[['manufacturer', 'model', 'year', 'category', 'hwy']]

# 제조사와 모델을 인덱스로 설정 (선택사항)
sample = sample_base.set_index(['manufacturer', 'model'])

# 제조사, 모델, 카테고리, 연도별로 그룹화하여 hwy 평균 계산
sample_result = sample.groupby(['manufacturer', 'model', 'category', 'year']).mean().reset_index()

Pivot Table 생성:

# 제조사명과 모델명을 공백으로 연결하여 'manufacturer_model' 컬럼 생성
sample_result['manufacturer_model'] = sample_result['manufacturer'] + ' ' + sample_result['model']

# pivot_table을 사용하여 데이터를 재구조화
# index='manufacturer_model': 행 인덱스를 제조사-모델 조합으로 설정
# columns='year': 열을 연도(1999, 2008)로 설정
# values='hwy': 각 셀의 값은 고속도로 연비(hwy)
pivot_data = sample_result.pivot_table(
    index='manufacturer_model',
    columns='year',
    values='hwy'
)

평균 연비 기준 정렬:

# 각 행(제조사-모델)의 평균 연비를 계산하여 'avg_hwy' 컬럼에 저장
# axis=1: 각 행(row)에 대해 평균 계산 (연도별 연비의 평균)
pivot_data['avg_hwy'] = pivot_data.mean(axis=1)

# 'avg_hwy' 기준으로 내림차순 정렬 후, 정렬에 사용한 임시 컬럼 'avg_hwy' 제거
pivot_data = pivot_data.sort_values('avg_hwy', ascending=False).drop('avg_hwy', axis=1)

Heatmap 시각화:

from matplotlib import rc
import platform

# 한글 폰트 설정
os_name = platform.system()
if os_name == 'Darwin':  # macOS
    rc('font', family='AppleGothic')
elif os_name == 'Windows':  # Windows
    rc('font', family='Malgun Gothic')
elif os_name == 'Linux':  # Linux
    rc('font', family='NanumGothic')

rc('axes', unicode_minus=False)  # 마이너스 기호 깨짐 방지

# 그래프 크기 설정 (데이터 행 수에 비례하여 높이 조정)
plt.figure(figsize=(12, len(pivot_data)*0.3))

# 히트맵 생성
sns.heatmap(
    pivot_data,                    # 위에서 만든 pivot 테이블 데이터
    annot=True,                    # 각 셀에 실제 값 표시
    fmt='.1f',                     # 값 표시 형식: 소수점 1자리까지
    cmap='RdYlGn',                 # 색상 맵: Red-Yellow-Green
    cbar_kws={'label': '연비 (hwy)'}  # 컬러바(색상 범례)의 라벨 설정
)

plt.title('제조사별 Model별 생산연도에 따른 연비 Heatmap (평균 연비 기준 정렬)')
plt.xlabel('생산연도')
plt.ylabel('제조사 - Model')
plt.tight_layout()
plt.show()

Heatmap 옵션 설명:

  • annot=True: 각 셀에 실제 값 표시
  • fmt='.1f': 값 표시 형식 (소수점 1자리)
  • cmap='RdYlGn': 색상 맵 (Red-Yellow-Green - 높은 값이 초록색, 낮은 값이 빨간색)
  • cbar_kws: 컬러바(색상 범례) 옵션

Heatmap의 장점:

  • 2차원(행×열) 패턴을 색상으로 빠르게 파악 가능
  • 연도별 비교와 전체적인 연비 분포를 동시에 확인
  • 정렬 기준에 따라 보는 관점이 달라짐 (평균 연비 기준 정렬 시 연비 순위 파악 용이)

💡 핵심 정리

배운 것

  • 데이터 탐색: shape, info(), describe(), head(), tail()
  • 데이터 정렬: sort_values() 활용
  • 다중 조건 필터링: isin(), pd.concat(), 다중 조건 (| 연산자)
  • groupby 집계: 단일 기준 및 다중 기준 groupby
  • Seaborn 시각화: countplot, violinplot, heatmap 등 다양한 차트 타입
  • Pivot Table: 데이터를 재구조화하여 히트맵으로 시각화

인사이트

  • 시각화의 중요성: 데이터를 시각화하면 패턴과 트렌드를 한눈에 파악 가능
  • 다중 기준 분석: 여러 기준으로 그룹화하면 더 세밀한 인사이트 도출 가능
  • Pivot Table 활용: 데이터를 재구조화하여 시각화하면 더 명확한 패턴 파악 가능
  • isin() 권장: 다중 조건 필터링에서 가장 간결하고 읽기 쉬움

주의사항

  • ✅ isin() 권장: 다중 조건 필터링에서 가장 간결하고 읽기 쉬움
