📋 리스트와 튜플 (List & Tuple)

리스트와 튜플이란?

  • 리스트: 순서가 있는 수정 가능한 객체의 집합
  • 튜플: 순서가 있는 수정 불가능한 객체의 집합

비교표:

특징ListTuple
문법[] (대괄호)() (소괄호)
가변성Mutable (수정 가능)Immutable (수정 불가능)
추가/수정/삭제가능불가능
메모리상대적으로 더 많이 사용메모리 절약
용도동적으로 변경되는 데이터수정되면 안 되는 데이터

리스트 (List)

기본 특징:

  • 대괄호 []로 작성, 리스트 내부는 ,로 구분
  • 하나의 리스트에 다양한 자료형을 포함할 수 있음
  • 비어있는 리스트도 작성 가능
  • 요소로 다른 리스트를 넣을 수 있음 (중첩 리스트)

인덱싱과 슬라이싱:

# 인덱싱: 특정 위치의 요소 접근
my_list = [10, 20, 30, 40, 50]
print(my_list[0])   # 10 (첫 번째 요소)
print(my_list[-1])  # 50 (마지막 요소)

# 슬라이싱: 범위의 요소 접근
print(my_list[1:4])  # [20, 30, 40] (인덱스 1부터 3까지)
print(my_list[:3])   # [10, 20, 30] (처음부터 인덱스 2까지)
print(my_list[2:])   # [30, 40, 50] (인덱스 2부터 끝까지)

💡 궁금해서 찾아본 내용: 인덱싱과 슬라이싱에 생긴 의문점

왜 인덱스는 0부터 시작하는가?

  • C 언어의 영향: 대부분의 현대 언어들이 C 언어의 관례를 따름
  • 메모리 주소 계산의 단순성: 베이스 주소 + (인덱스 × 요소 크기)
  • 범위 표현의 직관성: [0, len(list)) 형식으로 표현 가능
  • 수학적 모델링: 길이가 n일 때, 유효한 인덱스는 0부터 n-1까지

왜 슬라이싱은 end를 포함하지 않는가? (Half-Open Interval)

  • 길이 계산의 단순성: end - start로 간단하게 계산 가능
  • 연속된 슬라이싱의 자연스러움: 구간을 나눌 때 겹침 없이 분할 가능
  • 범위 표현의 일관성: [0:len(list)] 형식으로 자연스럽게 표현
  • 빈 슬라이싱의 명확성: 같은 인덱스로 슬라이싱하면 빈 리스트

리스트 연산:

# 덧셈: 두 리스트를 연결
list1 = [1, 2, 3]
list2 = [4, 5]
print(list1 + list2)  # [1, 2, 3, 4, 5]

# 곱셈: 리스트를 반복
print(list1 * 3)  # [1, 2, 3, 1, 2, 3, 1, 2, 3]

슬라이싱 할당:

list6 = [0, 1, 2, 3, 4, 5, 6]
list6[2:5] = [283, 'a']     # 정석: 리스트 사용
list6[2:5] = (283, 'a')     # 가능: 튜플도 iterable
list6[2:5] = 283, 'a'       # 가능: 튜플 자동 생성
list6[2:5] = "abc"          # 가능: 문자열도 iterable
# list6[2:5] = 283          # 에러: iterable이 아님 (TypeError)
  • 단일 값은 불가능 (TypeError 발생)

💡 궁금해서 찾아본 내용

  • 슬라이싱 할당은 **반복 가능한 객체(iterable)**를 요구함
  • 리스트, 튜플, 문자열 등 iterable 객체 사용 가능

중첩 리스트 접근:

list3 = [1, 2, 3, ['a', 'b', 'c']]
print(list3[3][1])  # 'b'
# list3[3]의 결과가 리스트이므로, 다시 인덱싱 가능

💡 궁금해서 찾아본 내용: 참조(Reference) 개념

  • Python은 참조를 사용하여 객체를 가리킴
  • 내부적으로는 주소값을 가리키지만, 프로그래머가 직접 주소 연산 불가능
  • 포인터와의 차이: 안전한 포인터 개념 (직접 메모리 조작 불가)

멤버십 연산자:

my_list = [1, 2, 3, 'a', 'b']
print(2 in my_list)      # True
print('c' not in my_list)  # True
  • in: 요소가 iterable에 있는지 확인
  • not in: 요소가 iterable에 없는지 확인

튜플 (Tuple)

기본 특징:

  • 소괄호 ()로 작성 (리스트와 거의 동일하나 수정 불가능)
  • Immutable 자료구조 (추가, 수정, 삭제 불가능)
  • 메모리 효율: List보다 메모리를 절약
  • 수정되면 안 되는 데이터에 사용

예시:

my_tuple = (1, 2, 'hello', 3.14)
# my_tuple[0] = 10  # 에러 발생! 수정 불가능

🔀 조건문 (Conditional Statement)

조건문이란?

  • 상황에 따라 실행 흐름을 다르게 하는 문법
  • 분기가 나뉘고, 상황에 따라 실행하거나 다음 조건으로 넘어감

기본 문법:

if 조건식:
    실행문장
elif 조건식:
    실행문장
else:
    실행문장

실행 흐름:

시작
  ↓
if 조건식 평가
  ├─ True  → 실행문장 실행 → 종료
  └─ False → 다음 조건으로 이동
            ↓
        elif 조건식 평가 (있을 경우)
          ├─ True  → 실행문장 실행 → 종료
          └─ False → 다음 조건으로 이동
                    ↓
                else (있을 경우)
                  → 실행문장 실행 → 종료

핵심 포인트:

  • 조건식이 True이면 해당 블록 실행 후 즉시 종료 (다음 조건은 평가하지 않음)
  • 조건식이 False이면 다음 조건(elif 또는 else)으로 넘어감
  • 모든 조건이 False이고 else가 있으면 else 블록 실행

실전 예제:

  • 점수 입력 및 학점 부여 (0-100 범위 검증)
  • 좌표 입력 및 사분면 판별 (원점 처리 포함)
  • 자판기 프로그램 (Enum 활용, 함수 분리, 잔액 부족 시 추가 금액 입력)

🔁 반복문 (Loop)

반복문이란?

  • 프로그램 내에서 동일한 명령을 일정 횟수만큼 반복하여 수행하도록 제어하는 명령문

반복문의 종류:

종류사용 시기특징
while반복 횟수가 명확하지 않을 때조건식이 True인 동안 반복, 조건 변화 필요
for반복 횟수가 명확할 때시퀀스(리스트, 튜플 등)를 순회하며 반복

1. while 문

기본 문법:

while 조건식:
    실행문장

특징:

  • 조건식이 True인 동안 반복 실행
  • 조건식이 False가 되면 루프 종료
  • 조건식이 변화하지 않으면 무한 루프에 빠질 수 있음

예제:

# 1부터 3까지 출력
number = 1
while number <= 3:  # 조건식
    print(number)
    number += 1  # 조건 변화 (없으면 무한 루프)

2. for 문

기본 문법:

for 변수 in iterable:
    실행문장

특징:

  • 문자열, 리스트, 튜플 등 iterable 객체 내 요소를 하나씩 반복
  • 반복 횟수가 명확할 때 사용

예제:

# 리스트 순회
fruits = ['사과', '바나나', '오렌지']
for fruit in fruits:
    print(fruit)

# 문자열 순회
for char in "Python":
    print(char)

3. 반복문 제어 (break)

기본 문법:

while True:
    if 조건:
        break  # 반복문 강제 종료

특징:

  • 반복문을 강제로 종료하는 기능
  • 조건문과 함께 사용하여 특정 조건에서 루프를 빠져나올 수 있음

예제:

# while True: 루프에서 사용자 입력이 'q'일 때 break로 종료
while True:
    user_input = input('입력 (종료: q) >> ')
    if user_input == 'q':
        break
    print(user_input)

4. range() 함수

기본 문법:

range(시작, 종료, 증가량)  # 종료 값은 포함하지 않음 (Half-open interval)

특징:

  • 필요한 만큼의 숫자를 만들어 내는 유용한 기능
  • 종료 값은 포함하지 않음 (Half-open interval)
  • 주로 for 문과 함께 사용

예제:

# 기본 사용법
range(0, 10, 1)   # 0부터 9까지 1씩 증가
range(1, 100, 3)  # 1부터 97까지 3씩 증가 (1, 4, 7, ..., 97)

# for 문과 함께 사용
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4 출력

💡 핵심 정리

📖 배운 것

  • 리스트와 튜플의 차이점 (가변성, 메모리 효율)
  • 인덱싱과 슬라이싱의 원리 (0-based indexing, Half-open interval)
  • 중첩 리스트 접근 및 참조 개념
  • 리스트의 다양한 메서드와 연산
  • 조건문 (if, elif, else)의 실행 흐름과 활용법
  • 반복문 (while, for)의 사용 시기와 특징
  • range() 함수의 활용

💭 인사이트

  • 리스트와 튜플의 가변성 차이는 메모리 효율과 데이터 안정성에 중요한 요소
  • 0-based indexing과 Half-open interval은 일관성 있는 코드 작성에 도움
  • 슬라이싱 할당은 iterable 객체를 요구하는 이유는 다중 요소 교체 연산이기 때문
  • 조건문의 실행 흐름을 이해하면 코드의 논리적 흐름을 파악하기 쉬움
  • 반복문에서 조건 변화가 없으면 무한 루프에 빠질 수 있으므로 주의 필요
  • range() 함수는 반복 횟수가 명확할 때 유용한 도구

⚠️ 주의사항

  • ⚠️ 리스트는 수정 가능하지만, 튜플은 수정 불가능 (Immutable)
  • ⚠️ 슬라이싱 할당은 반복 가능한 객체(iterable)를 요구함
  • ⚠️ remove() 메서드는 첫 번째 요소만 삭제 (모두 삭제하려면 반복 필요)
  • ⚠️ 조건문에서 조건식이 True이면 해당 블록 실행 후 즉시 종료 (다음 조건 평가 안 함)
  • ⚠️ while 문에서 조건식이 변화하지 않으면 무한 루프 발생 가능
  • ✅ 조건문은 중첩 구조로 코드 중복을 줄일 수 있음
  • ✅ 리스트 메서드는 각각의 특성을 이해하고 적절히 활용
  • ✅ 반복문은 break로 조기 종료 가능
