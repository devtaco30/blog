📚 오늘의 학습 내용

오늘은 유방암 데이터를 활용한 이진 분류 실습을 통해 신경망의 구조와 작동 원리를 심화 학습했습니다. 각 계층의 역할, 가중치의 의미, 선형/비선형 변환, 그리고 학습과 예측의 차이를 구체적으로 이해했습니다. 또한 머신러닝과 딥러닝의 근본적인 차이점도 학습했습니다.

0️⃣ 머신러닝 vs 딥러닝: 근본적인 차이

머신러닝: 이미 완성된 것을 '사용'하는 형태

특징:

  • 이미 구현된 알고리즘 클래스를 선택하여 사용
  • 비유: 완제품 피규어를 색칠하는 느낌
    • 피규어의 기본 형태는 이미 정해져 있음
    • 색상(하이퍼 파라미터)만 조절 가능
  • 특정 알고리즘을 선택하고 그 알고리즘의 하이퍼 파라미터를 조정하는 과정에 집중

작업 과정:

  1. 알고리즘 선택 (예: 선형 회귀, 결정 트리, SVM 등)
  2. 하이퍼 파라미터 조정 (예: max_depth, learning_rate 등)
  3. 모델 학습 및 평가

특성공학:

  • 특성공학이 머신러닝 학습 자체에서는 불가능
  • 데이터 전처리 단계에서 수동으로 특성을 만들어야 함
  • 3~4단계(데이터 전처리, 탐색적 데이터 분석)가 중요하고 오래 걸림

예시:

# Scikit-learn: 이미 완성된 알고리즘 사용
from sklearn.linear_model import LogisticRegression
model = LogisticRegression()  # 이미 완성된 구조
model.fit(X_train, y_train)   # 하이퍼 파라미터만 조정

딥러닝: 직접 조립해서 만들어 사용하는 형태

특징:

  • 신경망의 각 층(layer)을 직접 정의하고 조합하여 모델 설계
  • 비유: 레고 블록을 하나하나 쌓아 올려 구조물을 만드는 느낌
    • 어떤 블록을 몇 개 쌓을지, 어떻게 연결할지 모두 직접 결정
    • 층의 개수, 뉴런 개수, 활성화 함수 등 모든 것을 설계

작업 과정:

  1. 모델 구조 직접 설계
    • 입력층 크기 결정
    • 은닉층 개수, 뉴런 개수 결정
    • 활성화 함수 선택
    • 출력층 구조 결정
  2. 모델 학습 및 평가

특성공학:

  • 딥러닝 학습 자체에서 특성공학이 가능
  • 모델이 데이터로부터 계층적인 특징(feature)을 자동으로 학습
  • 전처리 단계에서 수동으로 특성을 만들 필요가 적음

예시:

# TensorFlow/Keras: 모델 구조 직접 설계
model = Sequential()
model.add(InputLayer(shape=(30,)))           # 입력층 직접 정의
model.add(Dense(units=32, activation='sigmoid'))  # 은닉층1 직접 설계
model.add(Dense(units=64, activation='sigmoid'))  # 은닉층2 직접 설계
model.add(Dense(units=1, activation='sigmoid'))   # 출력층 직접 설계
model.compile(...)
model.fit(X_train, y_train)  # 설계한 구조로 학습

핵심 차이점 정리

구분머신러닝딥러닝
모델 구조이미 완성된 알고리즘 선택직접 설계 (층, 뉴런, 활성화 함수 등)
비유완제품 피규어 색칠레고 블록 조립
특성공학수동으로 전처리 단계에서 수행모델이 자동으로 학습
유연성제한적 (알고리즘에 따라 구조 고정)매우 높음 (원하는 대로 설계 가능)
작업 집중도하이퍼 파라미터 조정에 집중모델 구조 설계에 집중

왜 이런 차이가 생기는가?

  • 머신러닝: 이미 검증된 알고리즘을 사용 → 빠르고 간단하지만 구조 변경 불가
  • 딥러닝: 문제에 맞는 맞춤형 구조 설계 → 복잡하지만 유연하고 강력함

1️⃣ 실습: 유방암 데이터 이진 분류

데이터 개요

  • 데이터셋: Wisconsin Breast Cancer (Diagnostic) Dataset
  • 샘플 수: 569개
  • 특성 수: 30개 (평균 반경, 질감, 둘레, 면적, 오목점 등)
  • 목표: 악성(Malignant) vs 양성(Benign) 분류
  • 클래스 분포: 악성 212개, 양성 357개

데이터 구조 예시:

특성명 (30개):

  • mean radius (평균 반경)
  • mean texture (평균 질감)
  • mean perimeter (평균 둘레)
  • mean area (평균 면적)
  • mean smoothness (평균 매끄러움)
  • ... (총 30개)

샘플 데이터 예시 (1행):

[17.99, 10.38, 122.8, 1001.0, 0.1184, 0.2776, 0.3001, 0.1471, 0.2419, 0.07871, 
 1.095, 0.9053, 8.589, 153.4, 0.006399, 0.04904, 0.05373, 0.01587, 0.03003, 0.006193, 
 25.38, 17.33, 184.6, 2019.0, 0.1622, 0.6656, 0.7119, 0.2654, 0.4601, 0.1189]
→ 정답: 0 (악성)

데이터 형태:

  • X (입력): (569, 30) - 569개 샘플, 각각 30개 특성
  • y (정답): (569,) - 0 (악성) 또는 1 (양성)

모델 구조

핵심 개념: 뉴런 → 층 → 여러 층 → 값이 거쳐가면서 추론

입력층(30) → 은닉층1(32) → 은닉층2(64) → 은닉층3(128) 
→ 은닉층4(64) → 은닉층5(32) → 은닉층6(16) → 출력층(1)

구조의 의미:

  1. 뉴런 (인공신경세포): 각 층에 여러 개의 뉴런이 있음

    • 입력층: 30개 뉴런 (30개 특성 각각을 담당)
    • 은닉층1: 32개 뉴런
    • 은닉층2: 64개 뉴런
    • ... (각 층마다 뉴런 개수 다름)
    • 출력층: 1개 뉴런 (최종 결과 출력)

  2. 층 (Layer): 뉴런들이 모여서 하나의 층을 이룸

    • 각 층은 여러 개의 뉴런으로 구성됨
    • 뉴런들이 함께 작동하여 정보를 처리

  3. 여러 층을 세팅: 층을 여러 개 쌓아 올림

    • 입력층 → 은닉층들 → 출력층
    • 각 층마다 역할이 다름

  4. 값들이 층을 거쳐가면서 추론:

    • 입력 데이터가 첫 번째 층(입력층)에 들어감
    • 각 층을 지날 때마다 뉴런들이 계산을 수행
    • 계산된 값이 다음 층으로 전달됨
    • 최종 층(출력층)에서 추론 결과가 나옴

설계 의도:

  • 입력층: 30개 검사 결과를 받음 (30개 뉴런)
  • 은닉층: 점진적으로 확장(32→64→128) 후 압축(128→64→32→16)
    • 확장: 더 많은 관점으로 정보 분석 (뉴런 수 증가)
    • 압축: 중요한 정보만 추출하여 최종 판단 준비 (뉴런 수 감소)
  • 출력층: 1개 뉴런 (이진 분류이므로 확률값 1개만 필요)

손실 함수와 옵티마이저

  • 손실 함수: binary_crossentropy (이진 분류 전용)
  • 옵티마이저: SGD (확률적 경사하강법)
  • 평가 지표: accuracy (정확도)

2️⃣ 신경망의 기본 개념: 선형 vs 비선형

선형 (Linear)

  • 특징: 일정한 패턴을 가짐
  • 입력이 2배 증가하면 출력도 2배 증가 (비율이 일정)
  • 그래프: 직선
  • 한계: 복잡한 관계를 표현할 수 없음
    • 예: "반경이 크면 악성" (단순한 관계만 표현)

비선형 (Non-linear)

  • 특징: 일정하지 않은 패턴
  • 입력이 2배 증가해도 출력이 2배가 아닐 수 있음
  • 그래프: 곡선 (S자, 지수 등)
  • 장점: 복잡한 관계를 표현할 수 있음
    • 예: "반경이 크고 질감이 거칠고 둘레가 일정 이상이면 악성" (복잡한 조건 표현 가능)

신경망에서의 차이

활성화 함수 없이 (선형만):

입력 → 선형결합 → 선형결합 → 선형결합 → 출력
결과: 결국 선형 결합만 반복 → 복잡한 패턴 학습 불가
  • 여러 층을 쌓아도 결국 선형 결합의 합성 → 여전히 선형
  • 예: "반경이 크면 악성" (단순한 관계만 표현 가능)

활성화 함수 있이 (선형 + 비선형 조합):

입력 → 선형결합 → sigmoid(비선형) → 선형결합 → sigmoid(비선형) → 출력
결과: 각 층마다 비선형 변환 → 복잡한 패턴 학습 가능
  • 각 층마다 선형 결합 + 비선형 변환이 반복됨
  • 층을 쌓을수록 복잡한 패턴 학습 가능
  • 예: "반경이 크고 질감이 거칠고 둘레가 일정 이상이면 악성" (복잡한 조건 표현 가능)

핵심 정리: 딥러닝은 비선형을 사용합니다 (YES)

명확한 답변:

  • 딥러닝은 비선형을 사용합니다 ✅
  • 하지만 선형 결합도 함께 사용합니다
  • 비선형 활성화 함수가 핵심입니다

작동 방식: 선형 + 비선형 조합

  • 각 뉴런마다: 선형 결합 (가중치 연산) → 비선형 변환 (활성화 함수)
  • 선형 결합: z = w1*입력1 + w2*입력2 + ... + b (가중치로 곱하고 더함)
  • 비선형 변환: 출력 = sigmoid(z) (활성화 함수 적용) ← 이것이 핵심!

왜 비선형이 핵심인가?

  • 선형 결합만으로는 복잡한 패턴을 학습할 수 없음
  • 활성화 함수(비선형)가 있어야 복잡한 관계를 학습할 수 있음
  • 비선형 변환이 딥러닝의 핵심 능력을 만들어냄
  • 따라서 "딥러닝은 비선형을 사용한다" = "비선형 활성화 함수가 필수다"
  1. 비유로 이해하기:
    • 선형 결합 = 재료 준비 (가중치로 정보를 조합)
    • 비선형 변환 = 요리 (활성화 함수로 복잡한 맛을 만들어냄)
    • 재료 준비만으로는 맛있는 요리가 안 되듯, 선형 결합만으로는 복잡한 패턴 학습 불가
    • 요리(비선형 변환)가 핵심이지만, 재료 준비(선형 결합)도 필수

구체적인 예시 (유방암 진단):

  • 선형만 사용: "반경이 크면 악성" (단순한 관계만 표현)
  • 선형+비선형 사용: "반경이 크고 질감이 거칠고 둘레가 일정 이상이면 악성" (복잡한 조건 표현 가능)

3️⃣ 가중치와 확률 변환 과정

뉴런의 계산 과정

공식: z = w1*입력1 + w2*입력2 + ... + w30*입력30 + b

각 요소의 의미

  1. 입력 (30개 검사 결과)

    • 유방암 환자의 30개 검사 결과
    • 예: 평균 반경 17.99, 평균 질감 10.38, 평균 둘레 122.8, ...

  2. 가중치 (w1, w2, ..., w30)

    • 각 검사 결과의 중요도를 나타내는 숫자
    • 예: w1 = 0.8 (반경이 중요), w2 = 0.3 (질감은 덜 중요)
    • TensorFlow가 자동으로 관리:
      • 초기화: 모델 생성 시 랜덤하게 초기화
      • 학습: model.fit() 실행 시 역전파 알고리즘으로 자동 조정
      • 저장: 학습된 가중치는 모델에 저장됨
    • 사용자는 모델 구조만 정의하고, 가중치는 TensorFlow가 알아서 처리!

  3. 편향 (b)

    • 추가적인 조정값
    • 모든 검사 결과가 낮아도 기본적으로 악성일 가능성을 조금 높여줌

  4. 선형 결합 결과 (z)

    • 30개 검사 결과를 가중치로 곱해서 더한 값
    • 아직 확률이 아님! (음수일 수도, 100보다 클 수도 있음)

확률로 변환하는 3단계

1단계: 선형 결합 (가중치 연산)

z = w1*입력1 + w2*입력2 + ... + w30*입력30 + b
  • 이것은 선형 연산입니다!
  • 검사 결과들을 가중치로 곱해서 더함
  • 결과: 어떤 숫자든 나올 수 있음 (예: -5.2, 0.3, 10.5, ...)
  • 확률로 변환하지 않음!

2단계: 활성화 함수 적용 (sigmoid)

출력 = sigmoid(z) = 1 / (1 + e^(-z))
  • 이것은 비선형 변환입니다!
  • sigmoid 함수가 z 값을 0~1 사이 확률로 변환
  • sigmoid의 역할 (2가지):
    1. 비선형 변환 (가장 중요!): 복잡한 패턴 학습 가능하게 함
    2. 확률 변환: z 값을 0~1 사이로 압축 (출력층에서 확률로 해석)

예시:

  • z = 5.2 → sigmoid(5.2) = 0.995 (99.5%)
  • z = 0 → sigmoid(0) = 0.5 (50%)
  • z = -5.2 → sigmoid(-5.2) = 0.005 (0.5%)

3단계: 최종 해석

  • 0.7 (70%) = 악성일 확률 70%, 양성일 확률 30%
  • 0.3 (30%) = 악성일 확률 30%, 양성일 확률 70%

중요한 구분:

  • 가중치 연산 = 선형 결합 (선형, 확률 변환 안 함)
  • sigmoid 함수 = 비선형 변환 + 확률 변환 (비선형, 확률로 변환함)

4️⃣ 신경망의 각 계층 상세 설명

1️⃣ 입력층 (Input Layer)

역할:

  • 데이터를 받아 신경망으로 전달하는 첫 번째 층
  • 데이터의 특성 개수와 뉴런 개수가 일치해야 함 (30개 특성 → 30개 뉴런)

구체적인 동작:

  • 샘플 1개 입력: [특성1, 특성2, ..., 특성30]
  • 각 뉴런이 특성 하나씩 받아서 그대로 다음 층으로 전달

비유: 30명의 의사가 각자 환자의 검사 결과 한 가지씩(평균 반경, 질감, 둘레 등) 받아서 확인하고, 다음 층에 전달

2️⃣ 은닉층 (Hidden Layer)

역할:

  • 입력과 출력 사이에서 패턴을 학습하는 층
  • 여러 층을 쌓아 복잡한 관계를 학습

은닉층의 핵심 메커니즘

각 뉴런이 하는 일:

  1. 이전 층의 모든 뉴런과 연결됨 (완전연결층, Dense)
  2. 각 연결마다 가중치가 있어서, 입력값에 곱해져서 더해짐
  3. 선형 결합: z = w1*입력1 + w2*입력2 + ... + b
  4. 활성화 함수 적용: 출력 = sigmoid(z) (비선형 변환)
  5. 이 출력을 다음 층으로 전달

은닉층을 지날 때마다 일어나는 일

중요한 구분: 학습 vs 예측

학습 과정 (가중치 조정 중):

  • 가중치가 계속 조정됨 (변경됨)
  • 각 샘플마다 예측 → 오차 계산 → 가중치 조정
  • 가중치가 최적값에 가까워지도록 학습

예측 과정 (학습 완료 후):

  • 가중치가 고정되어 있음 (학습된 가중치 사용)
  • 입력층 → 은닉층1 → 은닉층2 → ... → 출력층으로 모든 층을 거쳐감
  • 이전 층의 **출력값(결과값)**을 받아서 고정된 가중치로 계산
  • "확률을 높여간다"기보다는 "정보를 변환하고 종합해간다"

전체 흐름:

  1. 입력층: 새로운 환자의 검사 결과 (30개 특성) 입력
  2. 은닉층1: 입력층의 30개 값을 받아서 가중치로 계산 → 32개 출력값 생성
  3. 은닉층2: 은닉층1의 32개 출력값을 받아서 가중치로 계산 → 64개 출력값 생성
  4. 은닉층3: 은닉층2의 64개 출력값을 받아서 가중치로 계산 → 32개 출력값 생성
  5. 출력층: 은닉층3의 32개 출력값을 받아서 가중치로 계산 → 최종 확률값 출력

구체적인 과정:

은닉층1 → 은닉층2 예시 (예측 과정 기준):

  1. 은닉층1의 출력값 (32개)

    • 뉴런1: 0.995 (악성 가능성 99.5%)
    • 뉴런2: 0.850 (악성 가능성 85.0%)
    • ...
    • 뉴런32: 0.680 (악성 가능성 68.0%)

  2. 은닉층2의 뉴런1이 하는 일:

    • 은닉층1의 32개 출력값 모두를 받음
    • 각각에 학습된 가중치를 곱해서 더함 (예측 시에는 가중치 고정) 
      z = w1*0.995 + w2*0.850 + ... + w32*0.680 + b
    • 활성화 함수 적용 
      출력 = sigmoid(z) = 0.920 (악성 가능성 92.0%)
    • 이 새로운 값을 다음 층으로 전달

  3. 은닉층2의 뉴런2도 동일한 과정:

    • 같은 32개 입력을 받지만, 다른 가중치 사용 (각 뉴런마다 다른 가중치)
    • 다른 결과값 생성 (예: 0.750)

학습 과정에서는:

  • 위와 동일하게 계산하지만, 예측값과 정답을 비교하여 오차를 계산
  • 오차를 역방향으로 전파하여 가중치를 조정 (w1, w2, ... 값이 변경됨)
  • 다음 샘플에서는 조정된 가중치로 다시 계산

핵심 포인트:

  • 각 층마다 이미 학습된 가중치를 사용 (새로 만드는 게 아님!)
  • 이전 층의 **출력값(결과값)**을 받아서 가중치로 재계산
  • 각 층을 지날수록 정보가 변환되고 종합됨
  • 최종 출력층에서 최종 확률값 출력

완전연결의 의미:

  • 은닉층2의 뉴런1은 은닉층1의 뉴런1~32 모두와 연결됨
  • 은닉층2의 뉴런2도 은닉층1의 뉴런1~32 모두와 연결됨
  • 총 연결 수: 64개 뉴런 × 32개 연결 = 2,048개 연결선 (각각 다른 가중치)

뉴런 수 변화의 의미:

  • 증가 (30→32→64→128): 더 많은 관점으로 정보를 분석
  • 감소 (128→64→32→16): 정보 압축 및 최종 판단을 위한 요약

비유:

  • 32명의 진단 전문가가 각자 30명의 의사 모두에게서 검사 결과를 받음
  • 각 전문가는 받은 30개 결과를 각자 다른 중요도(가중치)로 평가
  • 30개 결과를 가중치로 곱해서 더한 후, 각자 진단 의견을 만듦

3️⃣ 출력층 (Output Layer)

역할:

  • 최종 결과를 출력하는 층
  • 문제 유형에 따라 뉴런 개수와 활성화 함수가 결정됨

이진 분류의 경우:

  • 뉴런 개수: 1개 (확률값 1개만 필요)
  • 활성화 함수: sigmoid (0~1 사이 확률로 변환)
  • 예: 0.7 = 악성 70%, 양성 30% (자동으로 계산됨)

비유: 모든 전문가들의 진단 의견을 종합해 주치의가 최종 판단 → "악성일 확률 70%"라고 진단

5️⃣ 학습(훈련) vs 예측

학습(훈련) 과정 - 가중치를 조정하는 단계

목적: 정답 데이터를 보고 가중치를 최적화

중요: 모든 과정은 TensorFlow가 자동으로 처리합니다!

과정:

각 샘플마다 반복되는 과정:

  1. 초기화 (첫 번째 샘플 전): TensorFlow가 가중치를 랜덤하게 초기화

    • 예: w1 = 0.1, w2 = -0.3, w3 = 0.5, ...

  2. 샘플 1 처리:

    • 예측: 현재 가중치로 예측값 계산
      • 입력층 → 은닉층1 (가중치 w1, w2, ... 사용) → 은닉층2 (가중치 w1', w2', ... 사용) → ... → 출력층
      • 예: 예측 = 0.3 (악성 30%)
    • 정답 확인: 실제 정답 데이터와 비교
      • 예: 실제 = 1 (악성), 예측 = 0.3 → 오차 = 0.7
    • 오차 계산: 손실 함수로 오차 측정
    • 가중치 조정: 역전파 알고리즘으로 오차가 큰 방향으로 가중치를 조금씩 변경
      • 예: w1을 0.1 → 0.12로 증가 (반경을 더 중요하게)

  3. 샘플 2 처리:

    • 예측: 조정된 가중치로 예측값 계산 (w1 = 0.12 사용)
    • 정답 확인: 실제 정답과 비교
    • 가중치 조정: 다시 조정 (w1 = 0.12 → 0.14)

  4. 반복 (Epoch):

    • 모든 샘플에 대해 반복 (1 epoch = 모든 샘플 1번 처리)
    • 여러 epoch 반복 (예: epochs=100 → 100번 반복)
    • 각 epoch마다 가중치가 점점 최적값에 가까워짐
    • 마지막 epoch의 가중치가 최종 가중치로 저장됨

Epoch별 가중치 변화 예시:

  • Epoch 1: w1 = 0.1 → 0.3 → 0.5 (모든 샘플 처리 후)
  • Epoch 2: w1 = 0.5 → 0.6 → 0.7
  • ...
  • Epoch 100: w1 = 0.8 (최종 가중치)
  • 기본적으로는 마지막 epoch의 가중치(w1=0.8)가 예측에 사용됨!

중요한 이해:

  • 학습 과정: 모든 epoch이 중요함! 각 epoch마다 가중치가 개선되어 점점 최적값에 가까워짐
    • Epoch 1의 가중치 → Epoch 2의 가중치 → ... → Epoch 100의 가중치
    • 각 epoch의 가중치는 이전 epoch의 학습 결과를 바탕으로 더 개선됨
  • 예측 과정: 기본적으로 마지막 epoch의 가중치만 사용
    • 모델이 완성되면 마지막 epoch의 가중치만 저장되고 사용됨
    • 이전 epoch의 가중치는 예측에 사용되지 않음

⚠️ 중요한 예외: 중간에 더 좋은 결과가 나왔을 때

문제 상황:

  • 20번 학습을 돌렸는데, 14번째 epoch에서 가장 좋은 결과가 나왔다면?
  • 예: Epoch 14에서 accuracy = 0.95 (가장 좋음), Epoch 20에서 accuracy = 0.90 (나빠짐)

기본 동작 (설정 없이):

  • 자동으로 마지막 epoch(20번째)의 가중치가 사용됨
  • 더 좋은 결과가 나온 14번째 epoch의 가중치는 사용되지 않음
  • 이는 과대적합(Overfitting) 때문일 수 있음
  • 별도 설정 없이도 마지막 epoch의 가중치가 자동으로 저장되고 사용됨

더 좋은 결과를 저장하려면:

  • 별도로 Callback 함수를 설정해야 함 (기본 동작이 아님!)
  • ModelCheckpoint: 가장 좋은 성능의 가중치를 자동으로 저장하도록 설정
  • EarlyStopping: 성능이 더 이상 개선되지 않으면 학습 중단하도록 설정
  • 이렇게 설정하면 14번째 epoch의 가중치를 저장하고 사용할 수 있음

예시 코드:

from tensorflow.keras.callbacks import ModelCheckpoint, EarlyStopping

# 가장 좋은 성능의 가중치를 자동으로 저장
checkpoint = ModelCheckpoint(
    'best_model.h5',           # 저장할 파일명
    monitor='val_accuracy',     # 모니터링할 지표
    save_best_only=True,        # 가장 좋은 것만 저장
    verbose=1
)

# 성능이 개선되지 않으면 학습 중단
early_stop = EarlyStopping(
    monitor='val_accuracy',      # 모니터링할 지표
    patience=5,                 # 5번 연속 개선 없으면 중단
    verbose=1
)

# 학습 시 callback 사용
model.fit(X_train, y_train,
          validation_split=0.3,
          epochs=100,
          callbacks=[checkpoint, early_stop])  # callback 추가

# 가장 좋은 가중치로 모델 로드
model.load_weights('best_model.h5')  # 14번째 epoch의 가중치 사용

핵심 정리:

  • 학습 과정에서는 가중치가 계속 조정됨 (변경됨)
  • 각 샘플마다 예측 → 오차 계산 → 가중치 조정이 반복됨
  • 기본적으로는 마지막 epoch의 가중치가 사용되지만, 더 좋은 결과가 중간에 나왔다면 Callback을 사용하여 그 시점의 가중치를 저장하고 사용할 수 있음
  • 정답 데이터가 있어야 함! (X_train, y_train)

평가 과정 - 학습된 모델로 테스트 데이터 평가

목적: 학습된 가중치로 테스트 데이터의 성능을 평가

중요: 학습이 완료된 후 가중치가 고정되어 있음!

기본 동작:

  • model.evaluate(X_test, y_test)를 호출하면 자동으로 마지막 epoch의 가중치로 평가됨
  • 별도 설정 없이도 마지막 epoch의 가중치가 사용됨
  • 머신러닝의 score() 함수와 비슷한 역할

예시 코드:

# 학습
model.fit(X_train, y_train, epochs=100)

# 평가 (자동으로 마지막 epoch의 가중치 사용)
model.evaluate(X_test, y_test)  # 가장 마지막 학습결과로 평가

과정:

  1. 학습 완료: 마지막 epoch의 가중치가 최종 가중치로 저장됨 (고정)

    • 예: Epoch 100의 가중치 w1 = 0.8, w2 = 0.2, w3 = 0.6, ... (더 이상 변경 안 함)
    • 모델이 완성되면 마지막 epoch의 가중치만 저장되고 사용됨
    • 이전 epoch의 가중치는 평가에 사용되지 않음

  2. 테스트 데이터 평가: model.evaluate() 호출

    • 자동으로 마지막 epoch의 가중치를 사용하여 테스트 데이터 평가
    • 정답(y_test)과 비교하여 성능 측정

예측 과정 - 학습된 모델로 새로운 데이터 예측

목적: 학습된 가중치로 새로운 환자의 결과를 예측

중요: 학습이 완료된 후 가중치가 고정되어 있음!

과정:

  1. 학습 완료: 마지막 epoch의 가중치가 최종 가중치로 저장됨 (고정)

    • 예: Epoch 100의 가중치 w1 = 0.8, w2 = 0.2, w3 = 0.6, ... (더 이상 변경 안 함)
    • 모델이 완성되면 마지막 epoch의 가중치만 저장되고 사용됨
    • 이전 epoch의 가중치는 예측에 사용되지 않음

  2. 새로운 데이터 입력: 새로운 환자의 검사 결과 입력

    • 예: [평균 반경 20.5, 평균 질감 12.3, ...]

  3. 예측 계산 (가중치 고정, 모든 층을 거쳐감):

    • 입력층: 새로운 환자의 검사 결과 (30개 특성) 입력
    • 은닉층1: 입력층의 30개 값을 받아서 고정된 가중치로 계산 → 32개 출력값 생성
    • 은닉층2: 은닉층1의 32개 출력값을 받아서 고정된 가중치로 계산 → 64개 출력값 생성
    • 은닉층3: 은닉층2의 64개 출력값을 받아서 고정된 가중치로 계산 → 32개 출력값 생성
    • 출력층: 은닉층3의 32개 출력값을 받아서 고정된 가중치로 계산 → 최종 확률값 출력
    • 학습된 가중치로 계산하여 확률값 출력
    • 예: sigmoid(z) = 0.85 (악성일 확률 85%)

    중요: 예측 과정에서도 모든 층을 거쳐감. 학습과 구조는 동일하지만, 가중치가 고정되어 있다는 점만 다름!

  4. 결과 출력: 예측값만 출력 (정답 확인 없음!)

핵심:

  • 예측 과정에서도 모든 층을 거쳐감 (입력층 → 은닉층들 → 출력층)
  • 학습과 구조는 동일하지만, 가중치가 고정되어 있다는 점만 다름
  • 예측 과정에서는 가중치가 고정되어 있음 (변경 안 함)
  • 마지막 epoch의 가중치만 사용하여 계산만 수행
  • 모델이 완성되면 마지막 epoch의 가중치만 저장되고, 이전 epoch의 가중치는 사용되지 않음
  • 정답 데이터가 없어도 됨! (X_test만 있으면 됨)

학습 vs 예측 비교

구분학습(훈련)예측

예시:

  • 학습: "이 환자는 악성이었어 (정답), 내가 30%라고 했네? 가중치를 조정해야겠다"
  • 예측: "이 환자는 몇 %일까? (정답 모름) 학습된 가중치로 계산해보자 → 85%"

6️⃣ 구체적인 예시: 유방암 진단 과정

환자 데이터

  • 평균 반경: 17.99
  • 평균 질감: 10.38
  • 평균 둘레: 122.8
  • ... (총 30개)

뉴런1의 계산 과정

학습된 가중치:

  • w1 = 0.8 (반경이 매우 중요)
  • w2 = 0.2 (질감은 덜 중요)
  • w3 = 0.6 (둘레도 중요)
  • ...
  • b1 = 0.1

1단계: 선형 결합

z1 = 0.8×17.99 + 0.2×10.38 + 0.6×122.8 + ... + 0.1
   = 14.39 + 2.08 + 73.68 + ... + 0.1
   = 5.2

2단계: 활성화 함수 (sigmoid)

출력1 = sigmoid(5.2) = 1 / (1 + e^(-5.2))
                   = 1 / (1 + 0.0055)
                   = 0.995

→ 이 뉴런은 "악성일 가능성 99.5%"라고 판단

3단계: 여러 뉴런의 의견 종합

  • 뉴런1: 0.995 (99.5%)
  • 뉴런2: 0.850 (85.0%)
  • 뉴런3: 0.720 (72.0%)
  • ...
  • 뉴런32: 0.680 (68.0%)

→ 이 32개 값이 다음 층(은닉층2)으로 전달

4단계: 은닉층2에서 재계산

  • 은닉층2의 각 뉴런(64개)이 은닉층1의 32개 출력값을 받음
  • 각 뉴런마다 다른 가중치로 재계산 
    은닉층2 뉴런1: w1*0.995 + w2*0.850 + ... + w32*0.680 + b → sigmoid → 0.920
은닉층2 뉴런2: w1'*0.995 + w2'*0.850 + ... + w32'*0.680 + b' → sigmoid → 0.750
...
  • 64개의 새로운 값 생성 → 다음 층으로 전달

5단계: 계속 변환 및 종합

  • 은닉층3: 64개 → 128개 (더 많은 관점으로 분석)
  • 은닉층4: 128개 → 64개 (정보 압축 시작)
  • 은닉층5: 64개 → 32개 (더 압축)
  • 은닉층6: 32개 → 16개 (최종 정리)

6단계: 최종 출력층

  • 은닉층6의 16개 값을 받아서 최종 계산
  • 모든 층을 거쳐 최종적으로 하나의 확률값 출력
  • 예: 0.7 (악성일 확률 70%)

핵심:

  • 학습 과정:
    • 각 샘플마다 예측 → 오차 계산 → 가중치 조정 (가중치가 계속 변경됨)
    • 이전 층의 출력값을 받아서 현재 가중치로 계산하고, 오차를 계산하여 가중치를 조정
  • 예측 과정 (학습 완료 후):
    • 각 층마다 학습된 가중치를 사용 (고정)
    • 이전 층의 **출력값(결과값)**을 받아서 고정된 가중치로 재계산
  • 각 층을 지날수록 정보가 변환되고 종합되어 최종 판단에 가까워짐

7️⃣ 핵심 개념 정리

완전연결 (Dense)

  • 각 뉴런은 이전 층의 모든 뉴런과 연결됨
  • 뉴런 수가 늘어나도 각 뉴런은 여전히 이전 층의 모두와 연결
  • 모든 정보를 종합하여 판단 (일부만 보는 게 아니라 전부 다 봄)

가중치의 역할

  • 각 연결마다 가중치가 있음 (입력값에 곱해지는 숫자)
  • 뉴런마다 다른 가중치 → 같은 입력이어도 다른 결과
  • 가중치가 크면 → 그 입력을 중요하게 봄
  • TensorFlow가 자동으로 관리:
    • 초기화: 모델 생성 시 자동으로 랜덤 초기화
    • 학습: model.fit() 실행 시 역전파로 자동 조정
    • 사용자는 모델 구조만 정의하면 됨!

활성화 함수의 역할

  • 주요 역할: 비선형 변환 (복잡한 패턴 학습 가능하게 함)
  • 부가 효과: z 값을 0~1 사이로 압축 (출력층에서 확률로 해석 가능)
  • 활성화 함수가 없으면 → 선형 결합만 반복 → 복잡한 패턴 학습 불가
  • 활성화 함수가 있으면 → 비선형 변환 → 복잡한 패턴 학습 가능

뉴런 수 변화의 의미

  • 증가 (30→32→64→128): 더 많은 관점으로 분석
  • 감소 (128→64→32→16→1): 정보 압축 및 최종 판단

각 층을 지날 때마다 일어나는 일

학습 과정:

  • 이전 층의 출력값을 받아서 현재 가중치로 계산
  • 오차를 계산하고 가중치를 조정 (변경)
  • 다음 샘플에서는 조정된 가중치로 다시 계산

예측 과정 (학습 완료 후):

  • 이전 층의 출력값(결과값)을 받음: 각 뉴런이 이전 층의 모든 뉴런 출력값을 받음
  • 마지막 epoch의 가중치로 재계산: 각 층마다 고정된 가중치(마지막 epoch의 가중치)를 사용하여 선형 결합 수행
  • 활성화 함수로 변환: sigmoid 함수로 비선형 변환 및 확률값 생성
  • 정보 변환 및 종합: 각 층을 지날수록 정보가 변환되고 종합되어 최종 판단에 가까워짐
  • 중요: "확률을 높여간다"기보다는 **"정보를 변환하고 종합해간다"**가 정확한 표현

💡 핵심 정리

배운 것

  • 신경망의 각 계층이 어떻게 작동하는지 구체적으로 이해
  • 가중치가 무엇이고, TensorFlow가 어떻게 자동으로 관리하는지
  • 선형 결합과 활성화 함수의 차이 (선형 vs 비선형)
  • 학습과 예측의 근본적인 차이
  • 완전연결(Dense)의 의미와 각 뉴런이 모든 이전 뉴런과 연결되는 구조

인사이트

  • 가중치 = 각 검사 결과의 중요도: TensorFlow가 학습 과정에서 자동으로 최적값을 찾음
  • 선형 결합 ≠ 확률 변환: 가중치로 계산하는 것은 선형 연산이고, 확률로 변환하는 것은 sigmoid 함수의 역할
  • 비선형성이 핵심: 활성화 함수가 있어야 복잡한 패턴을 학습할 수 있음
  • 완전연결의 의미: 각 뉴런이 이전 층의 모든 정보를 종합하여 판단
  • 학습 vs 예측: 학습은 가중치를 조정하는 과정, 예측은 마지막 epoch의 가중치로 결과를 계산하는 과정
  • 마지막 epoch의 가중치: 학습이 완료되면 마지막 epoch의 가중치가 최종 가중치로 저장되고, 이 가중치만 예측에 사용됨. 이전 epoch의 가중치는 예측에 사용되지 않음.
  • 모든 epoch의 중요성: 학습 과정에서는 모든 epoch이 중요함 (각 epoch마다 가중치가 개선됨). 하지만 모델이 완성되면 마지막 epoch의 가중치만 사용됨.
  • 각 층을 지날 때마다:
    • 학습 과정: 이전 층의 출력값을 받아서 현재 가중치로 계산하고, 오차를 계산하여 가중치를 조정함 (가중치 변경)
    • 예측 과정: 이전 층의 출력값(결과값)을 받아서 학습된 가중치로 재계산하고, 정보를 변환하고 종합해간다 (가중치 고정)
    • "확률을 높여간다"기보다는 "정보를 변환하고 종합해간다"가 정확한 표현이다.

주의사항

  • ⚠️ 가중치로 곱하고 더하는 것 자체는 선형 연산 (확률로 변환하지 않음)
  • ⚠️ 확률로 변환하는 것은 sigmoid 함수의 역할 (비선형 변환)
  • ⚠️ 학습 시에는 정답 데이터가 필요하지만, 예측 시에는 불필요
  • ⚠️ TensorFlow가 가중치를 자동으로 관리하므로, 사용자는 모델 구조만 정의하면 됨
  • ⚠️ 뉴런 수가 늘어나도 각 뉴런은 여전히 이전 층의 모든 뉴런과 연결됨
  • ⚠️ 학습 과정: 각 샘플마다 예측 → 오차 계산 → 가중치 조정 (가중치가 계속 변경됨)
  • ⚠️ 예측 과정: 학습 완료 후 마지막 epoch의 가중치가 고정되어 있고, 이전 층의 결과값을 받아서 고정된 가중치로 재계산
  • ⚠️ 마지막 epoch의 가중치: 학습이 완료되면 마지막 epoch의 가중치가 최종 가중치로 저장되고, 이 가중치가 예측에 사용됨
  • ⚠️ 각 층을 지날 때마다 이전 층의 출력값(결과값)을 받아서 가중치로 재계산함 (학습 중에는 가중치가 조정되고, 예측 시에는 고정된 가중치 사용)
