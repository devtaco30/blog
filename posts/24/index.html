📋 Matplotlib 소개

Mathematical Plotting Library (MATLAB-style plotting library for Python)

  • 메타데이터를 도표나 그래프(시각화)로 출력시키는 라이브러리
  • 메타데이터: 일정한 규칙에 따라 구조화, 표준화된 데이터
  • 분석 결과를 수치만으로 설명하는 것보다 더 직관적으로 이해할 수 있다
  • 타인에게 분석 결과를 전달할 때 효과적이다

📋 Line Graph (선 그래프)

기본 사용법:

import matplotlib.pyplot as plt
import numpy as np

# y값만 지정 (x는 자동으로 0, 1, 2, ...)
y_data = [2, 4, 5]
plt.plot(y_data)
plt.show()

# x, y값 모두 지정
x = [1, 2, 3, 4, 5]
y = [1, 5, 7, 8, 6]
plt.plot(x, y)
plt.show()

주의사항:

  • plt.plot(y) - y값(데이터)은 필수, x값은 선택적 (자동으로 0부터 시작)
  • Jupyter Notebook에서는 plt.show() 없이도 자동으로 표시됨

💡 궁금해서 찾아본 내용: 한글 폰트 설정

matplotlib에서 한글을 표시하려면 한글 폰트를 설정해야 합니다.

방법 1: rc() 함수 사용 (권장)

from matplotlib import rc
import platform

os_name = platform.system()
if os_name == 'Darwin':  # macOS
    rc('font', family='AppleGothic')
elif os_name == 'Windows':  # Windows
    rc('font', family='Malgun Gothic')  # 맑은 고딕
elif os_name == 'Linux':  # Linux
    rc('font', family='NanumGothic')  # 설치 필요

rc('axes', unicode_minus=False)  # 마이너스 기호 깨짐 방지

방법 2: rcParams 직접 사용

plt.rcParams['font.family'] = 'AppleGothic'  # macOS
plt.rcParams['axes.unicode_minus'] = False

📋 Grid (그리드)

차트의 선 위치를 잘 보여주기 위해 차트 중간에 선을 그어줍니다.

plt.plot(x, y)
plt.grid()  # 기본 그리드
plt.grid(axis='y', alpha=0.3, linestyle='--', linewidth=0.8)  # 세밀한 설정
plt.show()

옵션:

  • axis: 'x', 'y', 'both' (기본값)
  • alpha: 투명도 (0.0 ~ 1.0)
  • linestyle: 선 스타일
  • linewidth: 선 두께

📋 Tick (축 눈금)

플롯이나 차트에서 축 상의 위치 표시 지점입니다. 자동/수동 설정이 가능합니다.

수동 지정:

plt.xticks([0, 3, 6])
plt.yticks([1, 4, 7])

수식으로 자동 생성 (권장):

# 방법 1: np.arange() 사용 - 시작값부터 끝값까지 일정 간격으로
plt.xticks(np.arange(0, 7, 3))  # 0부터 6까지 3씩 증가: [0, 3, 6]

# 방법 2: np.linspace() 사용 - 시작값부터 끝값까지 균등하게 분할
# 주의: np.linspace()는 기본적으로 실수(float)를 반환합니다!
plt.xticks(np.linspace(0, 6, 3, dtype=int))  # 정수로 변환: [0, 3, 6]

# 방법 3: 데이터 범위에 맞춰 자동 생성
x_min, x_max = min(x), max(x)
plt.xticks(np.arange(x_min, x_max+1, 3))

💡 np.linspace() 주의사항:

  • 기본적으로 실수(float)를 반환합니다
  • 정수로 만들려면 dtype=int 지정 필요
  • 나누어떨어지지 않으면 실수 포인트가 생길 수 있음

📋 제목 및 레이블 설정

plt.xlabel('X axis')  # x축 레이블
plt.ylabel('Y axis')  # y축 레이블
plt.title('X-Y graph')  # 차트 제목

📋 여러 Plot 한 번에 그리기

여러 개의 선 그래프를 하나의 차트에 그릴 수 있습니다.

x = np.arange(4)
y1 = np.arange(4)
y2 = [1, 4, 6, 8]
y3 = np.arange(3, 13, 3)

plt.plot(x, y1, label='y1', color='indianred')
plt.plot(x, y2, label='y2', color='mediumturquoise')
plt.plot(x, y3, label='y3', color='chartreuse')
plt.legend(loc='best')
plt.show()

Legend (범례) 설정:

plt.legend(loc='best', prop={'size': 13, 'weight': 'bold', 'family': 'serif'})

  • loc 옵션:

    • 'best': 자동으로 최적의 위치 찾기 (권장)
    • 'upper left', 'upper right', 'lower left', 'lower right'
    • 'center left', 'center right', 'lower center', 'upper center', 'center'

  • prop 옵션:

    • size: 폰트 크기
    • weight: 폰트 굵기 ('bold', 'normal')
    • family: 폰트 패밀리 (여러 폰트를 나열해서 지정 가능)

📋 Bar Chart (막대 그래프)

기본 사용법:

x = np.arange(6)
y = [80, 85, 70, 60, 50, 90]

plt.bar(x, y)
plt.show()

스타일 옵션:

plt.bar(x, y, 
        color=['orange', 'pink', 'skyblue'],  # 막대 색깔
        edgecolor='crimson',  # 막대 테두리 색깔
        linewidth=4,  # 막대 테두리 두께
        alpha=0.5,  # 막대 투명도
        width=0.5)  # 막대 너비

📋 실습: 교통사고 데이터 분석

데이터 탐색:

# 기본 정보 확인
data.shape  # (4065, 27)
data.info()

# 주요 컬럼 확인
data['사고유형_대분류'].value_counts()
data['주야'].value_counts()  # 주간/야간

요일별 주간 차대차 교통사고 건수 시각화:

# 차대차 사고 필터링
car_car = data[data['사고유형_대분류'] == '차대차']
daytime_collision = car_car[car_car['주야'] == '주간']

# 요일별 사건 발생 횟수
date = daytime_collision.value_counts('요일')
date = date[['월', '화', '수', '목', '금', '토', '일']]  # 요일 순서 정렬

# 막대 그래프 그리기
x = date.index
y = date.values

plt.bar(x, y)
plt.title('요일별 주간 차대차 교통사고 건수')
plt.xlabel('요일')
plt.ylabel('사고 건수')
plt.show()

💡 핵심 정리

배운 것

  • Matplotlib: 데이터 시각화를 위한 Python 라이브러리
  • 한글 폰트 설정: OS별로 적절한 폰트 설정 필요 (macOS: AppleGothic, Windows: Malgun Gothic)
  • Line Graph: plt.plot() - 선 그래프 그리기
  • Bar Chart: plt.bar() - 막대 그래프 그리기
  • 스타일 옵션: color, linewidth, linestyle, marker 등 다양한 옵션으로 차트 꾸미기
  • 그룹 막대 그래프: x축을 공유하여 여러 데이터를 나란히 비교
  • Tick 설정: np.arange() 또는 np.linspace()로 자동 생성 가능
  • Legend: loc='best'로 자동 최적 위치 설정

인사이트

  • 데이터 분석 결과를 시각화하면 훨씬 직관적으로 이해할 수 있다
  • 한글 폰트 설정을 잊으면 경고가 발생하고 한글이 깨질 수 있다
  • np.linspace()는 기본적으로 실수를 반환하므로 정수가 필요하면 dtype=int 지정 필요
  • 그룹 막대 그래프는 x - width/2, x + width/2로 위치를 조정하여 나란히 배치

주의사항

  • ⚠️ 한글 폰트 설정 필수: matplotlib에서 한글을 사용하려면 반드시 폰트 설정 필요
  • ⚠️ np.linspace() 실수 반환: 기본적으로 float를 반환하므로 정수가 필요하면 dtype=int 지정
  • ⚠️ y값은 필수: plt.plot(y) - y값(데이터)은 필수, x값은 선택적
  • ✅ Tick 자동 생성 권장: 데이터가 많아지면 수동 지정보다 np.arange() 사용 권장
  • ✅ Legend 자동 위치: loc='best'로 자동으로 최적의 위치 찾기

  • 차트 저장 방법 (plt.savefig())
