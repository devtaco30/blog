EST AI - OpenCV : 동영상 출력 & 캠 제어

OpenCV의 VideoCapture로 동영상 파일과 실시간 캠에서 프레임을 읽고, waitKey로 재생 속도와 종료를 제어합니다. | 좌우 반전, 원하는 순간의 이미지 캡처와 저장, 캡처한 이미지의 사분면 출력으로 마무리합니다.

📚 오늘의 학습 내용

오늘은 OpenCV로 동영상·실시간 카메라를 다루는 방법을 학습했습니다. VideoCapture로 프레임을 읽고, waitKey로 재생 속도·종료를 제어하며, 원하는 순간의 프레임을 이미지로 저장하는 흐름을 익혔습니다.

1️⃣ 동영상 출력

VideoCapture

  • 동영상 파일: cv2.VideoCapture('./data/dogs.mp4')
  • 실시간 캠: cv2.VideoCapture(0) — 0은 기본 캠. 환경에 따라 0이 iPhone 캠일 수 있으니 연결 상태에 유의.

재생 루프

  • cap을 연 다음에는 반복문으로 프레임을 계속 읽어야 “재생”됨.
  • ch, frame = cap.read() — ch: 성공 여부(True/False), frame: 읽은 이미지(프레임)
  • ch == False이면 끝(파일 끝 또는 읽기 실패)이므로 break.

waitKey

  • cv2.waitKey(millisec): 지정한 ms만큼 대기하고, 그동안 눌린 키의 아스키 코드 반환. 안 눌리면 -1.
  • 동영상: waitKey(33) → 약 30fps 간격으로 다음 프레임.
  • key == ord('q')로 'q' 입력 시 루프 종료하는 패턴 사용.

정리

  • 루프 종료 후 cap.release()로 메모리 해제, cv2.destroyAllWindows(), 필요 시 cv2.waitKey(1) 한 번 더 호출.

2️⃣ 실시간 캠 + 좌우 반전

  • 전면 캠은 좌우 반전으로 나오는 경우가 많음.
  • frame = cv2.flip(frame, 1) — 1: 좌우 반전, 0: 상하, -1: 둘 다.

3️⃣ 이미지 캡쳐·저장

  • 목표: 영상 재생 중 특정 키(예: 스페이스) 입력 시, 그 순간의 프레임을 이미지로 저장.
  • cv2.imwrite(path, frame) — 해당 경로에 프레임 저장.
  • 실습에서는 time.time() 등으로 파일명에 타임스탬프를 넣어 me_frame_{시간값}.png 형태로 저장.

4️⃣ 캡쳐한 이미지 사분면 출력

  • 캡쳐된 이미지 파일명이 시간값을 포함하므로, 정규표현식으로 파일 목록을 추출한 뒤 cv2.imread로 읽어 리스트에 담음.
  • plt.subplot 또는 배열로 쌓아서 img_arr처럼 만든 뒤, 개수에 맞춰 행/열을 정해 한 번에 imshow로 출력 — “사분면”으로 4장 등을 보여주는 실습.

💡 핵심 정리

배운 것

  • VideoCapture(경로 또는 0) → read() 루프 → imshow + waitKey로 재생·종료 제어
  • waitKey(ms): 대기 시간 + 키 입력 반환; 동영상 fps 조절
  • imwrite로 프레임 저장; 캡쳐 후 파일명 규칙으로 불러와 시각화

주의사항

  • ⚠️ cap 사용 후 반드시 cap.release() 호출
  • ⚠️ 캠 번호 0이 다른 디바이스로 잡힐 수 있음 — 환경 확인
