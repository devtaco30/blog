📚 오늘의 학습 내용

오늘은 YOLO(You Only Look Once) 의 핵심 개념과 역사를 정리하고, Ultralytics 라이브러리로 음식 이미지 분류 모델을 직접 훈련·평가하는 실습을 진행했습니다.

1️⃣ 객체 탐지란?

분류 / 위치 파악 / 객체 탐지

용어설명
Classification (분류)이미지 속 물체가 어떤 클래스인지만 판별
Localization (위치 파악)물체가 어디 있는지 바운딩 박스로 표시
Object Detection (객체 탐지)분류 + 위치 파악을 동시에 수행

2-Stage vs 1-Stage Detector

R-CNN (2-Stage)

  • 후보 영역 제안(Region Proposal) → CNN 특징 추출 → 분류 및 위치 보정 순서로 처리
  • 정확도는 높지만 속도가 치명적으로 느리고, 구조가 복잡함

YOLO (1-Stage)

  • 이미지 전체를 단 한 번만 보고 위치·클래스를 동시에 예측
  • 압도적으로 빠르고, 이미지 전체를 보기 때문에 배경 오류도 적음
  • R-CNN 대비 상대적으로 정확도가 낮다는 단점

💡 극도의 정확도가 필요하면 R-CNN, 실시간 처리가 필요하면 YOLO

2️⃣ YOLO 작동 원리

처리 흐름

1단계 — 그리드 분할 입력 이미지를 S×S 격자(Grid)로 나눔

2단계 — 동시 예측 (각 격자 셀에서)

  • Bounding Box: 위치(x, y), 크기(w, h), 신뢰도(confidence) 예측
  • 클래스 확률: 해당 셀의 객체 종류 확률 예측

3단계 — 후처리 (NMS, Non-Maximum Suppression)

  • 신뢰도 낮은 박스 제거
  • 중복된 박스 중 점수가 가장 높은 것만 남김

YOLO 버전 히스토리

버전연도핵심 변경
v120161-Stage 탐지 최초 도입, S×S 그리드 예측
v22017앵커 박스(Anchor Box) 도입
v32018Darknet-53 백본, 3-scale 예측으로 소형 객체 인식 개선
v42020.4CSPDarknet53, Mosaic 데이터 증강
v52020.6Ultralytics, PyTorch 기반으로 전환
v82023.1앵커 프리(Anchor-free), Decoupled Head, 통합 프레임워크
v112024.9탐지·분할·포즈·추적·분류 멀티태스킹 SOTA

모델 크기별 트레이드오프

모델명 뒤에 붙는 알파벳(n < s < m < l < x)이 크기를 나타냄

구분작은 모델 (n, s)큰 모델 (l, x)
속도✅ 빠름, 경량❌ 느림, 고사양 필요
정확도❌ 낮음✅ 높음
용도실시간 영상, 모바일의료·연구 고정밀 분석

3️⃣ YOLO 평가 지표

지표설명
IoU예측 박스와 실제 박스의 겹침 비율 (0~1, 1=완벽 일치)
Precision예측한 객체 중 실제 객체 비율
Recall실제 객체 중 예측 성공 비율
F1Precision과 Recall의 조화 평균
mAP여러 클래스의 AP 평균 — 모델 전반 정확도 종합 평가의 대표 지표
AP50 / AP75IoU 0.5 / 0.75 기준 AP (AP75가 더 엄격)
FPS초당 처리 프레임 수 — 실시간 응용 속도 지표
Inference Time단일 이미지 처리 시간 (ms)

상황별 활용

  • 전체 정확도 비교 → mAP
  • 위치 예측 정밀도 → AP50 / AP75
  • 클래스별 오탐·미탐 분석 → Precision / Recall / F1
  • 실시간 처리 가능 여부 → FPS / Inference Time

4️⃣ YOLO 이미지 분류 실습

데이터셋 구성

  • 출처: Kaggle food41 (5개 음식 클래스 × 1,000장)
  • 클래스: apple_pie, donuts, hamburger, onion_rings, pizza
  • 분할: 훈련 640장 / 검증 160장 / 평가 200장 (클래스당)

Ultralytics는 아래 폴더 구조를 요구함:

food_for_yolo/
├── train/
│   ├── apple_pie/
│   └── ...
├── valid/
└── test/

모델 훈련

모델: YOLOv8n-cls (nano 크기, 분류 전용, 약 1.4M 파라미터)

from ultralytics import YOLO

model = YOLO('yolov8n-cls.pt')  # 사전학습 가중치 로드

results = model.train(
    data='./data/food_for_yolo/',
    epochs=100,
    imgsz=224,
    device='mps'  # Apple Silicon
)

훈련 중 끊기면 last.pt로 이어서 학습 가능:

model = YOLO('runs/classify/train/weights/last.pt')
model.train(..., resume=True)

최종 평가는 best.pt(검증 성능 최고 시점의 가중치)로 진행.

평가 결과

지표값
Top-1 Accuracy94.2%
Top-5 Accuracy100%
Inference Time15.0ms / 이미지 (CPU)

5개 클래스 음식 분류에서 Top-1 94.2%, Top-5 100%를 달성.

💡 핵심 정리

배운 것

  • YOLO = 1-Stage Detector: 그리드 분할 → 위치·클래스 동시 예측 → NMS 후처리
  • R-CNN(정확도 우선) vs YOLO(속도 우선) — 용도에 맞게 선택
  • 모델 크기 n < s < m < l < x: 작을수록 빠르고 가볍고, 클수록 정확
  • Ultralytics 기본 흐름: model.train() → model.val() → model.predict()

주의사항

  • ⚠️ Ultralytics 분류 데이터는 train/valid/test 아래에 클래스명 폴더가 있어야 함
  • ⚠️ resume=True는 반드시 last.pt 경로를 정확히 지정해야 함
  • ✅ 최종 평가·추론에는 last.pt가 아닌 best.pt 사용
