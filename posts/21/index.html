reshape()로 배열 형태를 바꾸는 방법과 인덱싱·슬라이싱이 결과의 차원을 어떻게 다르게 만드는지 확인합니다. | 불리언 인덱싱, & 와 and의 차이, 통계 함수, 파일 입출력을 거쳐 실제 데이터 분석 예제까지 갑니다.

📋 배열 형태 변경: reshape()

기능:

  • 기존 배열의 형태를 변경하여 새로운 차원의 배열 생성
  • 중요: 기존 배열의 원소 개수와 맞아떨어지는 형태로만 변경 가능

사용법:

arr = np.arange(12)           # 1차원: [0, 1, 2, ..., 11]
arr = arr.reshape(3, 4)       # 2차원: 3행 4열로 재배치

주의사항:

  • 원소 개수가 맞지 않으면 ValueError 발생
  • 예: 12개 원소를 reshape(3, 5)로 변경 불가 (3×5=15개 필요)

📋 Indexing과 Slicing

Indexing (인덱싱):

  • 특정 위치의 요소만 가져옴
  • 결과: 해당 요소의 값 (차원이 감소)

Slicing (슬라이싱):

  • 특정 범위의 배열 형태로 가져옴
  • 결과: 배열의 형태를 유지 (차원 유지)

예시:

arr = np.array([[1, 2, 3], [4, 5, 6]])

arr[0]        # indexing: [1, 2, 3] (1차원 배열)
arr[0:1]      # slicing: [[1, 2, 3]] (2차원 배열 유지)

스칼라 값 대입:

  • 배열의 특정 부분에 스칼라 값을 대입하면 자동으로 확장되어 적용됨
  • 예: arr[0] = 1 → 첫 번째 행이 모두 1로 변경 [[1, 1, 1], [4, 5, 6]]
  • 제약: 대입하는 배열의 크기가 맞아야 함 (기존 개수와 일치해야 함)

📋 2차원 배열에서의 데이터 접근

행과 열 구분:

  • arr[행, 열] 형태로 접근
  • 콤마(,)로 행과 열을 구분

다양한 접근 방법:

arr = np.arange(50).reshape(5, 10)

arr[:2, :6]        # 처음 2행, 처음 6열
arr[:, 0]          # 모든 행의 0번 열 (1차원 배열)
arr[:, 0:1]        # 모든 행의 0번 열 (2차원 배열 유지)
arr[0::2, 0]       # 0번 열에서 0부터 2칸씩 (0, 2, 4행)
arr[[0, 2, 4], 0]  # 0, 2, 4행의 0번 열 (fancy indexing)

Slicing 방법:

  • 리스트 형태: arr[1:, [1, 3, 5]]
  • range 형태: arr[1:, range(1, 6, 2)]
  • 슬라이싱 형태: arr[1:, 1:6:2]
  • slice 객체: arr[1:, slice(1, 6, 2)]

전치 (Transpose):

  • arr.T: 행과 열을 바꾸는 전치 연산
  • 예: (3, 6) 형태 → (6, 3) 형태로 변경

📋 랜덤 배열 생성

np.random.randint():

  • np.random.randint(start, end, size=크기): 지정 범위의 랜덤 정수 배열 생성
  • start 이상 end 미만의 정수 중 랜덤 선택
np.random.randint(0, 10, size=8)  # 0 이상 10 미만의 정수 8개

📋 Boolean Indexing (불리언 인덱싱)

개념:

  • 특정 조건에 맞는 값들을 찾아내고 싶을 때 사용
  • 인덱스 번호 대신 조건식을 입력

사용법:

arr = np.array([21, 31, 41, 51, 61, 70])

# 조건식 생성
arr >= 50                    # [False, False, False, True, True, True]
arr % 2 == 0                 # [False, False, False, False, False, True]

# Boolean indexing으로 값 가져오기
arr[arr >= 50]               # 조건에 맞는 값만 추출: [51, 61, 70]

다중 조건:

  • 여러 조건을 결합할 때는 & (비트 연산자) 사용
  • 주의: and는 사용 불가 (에러 발생)
# 30 이상이고 60 이하인 값 찾기
(arr >= 30) & (arr <= 60)    # ✅ 올바른 방법
(arr >= 30) and (arr <= 60)  # ❌ ValueError 발생

값 변경:

  • Boolean indexing으로 찾은 위치에 직접 값을 대입 가능
arr = np.array([[6, 9, 6, 8, 7], [2, 3, 5, 4, 1]])

# 짝수를 0으로 변경
arr[arr % 2 == 0] = 0
# 결과: [[0, 9, 0, 0, 7], [0, 3, 5, 0, 1]]

📋 & vs and 차이점

💡 궁금해서 찾아본 내용: & vs and 차이점

핵심 정리:

  • NumPy 배열: &, | 사용 (요소별 연산)
  • 일반 Python 조건문: and, or 사용 (단일 값 반환)

NumPy 배열에서 and 사용 시 에러:

(arr >= 30) and (arr <= 60)  # ❌ ValueError 발생
# ValueError: The truth value of an array with more than one element is ambiguous.

올바른 사용:

(arr >= 30) & (arr <= 60)    # ✅ NumPy 배열 boolean indexing
if x > 5 and y < 10:         # ✅ 일반 Python 조건문

📋 통계 함수

기본 통계 함수:

  • 배열 메서드와 NumPy 함수 두 가지 방식 모두 사용 가능

합계:

arr.sum()      # 배열 메서드
np.sum(arr)    # NumPy 함수

평균:

arr.mean()     # 배열 메서드
np.mean(arr)   # NumPy 함수

최소값:

arr.min()      # 배열 메서드
np.min(arr)    # NumPy 함수

특징:

  • range() 객체에도 직접 적용 가능: np.mean(range(10))
  • 다차원 배열의 경우 전체 원소에 대해 계산

📋 NumPy 파일 입출력

파일 읽기: np.genfromtxt()

  • 텍스트 파일을 배열로 읽어오는 함수
  • 구분자(delimiter)와 데이터 타입(dtype) 지정 가능
data = np.genfromtxt('파일경로', delimiter='::', dtype='int')

파일 저장: np.savetxt()

  • 배열을 텍스트 파일로 저장
  • 구분자와 출력 형식(fmt) 지정 가능
np.savetxt('파일경로', data, delimiter='::', fmt='%d')

출력 형식 설정: np.set_printoptions()

  • 배열 출력 시 형식 조정
  • suppress=True: 과학적 표기법 억제
  • precision=2: 소수점 자리수 지정
np.set_printoptions(suppress=True, precision=2)

📋 NumPy 실전 데이터 분석

💡 실제 데이터를 불러와서 분석하는 첫 실습 - 데이터 불러오기부터 인덱싱, 필터링, 집계까지 전체 흐름을 경험

1. 데이터 불러오기 및 구조 파악

# 파일에서 데이터 읽기
movie = np.genfromtxt('../data/ratings.dat', delimiter='::', dtype='int')

# 데이터 구조: [사용자ID, 영화ID, 평점, 시간]
# 각 열의 의미를 명확히 이해하는 것이 중요

2. 데이터 속성 확인

movie.shape   # (1000209, 4) - 행과 열의 개수
movie.ndim    # 2 - 차원 수
movie.size    # 4000836 - 전체 요소 수

3. 2차원 배열에서 특정 열 추출

# 모든 행의 특정 열만 가져오기
ratings = movie[:, 2]  # 모든 행의 2번 열 (평점 데이터)

# 특정 행의 특정 열
user_data = movie[movie[:, 0] == 1]  # 사용자 ID가 1인 모든 행
user_ratings = user_data[:, 2]       # 해당 사용자의 평점만

4. Boolean Indexing으로 조건부 데이터 추출

# 특정 사용자의 평점 추출
user_ratings = movie[movie[:, 0] == user_id][:, 2]

# 특정 영화의 평점 추출
movie_ratings = movie[movie[:, 1] == movie_id][:, 2]

# 조건에 맞는 행만 추출
high_rating_users = avg_ratings[avg_ratings[:, 1] >= 4]

5. 그룹별 집계 (Grouping)

# 각 사용자별 평균 평점 계산
ids = np.unique(movie[:, 0])  # 중복 제거된 사용자 ID 목록

avg_ratings = []
for id in ids:
    user_ratings = movie[movie[:, 0] == id][:, 2]
    avg_ratings.append([id, user_ratings.mean()])
avg_ratings = np.array(avg_ratings)

# 각 영화별 평균 평점 계산 (동일한 패턴)
movie_ids = np.unique(movie[:, 1])
each_movie_avg = []
for movie_id in movie_ids:
    movie_ratings = movie[movie[:, 1] == movie_id][:, 2]
    each_movie_avg.append([movie_id, movie_ratings.mean()])

6. 중복 제거: np.unique()

# 배열에서 중복된 값을 제거한 배열 반환 (정렬됨)
unique_ids = np.unique(movie[:, 0])  # 고유한 사용자 ID 목록
unique_movies = np.unique(movie[:, 1])  # 고유한 영화 ID 목록

7. 조건부 결과 필터링

# 평균 평점이 4점 이상인 사용자만 추출
high_rating_users = avg_ratings[avg_ratings[:, 1] >= 4][:, 0]

핵심 학습 포인트:

  • 2차원 배열에서 [행, 열] 형태로 접근하는 방법
  • Boolean indexing으로 조건에 맞는 데이터만 추출
  • 반복문과 Boolean indexing을 결합한 그룹별 집계
  • 데이터 구조를 이해하고 적절한 인덱싱으로 원하는 데이터 추출

💡 핵심 정리

📖 주요 포인트

  • reshape(): 배열 형태 변경 시 원소 개수가 맞아야 함
  • Indexing vs Slicing: indexing은 요소만, slicing은 배열 형태 유지
  • 2차원 접근: arr[행, 열] 형태로 콤마로 구분
  • Boolean Indexing: 조건식으로 원하는 값만 추출하거나 변경 가능
  • & vs and: NumPy 배열에서는 & 필수, 일반 조건문에서는 and 사용
  • 통계 함수: 메서드와 함수 두 가지 방식 모두 지원
  • 파일 입출력: genfromtxt(), savetxt()로 데이터 읽기/쓰기
  • 중복 제거: np.unique()로 고유값 추출
  • 실전 분석: 데이터 불러오기부터 집계까지 전체 흐름 이해

⚠️ 주의사항

  • reshape() 시 원소 개수가 맞지 않으면 에러 발생
  • Boolean indexing에서 다중 조건은 & 사용 (and 사용 불가)
  • Broadcasting 시 대입하는 배열의 크기가 맞아야 함
  • Indexing은 차원이 감소하고, Slicing은 차원이 유지됨

✅ 권장 사항

  • Boolean indexing으로 조건에 맞는 데이터를 효율적으로 처리
  • 2차원 이상 배열 접근 시 콤마로 행/열 구분하여 명확하게 표현
  • NumPy 배열 연산 시 &, | 사용 (논리 연산자와 구분)
  • 통계 함수는 상황에 맞게 메서드 또는 함수 선택
  • 데이터 구조를 먼저 파악한 후 적절한 인덱싱 방법 선택
