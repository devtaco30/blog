📋 Series 복합 조건 필터링

데이터 예시: 각 도시별 인구수를 Series로 표현한 데이터를 사용합니다.

# 도시별 인구수 Series 생성
pop = pd.Series([9901232, 3441423, 2891323, 2462123], index=['서울', '부산', '인천', '대구'])

논리 연산자 우선순위 주의:

  • 복합 조건 사용 시 괄호 필수
  • &, | 연산자는 비교 연산자보다 우선순위가 높음
# ❌ 잘못된 예 (우선순위 문제)
pop > 2500000 & pop < 5000000

# ✅ 올바른 예 (괄호 필수)
pop[(pop > 2500000) & (pop < 5000000)]
# 인구가 250만 초과, 500만 미만인 도시 필터링

Series 데이터 조작:

  • 데이터 변경: 기존 index로 값 덮어쓰기 → pop['부산'] = 3400000
  • 데이터 추가: 새로운 index로 추가 → pop['대전'] = 2400000
  • 데이터 삭제: del pop['서울']

💡 궁금해서 찾아본 내용: Series 값 포맷팅

Series도 DataFrame과 동일하게 style.format()을 사용할 수 있습니다:

pop.style.format('{:,}')  # 천 단위 구분 기호 추가
  • '{:,}': 천 단위마다 쉼표(,)를 추가하는 포맷 지정자
  • DataFrame의 style.format()과 동일한 방식

📋 DataFrame 생성 및 기본 구조

데이터 예시: 도시별 인구수를 연도별로 비교하는 데이터를 DataFrame으로 표현합니다.

생성 방법:

# Dictionary 방식 (권장)
# 각 도시를 컬럼으로, 연도를 행으로 표현
data = {'서울': [9904312, 9631482], '부산': [3448737, 3393191]}
pop = pd.DataFrame(data, index=['2015', '2010'])
# 결과: 행=연도(2015, 2010), 열=도시(서울, 부산)

# List 방식
# 데이터를 리스트로 제공하고, 컬럼명과 인덱스를 별도 지정
data = [[9904312, 3448737], [9631482, 3393191]]
pop = pd.DataFrame(data, index=['2015', '2010'], columns=['서울', '부산'])

주요 속성:

  • df.values, df.index, df.columns, df.dtypes, df.shape

주요 메서드:

  • df.T: 전치 (행과 열 위치 변경)
  • df.rename(): 이름 변경 (기본적으로 원본 변경 안 함, 반환값 받아야 함)
  • df.drop(): 행/열 삭제 (axis=0: 행, axis=1: 열)

📋 DataFrame 데이터 조작

데이터 예시: 도시별 인구수 DataFrame (pop)을 기준으로 설명합니다.

컬럼 값 변경:

pop['2015'] = [9900000, 3450000, ...]  # 기존 컬럼인 '2015' 연도 데이터 수정

컬럼 추가:

pop['2005'] = [1, 2, 3, 4]  # 새로운 연도 '2005' 컬럼 추가

컬럼 삭제:

del pop['2005']  # 또는
pop.drop('2005', axis=1)  # 열 삭제

행 삭제:

pop.drop('서울', axis=0)  # 도시 행 삭제

데이터 병합:

pd.concat([df1, df2, ...], axis=0)  # 행 방향 (세로로 붙이기)
pd.concat([df1, df2, ...], axis=1)  # 열 방향 (가로로 붙이기)
pd.concat({'컬럼명1': series1, '컬럼명2': series2}, axis=1)  # Dictionary로 컬럼명 지정

💡 궁금해서 찾아본 내용: del vs drop

  • del: Python 내장 키워드, DataFrame에서 컬럼만 삭제 가능
  • drop: Pandas 메서드, 행/열 모두 삭제 가능
    • axis=0: 행 삭제 (기본값)
    • axis=1: 열 삭제
    • inplace=False: 기본값, 원본 변경 안 함

📋 DataFrame 연산

데이터 예시: 도시별 인구수 DataFrame (pop)을 기준으로 설명합니다.

  • 스칼라 연산: pop + 1000000 (모든 도시의 인구수에 100만명씩 더하기)
  • DataFrame 간 연산: pop2 - pop (일치하는 행/컬럼끼리만 연산)
  • NaN 처리: 일치하지 않는 행/컬럼은 NaN으로 처리

📋 DataFrame 인덱싱/슬라이싱

원본 데이터 (score_data):

    1반  2반  3반  4반
수학  45  44  73  39
영어  76  92  45  69
국어  47  92  45  69
사회  92  81  85  40
과학  11  79  47  26

기본 인덱싱/슬라이싱:

  • 컬럼 인덱싱: score_data['1반'] (단일), score_data[['1반', '3반']] (여러 개)
  • 행 슬라이싱: score_data['수학':'국어'] (이름), score_data[0:1] (위치)

⚠️ 핵심 규칙 (외우기)

컬럼은 인덱싱, 행은 슬라이싱

  • 컬럼: df['컬럼명'] 또는 df[['컬럼1', '컬럼2']] (인덱싱)
  • 행: df['행1':'행2'] 또는 df[0:1] (슬라이싱)

loc (이름으로 검색):

  • score_data.loc[행, 열] 형식
  • score_data.loc['과학', :] 또는 score_data.loc['과학']: '과학' 행, 모든 열
  • score_data.loc['과학', '4반']: '과학' 행, '4반' 열
  • score_data.loc[:, '4반']: 모든 행, '4반' 열
  • score_data.loc[:, ['4반', '1반']]: 여러 컬럼 (리스트 형태)

iloc (숫자로 검색):

  • score_data.iloc[행, 열] 형식
  • score_data.iloc[4, :] 또는 score_data.iloc[4]: 4번째 행, 모든 열
  • score_data.iloc[4, 3]: 4번째 행, 3번째 열
  • score_data.iloc[2:4, 2]: 2~3번째 행, 2번째 열
  • score_data.iloc[[0,3], :2]: 0번째와 3번째 행, 처음 2개 열
  • score_data.iloc[2:4, [1,3]]: 2~3번째 행, 1번째와 3번째 열

⚠️ loc vs iloc 비교

구분lociloc
접근 방식이름(라벨)으로 접근위치(번호)로 접근
사용 시기행/열 이름을 알고 있을 때행/열 위치(번호)로 접근할 때
성능이름을 찾는 과정 필요직접 숫자로 접근, 대용량 데이터에 효율적
예시df.loc['수학', '1반']df.iloc[0, 0]

💡 열의 범위가 전체일 경우 생략 가능 (iloc[4] = iloc[4, :]), 행은 생략 불가

📋 DataFrame 집계 함수

sum() - 합계:

df.sum(axis=0)  # 행 방향 합계 (아래로) → 각 열의 합
df.sum(axis=1)  # 열 방향 합계 (우측으로) → 각 행의 합

mean() - 평균:

df.mean(axis=0)  # 행 방향 평균 → 각 열의 평균
df.mean(axis=1)  # 열 방향 평균 → 각 행의 평균
# skipna=True: 기본값, 결측치 제외

실제 사용 예시:

# 각 과목별 총합
score_data['총합'] = score_data[['1반', '2반', '3반', '4반']].sum(axis=1)

# 각 과목별 평균
score_data['평균'] = score_data[['1반', '2반', '3반', '4반']].mean(axis=1)

# 각 반별 총합
score_data.loc['총합', :] = score_data.loc[:, '1반':'4반'].sum(axis=0)

💡 결측치(NaN) 처리:

  • sum(): 모든 값이 NaN이어도 결과는 0.0 (NaN 아님)
  • mean(): 모든 값이 NaN이면 결과는 NaN
  • skipna=True(기본값): 결측치를 제외하고 계산

value_counts():

  • 특정 컬럼의 유니크값과 개수 출력
df['컬럼명'].value_counts()  # 단일 컬럼
df[['컬럼1', '컬럼2']].value_counts()  # 여러 컬럼 조합

📋 실습: 범죄 데이터 분석

목표: 2015~2017 광주광역시 범죄현황 데이터를 이용, 전년 대비 지역별 범죄 증감률 구하기

증감률 공식:

증감률 = (금년 발생건수 - 작년 발생건수) / 작년 발생건수 * 100 (%)

데이터 구조:

            구분  살인  강도  강간·강제추행    절도     폭력
관서명                                         
광주지방경찰청계  발생건수  18  44      750  8425   9593
광주지방경찰청계  검거건수  18  47      758  5409   8301
광주지방경찰청계  검거인원  17  66      776  3433  11774
...

주요 단계:

  1. 데이터 로드:

    pd.read_csv({경로}, index_col='관서명', encoding='euc-kr')

    주요 파라미터:

    • encoding: 문자 인코딩 방식 ('euc-kr', 'utf-8')
      • 문자와 바이트 간의 매핑을 정의하는 방법
      • 파일을 읽을 때 저장된 인코딩과 동일한 방식으로 읽어야 함
    • index_col: 인덱스로 사용할 컬럼 지정

  2. 데이터 전처리:

    • 중복 인덱스 확인: 같은 관서명이 여러 번 나타남 (구분 컬럼으로 구분됨)
    • 불일치 데이터 제거: df_2017.drop('광주지방경찰청', inplace=True)
    • Set 연산으로 차이 확인: set(df_2017.index) - set(df_2015.index)

  3. 총계 추가 및 발생건수 추출:

    # 각 관서별 범죄 총계
df_2015['총계'] = df_2015.loc[:, '살인':'폭력'].sum(axis=1)
df_2016['총계'] = df_2016.loc[:, '살인':'폭력'].sum(axis=1)
df_2017['총계'] = df_2017.loc[:, '살인':'폭력'].sum(axis=1)

# 발생건수만 추출
df_2015_sum_of_case = df_2015.loc[df_2015['구분'] == '발생건수', '총계']
df_2016_sum_of_case = df_2016.loc[df_2016['구분'] == '발생건수', '총계']
df_2017_sum_of_case = df_2017.loc[df_2017['구분'] == '발생건수', '총계']

  4. 증감률 계산:

    delta_15_16 = (df_2016_sum_of_case - df_2015_sum_of_case) / df_2015_sum_of_case * 100
delta_16_17 = (df_2017_sum_of_case - df_2016_sum_of_case) / df_2016_sum_of_case * 100

  5. 데이터 병합 (pd.concat):

    total_df = pd.concat({
    '2015년 총계': df_2015_sum_of_case,
    '2015->2016 증감률': delta_15_16,
    '2016년 총계': df_2016_sum_of_case,
    '2016->2017 증감률': delta_16_17,
    '2017년 총계': df_2017_sum_of_case,
}, axis=1)

  6. 스타일 포맷팅:

    # 특정 컬럼만 포맷 적용
total_df.style.format({
    '2015->2016 증감률': '{:.2f}%',
    '2016->2017 증감률': '{:.2f}%',
})

💡 핵심 정리

📖 주요 포인트

  • DataFrame: Series의 모음, 2차원 데이터 구조
  • 생성: Dictionary 또는 List 사용
  • 인덱싱 방식: 컬럼은 인덱싱, 행은 슬라이싱
  • loc: 이름으로 행/열 동시 접근
  • iloc: 숫자(위치)로 행/열 동시 접근, 대용량 데이터에 효율적
  • 집계 함수: sum(), mean() - axis 파라미터로 방향 지정
  • value_counts(): 유니크값과 개수 출력
  • pd.concat(): DataFrame/Series 병합
    • axis=0: 행 방향으로 합치기 (세로로 붙이기)
    • axis=1: 열 방향으로 합치기 (가로로 붙이기)
    • Dictionary로 전달하면 컬럼명 지정 가능
  • style.format(): DataFrame 표시 포맷 지정

⚠️ 주의사항

  • 논리 연산자 우선순위: &, | 사용 시 괄호 필수
  • rename(): 기본적으로 원본 변경 안 함, 할당 필요
  • DataFrame 연산: 일치하지 않는 행/컬럼은 NaN 처리
  • 여러 컬럼 선택: 리스트 형태로 전달해야 함

✅ 권장 사항

  • DataFrame 생성 시 Dictionary 방식이 더 직관적
  • 데이터 삭제 시 drop() 사용 권장 (행/열 모두 가능)
  • 행과 열을 동시에 접근할 때는 loc(이름) 또는 iloc(위치) 사용
  • 집계 함수 사용 시 axis 파라미터 명확히 지정
