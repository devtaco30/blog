📚 오늘의 학습 내용

📋 Dictionary (딕셔너리)

기본 개념:

  • key:value가 한 쌍으로 이루어진 자료구조
  • key는 immutable (불변), value는 mutable (가변)
  • 순서가 없는 집합 (Python 3.7+ 부터는 삽입 순서 유지, 하지만 인덱스로 접근 불가)

기본 문법:

dict1 = {'name': '박종혁', 'age': 20, 'phone': '010-1234-1234'}
print(dict1)  # {'name': '박종혁', 'age': 20, 'phone': '010-1234-1234'}
print(len(dict1))  # 3 (key:value 쌍의 개수)

Dictionary 순회:

# key 값만 출력
for i in dict1:
    print(i)  # name, age, phone

# value 값 출력
for i in dict1:
    print(dict1[i])  # 박종혁, 20, 010-1234-1234

Dictionary 값 변경 및 추가:

# 값 변경
dict1['age'] = 21

# 값 추가
dict1['birth'] = '2/13'

Dictionary 값 삭제:

# 특정 키-값 쌍 삭제
del dict1['age']

# 전체 비우기
dict1.clear()  # {}

Dictionary 메서드:

# keys() - 모든 키 반환
print(dict1.keys())  # dict_keys(['name', 'age', 'phone'])

# values() - 모든 값 반환
print(dict1.values())  # dict_values(['박종혁', 20, '010-1234-1234'])

# items() - 키-값 쌍 반환
for k, v in dict1.items():
    print(k, v)  # name 박종혁, age 20, phone 010-1234-1234

# 키 존재 확인
if 'name' in dict1:
    print('키가 존재합니다')

💡 궁금해서 찾아본 내용: Dictionary vs JSON 차이점

1. 데이터 타입 지원

  • Python Dictionary: 키는 문자열, 숫자, 튜플 등 다양한 타입 가능. 값은 모든 Python 객체 가능
  • JSON: 키는 항상 문자열만 가능. 값은 문자열, 숫자, 배열, 객체, 불리언, null만 가능

2. 사용 목적

  • Python Dictionary: Python 프로그램 내에서 데이터 저장 및 조작
  • JSON: 서로 다른 시스템 간 데이터 교환, 웹 애플리케이션에서 서버-클라이언트 간 데이터 전송

3. 변환

import json

# Dictionary → JSON (직렬화)
my_dict = {"name": "홍길동", "age": 30}
json_str = json.dumps(my_dict)

# JSON → Dictionary (역직렬화)
my_dict = json.loads(json_str)

주요 차이점 요약:

특징Python DictionaryJSON
키 타입문자열, 숫자, 튜플 등문자열만
값 타입모든 Python 객체제한적 (문자열, 숫자, 배열, 객체, 불리언, null)
사용 환경Python 프로그램 내부데이터 교환/전송

📋 Dictionary 실습 예제

학생 점수 관리:

score_dict = {'이름': ['홍길동','김철수','이영희'], '파이썬':[85,90,80], '기초통계':[100,70,90]}

# 특정 학생의 점수 찾기 (index() 사용)
idx = score_dict['이름'].index('홍길동')
py_score = score_dict['파이썬'][idx]
st_score = score_dict['기초통계'][idx]
print(f'홍길동 파이썬: {py_score}, 기초통계: {st_score}, 평균: {(py_score+st_score)/2}')

과목을 모르는 상황에서 동적 접근:

# 홍길동의 인덱스 찾기
idx = score_dict['이름'].index('홍길동')

# '이름'을 제외한 모든 키(과목)를 순회
for subject in score_dict.keys():
    if subject != '이름':
        score = score_dict[subject][idx]
        print(f'{subject}: {score}')

# 모든 과목의 평균 계산 (과목 개수를 모르는 상황)
total_score = 0
subject_count = 0
for subject in score_dict.keys():
    if subject != '이름':
        total_score += score_dict[subject][idx]
        subject_count += 1

if subject_count > 0:
    avg = total_score / subject_count
    print(f'평균: {avg}')

💡 궁금해서 찾아본 내용: Dictionary 데이터 접근의 다양한 방식

1. zip()을 사용하는 방식:

  • zip() 결과를 변수에 저장해서 재사용 가능
  • index()로 idx를 먼저 찾고 students_data[idx]로 접근

2. range()를 사용하는 방식:

  • index()로 idx를 먼저 찾고 score_dict['파이썬'][idx]로 접근

3. enumerate()를 사용하는 방식:

  • enumerate()로 인덱스와 값을 함께 순회하며 조건 확인

결론:

  • index()로 인덱스를 먼저 찾고 접근하는 방식이 가장 효율적
  • 불필요한 순회를 피할 수 있음

실습 예제: 약수 구하기 함수

def divisor(target):
    for i in range(1, target+1):
        if target % i == 0:
            print(i, end=' ')

divisor(10)  # 1 2 5 10
divisor(32)  # 1 2 4 8 16 32

💡 궁금해서 찾아본 내용: 약수 구하기 개선 방법

문제점:

  • 기존 방법은 1부터 target까지 모두 순회하므로 큰 수에서는 비효율적
  • O(n) 시간 복잡도

약수의 성질:

  • 약수는 제곱근을 기준으로 대칭적입니다
  • 예: 32의 약수는 1, 2, 4, 8, 16, 32
  • 1×32=32, 2×16=32, 4×8=32
  • 따라서 sqrt(target)까지만 확인하면 됩니다

개선 방법 1: target//2까지만 확인 (math 모듈 없이 사용 가능)

def divisor_improved1(target):
    divisors = []
    for i in range(1, target//2 + 1):
        if target % i == 0:
            divisors.append(i)
    divisors.append(target)
    print(*divisors)
  • O(n/2) 시간 복잡도
  • 기존 방법보다 2배 빠름

개선 방법 2: sqrt(target)까지만 확인 (가장 효율적)

import math

def divisor_improved2(target):
    divisors = []
    sqrt_target = int(math.sqrt(target))
    for i in range(1, sqrt_target + 1):
        if target % i == 0:
            divisors.append(i)
            if i != target // i:  # 제곱근이 아닌 경우 중복 방지
                divisors.append(target // i)
    divisors.sort()
    print(*divisors)
  • O(√n) 시간 복잡도
  • 가장 효율적

효율성 비교:

방법시간 복잡도target=10,000일 때
기존 방법O(n)10,000번 확인
방법 1O(n/2)5,000번 확인
방법 2O(√n)100번 확인

실용적인 방법 선택:

  1. math 모듈 사용 가능한 경우: sqrt(target) 방법이 가장 효율적
  2. math 모듈 사용 불가능한 경우: target//2 방법이 가장 실용적

💡 궁금해서 찾아본 내용: * 언패킹 연산자

print(*divisors)에서 *는 언패킹(unpacking) 연산자입니다.

동작 방식:

divisors = [1, 2, 4, 8, 16, 32]

# * 없이 출력
print(divisors)        # [1, 2, 4, 8, 16, 32] (리스트 전체)

# * 사용 (언패킹)
print(*divisors)       # 1 2 4 8 16 32 (요소들을 개별 인자로 전달)
# 위 코드는 아래와 동일합니다:
print(1, 2, 4, 8, 16, 32)  # 1 2 4 8 16 32

다른 예시:

numbers = [10, 20, 30]
print(*numbers)        # 10 20 30
print(*numbers, sep=',')  # 10,20,30 (구분자 지정 가능)

💡 궁금해서 찾아본 내용: 매우 큰 수에서의 가능성

장점:

  • O(√n) 시간 복잡도로 매우 효율적입니다
  • 기존 방법보다 훨씬 빠릅니다

예시 비교:

target기존 방법sqrt 방법개선율
10,00010,000번100번100배 빠름
1억 (10⁸)100,000,000번10,000번10,000배 빠름
1조 (10¹²)1,000,000,000,000번1,000,000번1,000,000배 빠름

결론:

  • 실용적인 범위(10¹² 이하)에서는 충분히 빠릅니다
  • 매우 큰 수도 가능하지만, 시간이 걸릴 수 있습니다
