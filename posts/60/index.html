📚 오늘의 학습 내용

오늘은 OpenCV 마우스 콜백으로 사용자가 클릭한 4점을 받아 **투시 변환(Perspective Transform)**을 적용해 문서를 평면처럼 펼치고, 저장된 이미지로 OCR까지 이어지는 반자동 문서 스캔 흐름을 학습했습니다.

1️⃣ 마우스 이벤트

setMouseCallback

  • cv2.setMouseCallback(window_name, on_mouse, userdata)
    • window_name: 이벤트를 받을 윈도우 이름 (먼저 cv2.namedWindow('img') 등으로 이름 지정)
    • on_mouse: 콜백 함수
    • userdata: (선택) 콜백에 넘길 데이터

콜백 시그니처

  • def on_mouse(event, x, y, flags, param):

    • event: 마우스 이벤트 종류 (예: cv2.EVENT_LBUTTONDOWN)
    • x, y: 클릭 좌표 (픽셀)
    • flags: 추가 이벤트 정보
    • param: userdata

  • 문서 스캔에서는 왼쪽 버튼 클릭 시 (x, y)를 리스트에 append해 4점을 모음.

2️⃣ 이미지 리사이즈

  • 큰 이미지는 클릭 위치 맞추기 어려우므로, 비율로 줄인 뒤 좌표를 사용.
  • scale = 0.6 → width, height 계산 후 cv2.resize(img, (width, height)).
    (나중에 투시 변환 결과도 이 (width, height)로 맞추면 일관됨.)

3️⃣ 투시 변환 (Perspective Transform)

목적

  • 찍은 문서 사진의 네 모서리를 사용자가 클릭으로 지정하면, 그 4점을 직사각형으로 매핑해 “스캔한 것처럼” 펼친 이미지를 만듦.

좌표 순서

  • src: 사용자가 클릭한 4점 — 좌상, 우상, 우하, 좌하 순서로 통일.
  • dst: 변환 후 직사각형의 4점 — 같은 순서로 [0,0], [width,0], [width,height], [0,height] 등.

행렬 생성·변환

  • cv2.getPerspectiveTransform(src, dst): 4대 4 점으로 투시 변환 행렬 생성. src, dst는 np.array(..., np.float32) 형태.
  • cv2.warpPerspective(src, matrix, dsize): 원본 이미지에 행렬을 적용해 dsize 크기의 결과 이미지 생성.
src = np.array(xy_list, np.float32)  # 클릭 4점
dst = np.array([[0,0], [width,0], [width,height], [0,height]], np.float32)
M = cv2.getPerspectiveTransform(src, dst)
warped = cv2.warpPerspective(img, M, (width, height))
cv2.imwrite('./data/warped_doc.png', warped)

4️⃣ 저장된 이미지로 OCR

  • warped_doc.png를 저장한 뒤, pytesseract 등으로 텍스트 추출.
  • 실습에서는 (1) 본문만 크롭해 OCR, (2) 전체를 scale·denoise 후 OCR 등으로 결과를 비교.
    문서가 평면에 가깝게 정렬되면 인식률이 좋아짐.

💡 핵심 정리

배운 것

  • setMouseCallback으로 클릭 좌표 수집 → 4점을 좌상·우상·우하·좌하 순으로 정렬
  • getPerspectiveTransform + warpPerspective로 투시 변환 후 imwrite 저장
  • 저장된 스캔 이미지를 OCR에 넣어 텍스트 추출

주의사항

  • ⚠️ src / dst 좌표 순서를 반드시 동일하게 (좌상→우상→우하→좌하)
  • ⚠️ 리사이즈한 이미지로 클릭했으면, 변환 결과 크기도 같은 (width, height)로 맞추는 것이 일관적
