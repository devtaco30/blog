📋 apply 함수

apply 함수란?

  • 각 요소에 특정 함수를 적용시켜주는 함수
  • Series나 DataFrame의 각 요소/행/열에 함수를 적용

Series에서 apply 사용:

import pandas as pd

pop = pd.Series([9600000, 3340000, 1480000, 2410000],
                index=['서울', '부산', '광주', '대구'])

# 벡터 연산 (자동으로 모든 요소에 적용)
pop + 100

# apply 사용 (각 요소에 개별적으로 함수 적용)
def plus_100(x):
    return x + 100

pop.apply(plus_100)
# 또는 lambda 사용
pop.apply(lambda x: x + 100)

차이점:

  • 산술 연산만 있는 함수: plus_100(pop)과 pop.apply(plus_100) 둘 다 작동함
    • plus_100(pop): pandas가 자동으로 벡터 연산 수행 (각 요소에 100 더하기)
    • pop.apply(plus_100): apply를 통해 각 요소에 개별 적용
  • 조건문이 있는 함수: apply()만 작동함
    • pop_judge_based_300(pop): 에러 발생 (Series 전체를 if 조건으로 판단 불가)
    • pop.apply(pop_judge_based_300): 정상 작동 (각 요소에 개별 적용)

조건문이 있는 함수의 경우:

def pop_judge_based_300(x):
    if x >= 3000000:
        return '많다'
    else:
        return '적다'

# ✅ apply 사용 - 각 요소에 개별 적용
pop.apply(pop_judge_based_300)

# ❌ apply 미사용 - 에러 발생!
# pop_judge_based_300(pop)  # ValueError: The truth value of a Series is ambiguous

⚠️ 주의: 조건문이 있는 함수는 반드시 apply()를 사용해야 합니다. Series 전체를 함수에 전달하면 if 문에서 boolean Series를 판단할 수 없어 에러가 발생합니다.

📋 lambda 함수

lambda 함수란?

  • 익명함수 (잠깐 사용할 함수)
  • apply와 함께 자주 사용

사용 예시:

# 포맷팅
pop.apply(lambda x: f'{x:,}')  # 천 단위 구분 기호 추가

# 조건문과 함께 사용
pop.apply(lambda x: '많다' if x >= 3000000 else '적다')

📋 DataFrame에서 apply 사용

기본 사용법:

# 데이터 로드 (index_col로 '과목'을 인덱스로 설정)
score_data = pd.read_csv('../data/score.csv', encoding='euc-kr', index_col='과목')

# 각 열에 함수 적용 (기본)
score_data.apply(lambda x: x + 8)  # 모든 점수에 8점 추가

# 각 행에 함수 적용
score_data.apply(lambda row: row.max(), axis=1)  # 과목별 최고 점수

이중 apply() 사용:

# 60점 이상이면 Pass, 미만이면 Fail
score_data.apply(lambda col: col.apply(lambda x: 'Pass' if x >= 60 else 'Fail'))

이중 apply()가 필요한 이유:

  1. 첫 번째 apply: DataFrame의 각 열(컬럼)에 적용 → 각 열이 Series로 전달됨

    • 열 전체(Series)에는 직접 boolean 조건을 적용할 수 없음

  2. 두 번째 apply: 각 열(Series)의 각 요소에 적용 → 각 점수에 조건 적용

    • 각 점수에 대해 'Pass'/'Fail' 조건을 적용할 수 있음

정리:

  • 첫 번째 apply: DataFrame → 각 열(Series) 추출
  • 두 번째 apply: 각 열(Series) → 각 요소에 조건 적용

📋 groupby와 집계 함수

groupby란?

  • 특정 열 기준으로 그룹화
  • SQL의 GROUP BY와 유사한 개념
  • 집계 함수와 함께 사용해야 결과를 확인할 수 있음 (groupby 객체만으로는 출력이 보이지 않음)

SQL과의 비교:

-- SQL
SELECT category, AVG(cty) 
FROM mpg 
GROUP BY category;

# pandas
mpg[['category', 'cty']].groupby('category').mean()

기본 사용법:

# 카테고리별 cty 평균
cty_mean = mpg[['category', 'cty']].groupby('category').mean()
cty_mean.sort_values('cty', ascending=False)

# 회사별 hwy 평균 (상위 3개)
mpg[['manufacturer', 'hwy']].groupby('manufacturer').mean().sort_values('hwy', ascending=False).head(3)

size() vs count():

# 회사별 compact 차종 수 내림차순 정렬

# 방법 1: size() 사용 (권장 - 더 직관적)
# size(): 그룹의 모든 행 수를 반환 (NaN 포함) → Series 반환
mpg[mpg['category'] == 'compact'].groupby('manufacturer').size().sort_values(ascending=False)

# 방법 2: count() 사용 (컬럼 지정) - Series 반환
# groupby() 뒤에 ['model'] 같이 컬럼을 지정하면 Series 반환
mpg[mpg['category'] == 'compact'].groupby('manufacturer')['model'].count().sort_values(ascending=False)

# 방법 3: count() 사용 (컬럼 지정 없이) - DataFrame 반환
# DataFrame이므로 sort_values()에 by 파라미터 필수!
mpg[mpg['category'] == 'compact'][['manufacturer', 'category']].groupby('manufacturer').count().sort_values(by='category', ascending=False)

차이점 정리:

구분size()count() (컬럼 지정)count() (컬럼 지정 없이)
반환 타입SeriesSeriesDataFrame
컬럼 지정불필요필요 (['model'])불필요
결측치 처리NaN 포함NaN 제외NaN 제외
sort_values()sort_values(ascending=False)sort_values(ascending=False)sort_values(by='컬럼명', ascending=False)

⚠️ 주의:

  • 결측치(NaN)가 있는 경우: size()는 결측치를 포함한 전체 행 수 반환, count()는 결측치를 제외한 행 수 반환
  • count()를 컬럼 지정 없이 사용하면 DataFrame 반환 → sort_values()에 by 파라미터 필수!

📋 다중 조건 필터링

특정 제조사들의 데이터만 추출하기:

  • toyota, ford, audi, hyundai, honda

방법 1: pd.concat() 사용

hw_method_1 = pd.concat([
    mpg[mpg['manufacturer'] == 'toyota'],
    mpg[mpg['manufacturer'] == 'ford'],
    mpg[mpg['manufacturer'] == 'audi'],
    mpg[mpg['manufacturer'] == 'hyundai'],
    mpg[mpg['manufacturer'] == 'honda']
], axis=0)

방법 2: 다중 조건 (| 연산자)

# ⚠️ 각 조건을 괄호로 묶어야 함!
hw_method_2 = mpg[
    (mpg['manufacturer'] == 'toyota') | 
    (mpg['manufacturer'] == 'ford') | 
    (mpg['manufacturer'] == 'audi') | 
    (mpg['manufacturer'] == 'hyundai') | 
    (mpg['manufacturer'] == 'honda')
]

⚠️ 주의: pandas에서 | 연산자를 사용할 때는 각 조건을 괄호로 묶어야 합니다. 괄호 없이 사용하면 연산자 우선순위로 인해 에러가 발생합니다.

방법 3: isin() 사용 (권장)

# 가장 간결하고 읽기 쉬움
hw_method_3 = mpg[mpg['manufacturer'].isin(['toyota', 'ford', 'audi', 'hyundai', 'honda'])]

💡 핵심 정리

배운 것

  • apply 함수: 각 요소에 특정 함수를 적용
  • lambda 함수: 익명함수, apply와 함께 자주 사용
  • 이중 apply(): DataFrame의 각 열에 apply → 각 열(Series)의 각 요소에 apply
  • groupby: 특정 열 기준으로 그룹화, 집계 함수와 함께 사용
  • size() vs count(): size()는 Series 반환, count()는 컬럼 지정 여부에 따라 Series/DataFrame 반환
  • 다중 조건 필터링: isin(), pd.concat(), 다중 조건 (| 연산자)

인사이트

  • 조건문이 있는 함수는 반드시 apply()를 사용해야 한다 (Series 전체를 전달하면 에러 발생)
  • 이중 apply()는 DataFrame의 각 열을 Series로 추출한 후, 각 요소에 조건을 적용하기 위해 필요
  • size()와 count()는 결측치 처리 방식이 다르므로 상황에 맞게 선택해야 함
  • isin()이 다중 조건 필터링에서 가장 간결하고 읽기 쉬움

주의사항

  • ⚠️ 조건문이 있는 함수는 apply() 필수: Series 전체를 함수에 전달하면 if 문에서 에러 발생
  • ⚠️ 다중 조건에서 괄호 필수: | 연산자 사용 시 각 조건을 괄호로 묶어야 함
  • ⚠️ count() 반환 타입 주의: 컬럼 지정 없이 사용하면 DataFrame 반환 → sort_values()에 by 파라미터 필수
  • ⚠️ size() vs count(): 결측치가 있으면 결과가 다를 수 있음 (size는 NaN 포함, count는 NaN 제외)
  • ✅ isin() 권장: 다중 조건 필터링에서 가장 간결하고 읽기 쉬움
