1️⃣ 활성화 함수(Activation Function)

활성화 함수의 개념

활성화 함수란?

  • 신경망은 한 계층의 신호를 다음 계층으로 그대로 전달하지 않고 활성화 함수를 거친 후에 전달함
  • 사람의 신경망 속 뉴런들도 모든 자극을 다 다음 뉴런으로 전달하는 것이 아니라 역치 이상의 자극만 전달하게 됨
  • 활성화 함수는 이런 부분까지 사람과 유사하게 구현하여 사람처럼 사고하고 행동하는 인공지능 기술을 실현하기 위해 도입됨
  • 또한 선형모델을 기반으로 하는 딥러닝 신경망에서 분류 문제를 해결하기 위해서 비선형 활성화 함수가 필요함

문제 유형에 따른 활성화 함수

유형출력층 활성화 함수손실함수

2진 분류sigmoid (로지스틱 함수)binary_crossentropy
다중 분류softmax (소프트맥스 함수)categorical_crossentropy

2️⃣ 주요 활성화 함수

1. Linear Function (선형 함수 = 항등 함수)

용도: 회귀 문제

특징:

  • h(x)=xh(x) = xh(x)=x
  • 입력값을 그대로 출력
  • 비선형 변환이 없어 다층 구조의 효과를 살릴 수 없음

중간층에 사용 시 문제:

  • 중간층에 선형 함수를 사용하면 다층 구조의 효과를 살릴 수 없음
  • 여러 층을 쌓아도 결국 선형 결합만 반복됨

2. Step Function (계단 함수)

용도: 분류의 초기 활성화 함수

특징:

h(a)={0(a≤0)1(a>0)h(a) = \begin{cases} 0 & (a \leq 0) \\ 1 & (a > 0) \end{cases}h(a)={01​(a≤0)(a>0)​

한계:

  • 미분 불가능 → 역전파 불가능
  • a = 0 지점에서 불연속
  • 현재는 개념 이해용으로만 사용

3. Sigmoid 함수

용도: 이진분류

특징:

  • 출력값: 0~1 사이
  • 미분 가능 → 역전파 가능
  • 비선형 함수

수식:

σ(x)=11+e−x\sigma(x) = \frac{1}{1 + e^{-x}}σ(x)=1+e−x1​

미분:

σ′(x)=σ(x)×(1−σ(x))\sigma'(x) = \sigma(x) \times (1 - \sigma(x))σ′(x)=σ(x)×(1−σ(x))

한계:

  • 깊은 네트워크에서 Vanishing Gradient 문제 발생
  • 미분값이 최대 0.25로 작아서 여러 층을 거치면 gradient가 0에 수렴
  • 학습이 제대로 이루어지지 않음

4. ReLU (Rectified Linear Unit)

용도: 중간층(은닉층) 활성화 함수

특징:

ReLU(x)=max⁡(0,x)={0(x≤0)x(x>0)\text{ReLU}(x) = \max(0, x) = \begin{cases} 0 & (x \leq 0) \\ x & (x > 0) \end{cases}ReLU(x)=max(0,x)={0x​(x≤0)(x>0)​

미분:

ReLU′(x)={0(x≤0)1(x>0)\text{ReLU}'(x) = \begin{cases} 0 & (x \leq 0) \\ 1 & (x > 0) \end{cases}ReLU′(x)={01​(x≤0)(x>0)​

장점:

  • 양수 영역에서 미분값이 1로 유지됨
  • Vanishing Gradient 문제 해결
  • 계산이 빠름
  • 현재 가장 널리 사용되는 활성화 함수

단점:

  • 음수 영역에서 gradient가 0 (Dying ReLU 문제)
  • 해결책: Leaky ReLU, ELU 등

5. Softmax 함수

용도: 다중분류

특징:

  • 모든 출력값의 합이 1이 되도록 정규화
  • 각 클래스에 대한 확률값으로 해석 가능
  • Sigmoid에 비해 예측 오차의 평균을 줄여주는 효과

수식:

yk=exp⁡(ak)∑i=1nexp⁡(ai)y_k = \frac{\exp(a_k)}{\sum_{i=1}^{n} \exp(a_i)}yk​=∑i=1n​exp(ai​)exp(ak​)​

예시:

  • 입력: [2.0, 1.0, 0.1]
  • 출력: [0.659, 0.242, 0.099] (합 = 1.0)

3️⃣ 중간층에 비선형 활성화 함수가 필요한 이유

선형 함수를 사용하면?

문제:

  • 선형 함수 h(x)=xh(x) = xh(x)=x를 여러 층에 사용하면: y=h3(h2(h1(x)))=h3(h2(x))=h3(x)=xy = h_3(h_2(h_1(x))) = h_3(h_2(x)) = h_3(x) = xy=h3​(h2​(h1​(x)))=h3​(h2​(x))=h3​(x)=x
  • 결국 여러 층을 쌓아도 선형 결합만 반복됨
  • 다층 구조의 효과를 살릴 수 없음

비선형 활성화 함수를 사용하면?

장점:

  • 각 층마다 비선형 변환이 수행됨
  • 층을 쌓을수록 복잡한 패턴 학습 가능
  • XOR 문제와 같은 비선형 문제 해결 가능

4️⃣ 최적화 함수(Optimizer)

경사하강법(Gradient Descent Algorithm)

기본 개념:

  • 손실 함수의 기울기(gradient)를 계산하여 가중치를 업데이트
  • 기울기의 반대 방향으로 이동하여 손실을 최소화

최적화 함수의 종류

1. GD (Gradient Descent)

특징:

  • 전체 데이터를 이용해 업데이트
  • 정확하지만 느림

2. SGD (Stochastic Gradient Descent)

특징:

  • 확률적으로 선택된 일부 데이터를 이용해 업데이트
  • 빠르지만 노이즈가 많음

Batch Size:

  • 모델이 한 번에 학습하는 데이터 샘플의 개수
  • 전체 데이터셋을 한 번에 학습하면 메모리 문제 발생
  • 일반적으로 32, 64를 많이 사용
  • batch_size를 줄임: 메모리 소모 적음, 학습 속도 느림, 정확도 ↑
  • batch_size를 높임: 메모리 소모 큼, 학습 속도 빠름, 정확도 ↓

3. Momentum

특징:

  • 경사 하강법에 관성을 적용
  • 현재 batch뿐만 아니라 이전 batch 데이터의 학습 결과도 반영
  • 지그재그 형태로 이동하는 현상이 줄어듦

수식:

V(t)=m×V(t−1)−α∂∂wCost(w)V(t) = m \times V(t-1) - \alpha \frac{\partial}{\partial w} Cost(w)V(t)=m×V(t−1)−α∂w∂​Cost(w) W(t+1)=W(t)+V(t)W(t+1) = W(t) + V(t)W(t+1)=W(t)+V(t)
  • α\alphaα: Learning Rate
  • mmm: momentum 계수 (보통 0.9)

4. NAG (Nesterov Accelerated Gradient)

특징:

  • 개선된 모멘텀 방식
  • w, b값 업데이트 시 모멘텀 방식으로 먼저 더한 다음 계산
  • 미리 해당 방향으로 이동한다고 가정하고 기울기를 계산해본 뒤 실제 업데이트 반영
  • 불필요한 이동을 줄일 수 있음

수식:

V(t)=m×V(t−1)−α∂∂(w+m×V(t−1))Cost(w)V(t) = m \times V(t-1) - \alpha \frac{\partial}{\partial (w + m \times V(t-1))} Cost(w)V(t)=m×V(t−1)−α∂(w+m×V(t−1))∂​Cost(w) W(t+1)=W(t)+V(t)W(t+1) = W(t) + V(t)W(t+1)=W(t)+V(t)

5. Adagrad (Adaptive Gradient)

특징:

  • 학습을 진행하면서 학습률을 점차 줄여가는 방법
  • 처음에는 크게 학습하다가 조금씩 작게 학습
  • 학습을 빠르고 정확하게 할 수 있음

수식:

G(t)=G(t−1)+(∂∂w(t)Cost(w(t)))2G(t) = G(t-1) + \left(\frac{\partial}{\partial w(t)} Cost(w(t))\right)^2G(t)=G(t−1)+(∂w(t)∂​Cost(w(t)))2 W(t+1)=W(t)−α×1G(t)+ϵ×∂∂w(t)Cost(w(t))W(t+1) = W(t) - \alpha \times \frac{1}{\sqrt{G(t) + \epsilon}} \times \frac{\partial}{\partial w(t)} Cost(w(t))W(t+1)=W(t)−α×G(t)+ϵ​1​×∂w(t)∂​Cost(w(t))

단점:

  • 최소값을 찾기 전 학습이 멈추는 문제

6. RMSProp

특징:

  • Adagrad의 단점을 해결한 최적화 함수
  • Adagrad와 동일하게 학습을 진행하면서 학습률을 점차 줄여가는 방법
  • 지수이동 평균을 도입해서 해결
  • 지수 이동 평균: 최근 학습한 수치의 영향력은 높이고 과거 학습한 수치의 영향력은 낮추는 방식

7. Adam (Adaptive Moment Estimation)

특징:

  • Momentum과 RMSProp의 장점만을 취한 최적화 함수
  • 관성 방향으로 움직이는 Momentum과 보폭을 조절하며 움직이는 RMSProp의 특성을 하나로 합침
  • 현재 보편적으로 사용하는 최적화 함수
  • 성능적인 측면에서 가장 나은 최적화 함수

수식:

m1←β1m0+(1−β1)g1m1^←m11−β11\begin{array}{l} m_1 \leftarrow \beta_1 m_0 + (1 - \beta_1) g_1 \\ \widehat{m_1} \leftarrow \frac{m_1}{1 - \beta_1^1} \end{array}m1​←β1​m0​+(1−β1​)g1​m1​​←1−β11​m1​​​

최적화 함수 선택론

핵심:

  • 모든 문제에서 뛰어난 기법은 없음
  • 하지만 많은 사람들이 Adam에 만족하며 사용
  • 각자의 상황을 고려해보고 여러가지를 시도하는 것이 가장 좋은 방법론
  • 모르겠으면 Adam을 쓰는 것도 하나의 방법론!

5️⃣ 이미지 데이터 전처리 실습 (ex03-1)

목표

  • 강아지, 고양이 이미지를 배열로 변환
  • 압축된 형식의 배열로 저장: NPZ (numpy 라이브러리에서 읽고 쓸 수 있는 바이너리 파일)
  • 대용량 데이터를 압축 형태로 정리하면 클라우드 환경에 쉽게 업로드/다운로드 가능
  • 저장소의 공간 적게 차지 (공간 사용 효율 좋아짐)

NPZ 파일이란?

바이너리 파일:

  • 컴퓨터가 읽을 수 있게 이진수로 내용을 저장한 파일

NPZ:

  • 배열 파일 여러 개를 하나의 파일에 묶어서 저장(압축)
  • 여러 numpy 배열을 하나의 파일로 저장 가능

전처리 과정

전처리 플로우:

실습 단계

주요 과정:

  1. 압축 폴더 해제: ZIP 파일을 해제하여 폴더 구조 생성
  2. 파일명 정렬: os.listdir()로 가져온 파일명을 sorted()로 정렬 (중요!)
  3. 이미지 전처리: 모든 이미지를 224×224 크기로 조정하고 배열로 변환
  4. 데이터 결합: 고양이와 강아지 데이터를 각각 결합
  5. 정답 데이터 생성: 고양이=0, 강아지=1로 레이블 생성
  6. NPZ 파일 저장: 모든 데이터를 압축 파일로 저장

주의사항:

  • 파일명 정렬을 하지 않으면 인덱스 접근 시 예상과 다른 파일이 선택될 수 있음
  • 이미지 크기를 통일하여 모델 입력 형태를 일관되게 유지
  • 진행률 표시(tqdm)로 처리 상태 확인 가능

  • 이진 분류 문제 해결

데이터 불러오기

  • 학습 데이터: 2,000개 (고양이 1,000 + 강아지 1,000)
  • 테스트 데이터: 1,000개 (고양이 500 + 강아지 500)

MLP 모델 설계

모델 구조:

모델 구성:

  • 입력: (224, 224, 3) → Flatten → (150,528)
  • 은닉층: 256 → 128 → 64 (ReLU 활성화)
  • 출력층: 1개 뉴런 (Sigmoid 활성화, 이진분류)

모델 구성:

  • 입력층: Flatten(input_shape=(224, 224, 3)) - 3차원 이미지를 1차원으로 변환
  • 은닉층: 256 → 128 → 64 (모두 ReLU 활성화)
  • 출력층: 1개 뉴런 (Sigmoid 활성화, 이진분류)

학습 설정

모델 컴파일:

  • 최적화 함수: Adam
  • 손실함수: binary_crossentropy (이진분류)
  • 평가 지표: accuracy

EarlyStopping:

  • 검증 정확도를 모니터링하여 5번 연속 개선이 없으면 학습 중단

학습 파라미터:

  • 최대 100번 반복, 배치 크기 32
  • 학습 데이터의 30%를 검증 데이터로 사용

학습 결과 분석

학습 과정:

  • Epoch 1: accuracy 0.59, val_accuracy 1.00 (과대적합 의심)
  • Epoch 2-4: val_accuracy 불안정 (0.22 → 0.00)
  • Epoch 5: val_accuracy 0.94 (개선)
  • Epoch 6: val_accuracy 0.62 (하락)
  • EarlyStopping: Epoch 6에서 학습 중단

특징:

  • 초기 단계에서 검증 정확도가 불안정
  • MLP는 이미지의 공간적 정보를 잘 활용하지 못함
  • Flatten으로 인해 픽셀 간의 위치 관계 정보 손실

인사이트

  1. 비선형 활성화 함수의 중요성

    • 중간층에 비선형 활성화 함수가 없으면 다층 구조의 효과를 살릴 수 없음
    • ReLU가 현재 가장 널리 사용됨

  2. 최적화 함수 선택

    • Adam이 대부분의 경우에서 우수한 성능
    • 하지만 문제에 따라 다른 최적화 함수가 더 나을 수 있음

  3. 데이터 전처리의 중요성

    • NPZ 형식으로 저장하면 공간 효율성과 전송 속도 향상
    • 대용량 이미지 데이터 처리에 유용

주의사항

  1. 활성화 함수 선택

    • 중간층: ReLU 권장 (Vanishing Gradient 문제 해결)
    • 출력층: 문제 유형에 따라 선택 (회귀: linear, 이진분류: sigmoid, 다중분류: softmax)

  2. 최적화 함수 설정

    • 기본적으로 Adam 사용 권장
    • 학습률은 문제와 데이터에 따라 조정 필요

  3. NPZ 파일 사용

    • 여러 배열을 하나의 파일로 저장 가능
    • 압축 형식으로 공간 효율적

  4. 파일명 정렬

    • os.listdir()은 정렬되지 않은 순서로 반환
    • sorted()를 사용하여 파일명 순서대로 정렬 필요
    • 정렬하지 않으면 인덱스 접근 시 예상과 다른 파일 선택 가능

  5. 이미지 전처리

    • 모든 이미지를 동일한 크기(224×224)로 조정
    • 진행률 표시로 처리 상태 확인 (tqdm)
    • RGB 이미지: (높이, 너비, 3) 형태

  6. MLP 모델의 한계

    • Flatten으로 인해 공간적 정보 손실
    • 이미지 분류에는 CNN이 더 적합
    • MLP는 픽셀 간의 위치 관계를 학습하기 어려움
