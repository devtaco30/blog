📚 오늘의 학습 내용

오늘은 Transformer 아키텍처와 Hugging Face Transformers 라이브러리를 학습했습니다. RNN의 한계를 극복한 Transformer의 Self-Attention 메커니즘을 이해하고, 실무에서 사전 학습된 모델을 활용하는 방법을 익혔습니다.

1️⃣ Transformer의 등장 배경

RNN 계열의 한계

문제점:

  • 순차적 처리로 인한 느린 속도
  • 장기 의존성 문제 (긴 시퀀스에서 초반 정보 손실)
  • 병렬 처리 불가능

Transformer의 등장 (2017년 Google)

  • 논문: "Attention is All You Need"
  • RNN/LSTM 없이 Attention 메커니즘만으로 구현
  • 병렬 처리 가능, 빠른 학습 속도
  • 장기 의존성 문제 해결

2️⃣ Self-Attention 메커니즘

Attention이란?

개념:

  • 입력 시퀀스에서 특정 단어를 처리할 때 어느 부분을 중요하게 볼지 결정
  • 모든 입력 요소 간의 관계를 계산하여 문맥 정보 생성

예시:

문장: "월요일은 수업이 5시에 끝난다. 그래서 나는 오늘 5시에 쉴거다"

Self-Attention:
- "오늘" → "월요일" (높은 관계)
- "5시" → "끝난다", "쉴거다" (높은 관계)

Self-Attention 계산 과정

주요 구성 요소:

  1. Query (Q): 현재 집중하고 있는 단어
  2. Key (K): 비교 대상이 되는 모든 단어
  3. Value (V): 실제로 가져올 정보

계산 단계:

1. 입력 임베딩에 가중치 행렬 곱셈
   Q = X · W_Q
   K = X · W_K
   V = X · W_V

2. Attention Score 계산 (유사도)
   Score = Q · K^T / √d_k
   (d_k: key 벡터의 차원, 스케일링을 위해 나눔)

3. Softmax로 확률 분포 변환
   Attention Weights = softmax(Score)

4. Value와 가중합
   Output = Attention Weights · V

3️⃣ Transformer 구조

Positional Encoding (위치 인코딩)

필요성:

  • Self-Attention은 순서 정보를 고려하지 못함
  • 단어의 위치 정보를 주입해야 함

방법:

  • 사인/코사인 함수를 사용한 위치 벡터 생성
  • 입력 임베딩에 위치 벡터를 더함
PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

Transformer 전체 구조

Encoder:

  1. Input Embedding + Positional Encoding
  2. Multi-Head Self-Attention
  3. Add & Normalize (Residual Connection)
  4. Feed Forward Network
  5. Add & Normalize

Decoder:

  1. Output Embedding + Positional Encoding
  2. Masked Multi-Head Self-Attention
  3. Add & Normalize
  4. Encoder-Decoder Attention
  5. Add & Normalize
  6. Feed Forward Network
  7. Add & Normalize

4️⃣ Hugging Face Transformers 라이브러리

모델링 개발 방식 비교

방법장점단점
Open API 활용빠른 구현, 유지보수 불필요비용 발생, 데이터 외부 전송
직접 AI 개발비용 절감, 데이터 보안개발 시간 소요, 전문성 필요

Hugging Face란?

특징:

  • 사전 학습된 NLP 모델 제공
  • 간단한 API로 모델 사용 가능
  • BERT, GPT, T5 등 다양한 모델 지원

주요 구성 요소

1. Model (모델)

  • 사전 학습된 가중치를 가진 신경망
  • 예: BertModel, GPT2Model

2. Tokenizer (토크나이저)

  • 텍스트를 토큰으로 분리
  • 토큰을 정수 ID로 변환
  • 모델마다 전용 토크나이저 사용

3. Pipeline (파이프라인)

  • 전처리 → 모델 추론 → 후처리를 한 번에 처리
  • 간편한 인터페이스 제공

실습 예시

1. Pipeline 사용 (간단한 방법)

from transformers import pipeline

# 감성 분석
classifier = pipeline("sentiment-analysis")
result = classifier("I love this movie!")
# [{'label': 'POSITIVE', 'score': 0.9998}]

# 텍스트 생성
generator = pipeline("text-generation", model="gpt2")
result = generator("Once upon a time", max_length=50)

# 질의응답
qa = pipeline("question-answering")
context = "Transformers is a library by Hugging Face."
question = "Who created Transformers?"
result = qa(question=question, context=context)

2. Model & Tokenizer 직접 사용

from transformers import AutoTokenizer, AutoModel

# 토크나이저와 모델 로드
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
model = AutoModel.from_pretrained("bert-base-uncased")

# 텍스트 토큰화
text = "Hello, how are you?"
inputs = tokenizer(text, return_tensors="pt")
# {'input_ids': tensor([[...]), 'attention_mask': tensor([[...])}

# 모델 추론
outputs = model(**inputs)
last_hidden_states = outputs.last_hidden_state
# shape: (batch_size, sequence_length, hidden_size)

3. 사전 학습 모델 파인튜닝

from transformers import Trainer, TrainingArguments

# 학습 설정
training_args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=3,
    per_device_train_batch_size=16,
    learning_rate=2e-5,
    logging_dir="./logs",
)

# Trainer 설정
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,

# 학습 시작
trainer.train()
