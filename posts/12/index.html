오늘의 토론 주제:

  • 인공지능 윤리와 보안
  • 인공지능 딜레마

주요 딜레마들:

1. 모라벨의 역설 (Moravec's Paradox) 🤖

  • AI는 수학적 계산은 잘 하지만, 비정형 데이터 판단은 아직 약함
  • 예: 헬스케어 로봇은 수치 분석은 정확하나, 환자의 표정·감정·통증 판단은 부족

2. 불쾌한 골짜기 (Uncanny Valley) 😰

  • 인간과 비슷할수록 호감도가 높아지지만, 어느 순간 거부감이 드는 구간이 존재

3. 트롤리 딜레마 (Trolley Problem) ⚖️

  • 사람이 아닌 존재에게 '윤리적인 결정'을 어디까지 맡길 수 있을까?

4. 전자인경 도입에 관한 연구 🤔

  • AI가 인간과 유사한 수준에 도달한다면, 그것은 '인격'을 가졌다고 할 수 있는가?

🍊 Orange3 설치 및 인공지능의 7과정

Orange3란?

  • 기계학습과 데이터 분석을 위한 오픈 소스 소프트웨어
  • 캔버스에 위젯만으로 데이터를 분석할 수 있어 인공지능의 원리를 시각적으로 쉽게 이해할 수 있음

인공지능의 7과정:

  1. 문제 정의 (Problem Identification)

    • 해결할 문제의 정확한 조건과 목표 정의

  2. 데이터 수집 (Data Collection)

    • File (CSV, XML, JSON), Database, Web Crawler, IoT 센서, Survey 등

  3. 데이터 전처리 (Data Preprocessing)

    • 결측치·이상치 처리
    • Feature Engineering: Scaling, Encoding, Binning, Transform

  4. 탐색적 데이터 분석 (EDA)

    • 기술통계, 변수간 상관관계 분석
    • 시각화 (Pandas, matplotlib, seaborn)
    • Feature Selection

  5. 모델 선택 및 Hyper Parameter 조정

    • 문제 유형에 맞는 모델 선택 (KNN, SVM, Linear Regression, Ridge, Lasso 등)
    • Hyper Parameter: 모델 성능 최적화를 위해 수동으로 조정하는 파라미터

  6. 모델 학습 (Model Training)

    • Train/Test 데이터를 7:3 비율로 분리
    • model.fit(x_train, y_train): 학습 데이터로 모델 학습
    • model.predict(x_test): 테스트 데이터로 예측 수행

  7. 평가 (Evaluation)

    • 분류 문제: 정확도, 재현율, 정밀도, F1 score, ROC 곡선의 AUC
    • 회귀 문제: MSE, RMSE, R square

🍊 Orange 메뉴

  1. Data: 데이터 불러오기
  2. Transform: 데이터 전처리 기능
  3. Visualize: 데이터 시각화 및 관계 분석
  4. Model: 머신러닝 알고리즘 모음 (핵심 메뉴)
  5. Evaluate: 모델 성능 평가 및 예측 결과 확인
  6. Unsupervised: 비지도 학습 (거의 사용하지 않음)

🎨 Orange 실습

1️⃣ 데이터 불러오기

  • 데이터 가져오기: 드래그앤드롭 또는 파일 선택
  • Column Role 설정: 정답으로 사용할 컬럼의 Role을 feature → target으로 변경

2️⃣ 데이터 탐색

  • Data Table, Scatter Plot 위젯으로 데이터 분포와 형태를 시각적으로 확인

3️⃣ Train/Test 데이터 분리

  • Data Sampler 위젯 사용
  • 더블클릭으로 train/test 비율 조정 (기본 7:3)
  • Sample과 Remain으로 분리된 데이터를 각각 Data Table 위젯으로 확인

4️⃣ 모델 학습

  • Model 메뉴에서 알고리즘 선택 (예: Logistic Regression)
  • Train data와 모델을 연결
  • Data Sampler에서 'sample data' 선택하여 학습 실행

5️⃣ 모델 평가 및 예측

연결 순서:

data sampler (train) → model → test and score / predictions
data sampler (test) → test and score / predictions

모델 비교:

  • 동일한 플로우에 여러 모델을 추가하여 Test and Score에서 성능 비교 가능
