EST AI - Python(numpy)

Numpy 배열(ndarray)과 파이썬 리스트가 자료형과 연산에서 어떻게 다른지 비교합니다. | 배열 생성과 연산, 자료형 우선순위, float64와 float32의 차이, 차원을 차례로 봅니다.

📋 Numpy 소개

Numpy란?

  • 복잡한 빅데이터의 수학적/과학적 연산을 위해 만들어진 라이브러리
  • 반복문 없이 전체 데이터 배열 연산 가능한 수학 함수 제공

📋 List vs Numpy 비교

List (파이썬 리스트):

  • 자료형: 숫자형, 문자형 등 여러 가지 자료형을 한 번에 다룰 수 있음
  • 벡터 연산: 지원하지 않음
    • + 연산을 하면 리스트를 이어붙임 (concatenation)
    • 예: [1, 2] + [3, 4] → [1, 2, 3, 4]

Numpy (넘파이 배열):

  • 자료형: 한 가지 동일한 자료형이어야 함
  • 구조 제약: 배열의 원소 구조가 모두 동일해야 함
    • ❌ 불가능: np.array([[1], [2, 3], [4, 5, 6]]) (각 행의 길이가 다름)
    • ✅ 가능: np.array([[1, 2], [3, 4], [5, 6]]) (모든 행의 길이가 동일)
  • 벡터 산술 연산: 제공함
    • 동일한 인덱스끼리 연산을 수행
    • 예: np.array([1, 2]) + np.array([3, 4]) → np.array([4, 6])
  • 수학 함수: 표준 수학 함수를 제공함

📋 모듈(라이브러리) 사용하기

import numpy as np  # np라는 별칭(alias)을 사용하여 numpy를 import

📋 numpy.ndarray 클래스

정의:

  • 동일한 자료형의 원소들이 연속으로 구성된 자료구조 (배열)
  • 각 값들은 정수로 인덱스(idx)가 부여되어 있음

ndarray 생성하기:

  1. 리스트를 변환하는 방식: np.array([1, 2, 3]) 또는 np.array(my_list)
  2. 바로 생성하는 방식: np.zeros(), np.ones(), np.arange() 등

📋 배열 연산

벡터 연산:

  • 스칼라 연산: 각 원소에 연산이 적용됨 (arr + 1, arr * 3 등)
  • 배열끼리 연산: 동일한 인덱스끼리 요소별로 연산 (arr1 + arr2, arr1 * arr2 등)
  • 배열의 길이(shape)가 같아야 연산 가능
  • shape가 다르면 broadcasting 규칙에 맞지 않아 오류 발생

📋 자료형의 우선순위

자료형 자동 변환:

  • numpy는 동일한 자료형을 유지해야 하므로, 서로 다른 자료형이 섞여있으면 가장 상위 자료형으로 자동 변환

우선순위: boolean < int < float < complex < object < str

  • 정수와 실수가 섞여있으면 float로 통일
  • 문자열과 숫자가 섞여있으면 모두 문자열로 변환

📋 float64와 float32의 차이

💡 궁금해서 찾아본 내용: float64와 float32의 차이, 그리고 운영체제와의 관계

float64 (double precision, 배정밀도):

  • 비트 수: 64비트 (8바이트)를 사용
  • 정밀도: 소수점 이하 약 15~17자리까지 정확하게 표현 가능
  • 범위: 더 넓은 범위의 숫자를 표현 가능
  • 메모리: 각 숫자당 8바이트 사용
  • 용도: 일반적으로 기본값으로 사용, 높은 정밀도가 필요한 경우

float32 (single precision, 단정밀도):

  • 비트 수: 32비트 (4바이트)를 사용
  • 정밀도: 소수점 이하 약 6~7자리까지 정확하게 표현 가능
  • 범위: float64보다 작은 범위의 숫자 표현
  • 메모리: 각 숫자당 4바이트 사용 (float64의 절반)
  • 용도: 메모리가 제한적이거나, 정밀도보다 속도/메모리가 중요한 경우

비유: float64 = 정밀한 저울 (더 정확하지만 무거움), float32 = 간단한 저울 (덜 정확하지만 가벼움)

운영체제와 float64/float32의 관계:

  • NumPy는 일반적으로 운영체제 비트 수와 무관하게 기본적으로 float64를 사용합니다
  • 32비트 운영체제에서도 일반적으로 float64가 기본입니다
  • 일부 오래된 32비트 시스템이나 특수한 빌드에서는 float32가 기본일 수 있지만, 현재 일반적인 환경에서는 float64가 기본입니다
  • M1 Mac (ARM64, 64비트)에서도 기본적으로 float64를 사용합니다

확인 방법:

import numpy as np
arr = np.array([1.0, 2.0, 3.0])
print(arr.dtype)  # float64 (기본값)

📋 차원 (Dimension)

차원 속성:

  • ndim: 차원의 개수
  • shape: 각 차원의 크기 (튜플 형태)
  • size: 전체 원소의 개수

차원별 구조:

  • 1차원: shape: (4,) - 4개의 원소
  • 2차원: shape: (2, 3) - 2행 3열
  • 3차원: shape: (2, 2, 3) - 3차원 2개 × 2차원 2개 × 1차원 3개
  • 4차원: 이미지 배치 처리 (배치 크기, 높이, 너비, 채널) - 예: (32, 224, 224, 3)
  • 5차원: 비디오 데이터 (배치, 시간(프레임), 높이, 너비, 채널) - 예: (10, 30, 224, 224, 3)

💡 비디오 = 이미지 + 시간축. 이미지 4차원에 시간(프레임) 차원이 추가되어 5차원이 됩니다.

📋 편리한 배열 생성 함수

  • np.zeros(shape, dtype): 0으로 채워진 배열 생성
  • np.ones(shape, dtype): 1로 채워진 배열 생성
  • np.arange(start, stop, step): 일정 간격의 배열 생성
  • dtype을 지정하지 않으면 기본적으로 float64 사용

💡 핵심 정리

📖 주요 포인트

  • Numpy의 핵심: 반복문 없이 전체 배열에 대한 벡터 연산 가능
  • List와의 차이: 동일한 자료형이어야 하며, 벡터 연산 지원
  • 차원 속성: ndim, shape, size, dtype로 배열 구조 파악
  • 자료형: 자동 변환되므로 의도한 타입 사용 시 dtype 명시 권장

⚠️ 주의사항

  • 배열의 원소 구조가 모두 동일해야 함 (각 행의 길이가 같아야 함)
  • 배열 연산 시 shape가 다르면 오류 발생
  • 배열 + 리스트는 가능하지만 정석은 아님 (numpy 배열끼리 연산 권장)
  • 자료형 우선순위에 따라 자동 변환되므로 주의 필요

✅ 권장 사항

  • 배열 연산은 numpy 배열끼리 사용하는 것이 정석
  • dtype을 명시적으로 지정하면 의도한 자료형 사용 가능
  • 고차원 배열 작성 시 들여쓰기와 주석을 활용하여 구조를 명확히 표현
