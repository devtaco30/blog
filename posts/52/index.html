📚 오늘의 학습 내용

오늘은 CNN(Convolutional Neural Network) 모델을 활용한 이미지 분류 실습을 진행했습니다. MLP 모델의 한계를 극복하기 위해 CNN을 도입하고, 과대적합 문제를 해결하기 위한 기법들인 데이터 증강(Data Augmentation), Dropout, 그리고 **전이학습(Transfer Learning)**을 학습했습니다.

1️⃣ CNN (Convolutional Neural Network, 합성곱 신경망)

CNN의 개념

CNN이란?

  • 공간적인 구조가 중요한 데이터에 주로 사용되는 신경망
  • 이미지, 영상, 음성처럼 패턴이나 위치가 중요한 데이터에서 사용됨
  • MLP 모델의 한계를 극복하기 위한 모델 구조

MLP 모델의 한계:

  • Flatten으로 인해 이미지의 공간적 정보 손실
  • 픽셀 간의 위치 관계를 학습하기 어려움
  • 복잡한 이미지 데이터에 대한 학습 성능이 떨어짐

CNN의 주요 구성 요소

1. Conv(Convolution) Layer (합성곱 층)

  • 작은 필터로 이미지를 훑으면서 엣지, 선, 모양 같은 특징을 추출
  • Conv2D 레이어로 구현

2. Pooling 층

  • 중요한 특징만 남기고 크기를 줄임
  • 연산량 감소 + 노이즈 제거
  • MaxPooling2D 레이어로 구현

3. Dense 층

  • Flatten된 특징 벡터를 받아서 최종 분류 수행
  • 최종 분류(고양이/강아지 등) 수행

CNN 모델 구조

특성 추출부:

  • Conv2D + MaxPooling2D를 반복하여 특징 추출
  • 여러 층을 쌓을수록 고수준 특징 추출

분류부:

  • Flatten으로 1차원 벡터 변환
  • Dense 레이어로 최종 분류

모델 구조:

Conv2D 레이어의 주요 파라미터

filters:

  • 특징을 잡아내는 '눈'의 개수
  • 예: filters=32 → 32개의 서로 다른 특징을 감지

kernel_size:

  • 각 '눈'이 한 번에 보는 영역의 크기
  • 예: kernel_size=(3, 3) → 3×3 픽셀 영역

padding:

  • 'same': 입출력의 크기를 동일하게 하기 위해 이미지 주변에 0을 추가
    • 출력 크기 = 입력 크기 (224×224 → 224×224)
    • 모든 픽셀을 동일하게 처리할 수 있어 정보 손실 최소화
  • 'valid': 패딩을 추가하지 않음
    • 출력 크기 = 입력 크기 - (kernel_size - 1) (224×224 → 222×222)
    • 가장자리 픽셀의 정보가 손실됨

strides:

  • 커널이 이동하는 간격 (보폭)
  • 예: strides=(2, 2) → 2×2 픽셀씩 이동
  • 첫 번째 Conv2D에만 적용하여 초기 단계에서 연산량 빠르게 감소

왜 첫 번째 Conv2D에만 strides를 사용하나?

  • 초기 단계에서 연산량 빠르게 감소: 224×224 → 112×112로 줄이면 연산량이 1/4로 감소
  • MaxPooling과의 역할 분담: 이후 층들은 MaxPooling만으로도 충분히 크기를 줄일 수 있음
  • 정보 손실 최소화: 첫 번째 층은 저수준 특징(엣지, 선 등)을 추출 → strides로 크기를 줄여도 정보 손실 적음

MaxPooling2D 레이어

pool_size:

  • 풀링 윈도우 크기: 2×2 영역을 하나의 픽셀로 압축

작동 방식:

  • 2×2 영역(4개 픽셀)에서 최대값(max)만 선택
  • 나머지 3개 픽셀은 버림
  • 이미지 크기를 절반으로 줄임 (224×224 → 112×112)

목적:

  • Conv2D가 찾은 특징들 중 가장 중요한 것만 남김
  • 이미지 크기 감소로 연산량 감소
  • 노이즈 제거 및 과대적합 방지
  • 위치에 대한 불변성 증가 (약간의 이동에도 같은 특징 인식)

CNN 모델의 학습 결과

특징:

  • MLP 모델보다 성능 향상
  • 하지만 여전히 과대적합 문제 발생
    • accuracy는 높지만 val_accuracy는 낮음
    • 학습 데이터에 과도하게 맞춰져서 일반화 성능 저하

과대적합 발생 이유:

  • 훈련 데이터가 부족함
  • 모델이 학습 데이터의 노이즈까지 학습

2️⃣ 데이터 증강 (Data Augmentation)

데이터 증강의 개념

데이터 증강이란?

  • 이미지 회전, 이동, 확대, 축소 등을 통해 데이터를 늘리는 작업
  • 훈련 데이터를 다양하게 변형하여 변형된 새로운 훈련 데이터처럼 사용
  • 마치 훈련 데이터 수가 늘어난 효과를 얻는 것

과대적합이 일어나는 이유:

  • 훈련 데이터가 부족하기 때문
  • 훈련 데이터가 충분히 많다면 과대적합을 줄일 수 있음

주의사항:

  • 증강은 '훈련 데이터'에서만 진행해야 함
  • 테스트 데이터에는 증강을 적용하면 안됨 (단, rescale은 예외)

ImageDataGenerator

역할:

  • 이미지 크기 조절, 픽셀값 변경, 라벨링, 이미지 데이터 증강을 위한 라이브러리

주요 옵션:

옵션설명
rescale입력 이미지의 픽셀 값 재조정 (ex. rescale=1./255 → 모든 픽셀값을 0~1 사이로 정규화)
rotation_range이미지의 회전 범위를 설정 (ex. rotation_range=20 → -20~20도 사이에서 무작위로 회전)
width_shift_range이미지의 수평 이동 범위를 설정 (ex. 0.1은 전체 너비의 10%만큼 좌우로 무작위로 이동)
height_shift_range이미지의 수직 이동 범위를 설정 (ex. 0.1은 전체 높이의 10%만큼 위아래로 무작위로 이동)
shear_range시계 반대 방향으로 지정된 각도만큼 변형
zoom_range이미지의 확대 및 축소 범위를 설정 (ex. 0.1 → 0.9배~1.1배 사이에서 무작위로 확대하거나 축소)
horizontal_flip이미지를 수평 방향으로 뒤집을지 여부를 설정
fill_mode이미지를 변형할 때 생기는 빈 공간을 채우는 방식을 설정 (ex. 'nearest' → 가장 가까운 픽셀값을 사용하여 빈공간 채우기)

정규화 (rescale)의 의미

정규화란?

  • 픽셀값 0255 → 01 사이로 변환 (스케일)
  • 수치 자체는 변함: 0255(색상 범위) → 01(정규화된 값)
  • 하지만 상대적 관계는 유지됨: 밝은 픽셀은 여전히 밝고, 어두운 픽셀은 여전히 어둡다
  • 이미지의 패턴, 구조, 정보는 그대로 (단지 스케일만 바뀜)
  • 시각적으로는 동일한 이미지 (사람 눈으로 보면 차이 없음)

왜 필요한가?

  • 딥러닝 모델은 0~1 범위의 작은 값에서 더 안정적으로 학습
  • 0~255 범위는 너무 커서 gradient 계산 시 불안정할 수 있음
  • 활성화 함수(Sigmoid, ReLU 등)가 작은 값에서 더 잘 작동
  • 학습 속도와 수렴 안정성 향상

zoom_range의 작동 방식

확대/축소 범위:

  • zoom_range=0.2 → 0.8배 ~ 1.2배 사이에서 무작위로 확대 또는 축소
  • 확대: 1.0 ~ 1.2배 (이미지를 1.0배~1.2배로 확대)
  • 축소: 0.8 ~ 1.0배 (이미지를 0.8배~1.0배로 축소)

기전:

  1. 원본 이미지(224×224)를 무작위 배율(0.8~1.2)로 확대/축소
  2. 확대 시: 이미지가 커지므로 가장자리 일부가 잘림 (crop)
  3. 축소 시: 이미지가 작아지므로 빈 공간이 생김 → fill_mode로 채움
  4. 최종적으로 항상 224×224 크기로 반환

왜 필요한가?

  • 과대적합 방지: 같은 이미지를 다양한 크기로 학습하여 일반화 성능 향상
  • 다양한 크기의 객체 학습: 실제 환경에서는 객체 크기가 다양함
  • 데이터 증강: 하나의 이미지로 여러 변형 생성 (데이터 수 증가 효과)
  • 모델의 강건성 향상: 크기 변화에 덜 민감한 모델 학습

flow_from_directory

역할:

  • 지정된 디렉토리에서 이미지를 불러오고, 실시간으로 배치로 데이터를 생성하는 기능

train_gen과 flow_from_directory의 관계:

1. train_gen (ImageDataGenerator 객체)

  • 역할: "설정 객체" (레시피)
  • 기능: 데이터 증강 방법을 정의 (rescale, zoom_range, horizontal_flip 등)
  • 상태: 설정만 저장하고 있음, 아직 이미지를 처리하지 않음

2. flow_from_directory (train_gen의 메서드)

  • 역할: "실행 객체" (실제 요리)
  • 기능: train_gen에 정의된 설정대로 디렉토리에서 이미지를 불러와서 증강 적용
  • 반환: 실제로 배치 단위로 이미지를 생성하는 제너레이터 객체

작동 흐름:

  1. train_gen 생성 → "이렇게 증강하겠다" 설정만 저장
  2. flow_from_directory 호출 → 실제로 디렉토리에서 이미지 불러오기 시작
  3. train_generator 사용 → 모델 학습 시 배치 단위로 증강된 이미지 제공

왜 분리되어 있나?

  • 같은 설정(train_gen)으로 여러 디렉토리(train_dir, val_dir 등)에 적용 가능
  • 설정과 실행을 분리하여 코드 재사용성 향상
  • 메모리 효율: 필요한 시점에만 이미지를 불러와서 처리 (lazy loading)

주요 파라미터:

  • target_size=(224, 224): 이미지들의 크기 조정
  • batch_size=32: 한번에 변환할 이미지 개수
  • class_mode='binary': 이진 분류 모델 사용

주의사항:

  • validation_split은 generator 객체와 함께 사용할 수 없음
  • 대신 validation_data 파라미터로 별도의 test_generator를 사용해야 함

데이터 증강의 효과

결과:

  • 과대적합이 어느 정도 해소됨
  • 모델의 일반화 성능 향상
  • val_accuracy가 개선됨

단점:

  • 학습 시간이 오래 걸림
  • 자체적으로 설계한 모델은 여러 번 진행하고 수정하는 작업이 필요 → 시간이 오래 걸림

3️⃣ Dropout

Dropout의 개념

Dropout이란?

  • 과대적합을 개선하기 위한 기법
  • 학습하는 동안에만 적용 → 예측 시에는 적용하지 않음
  • 신경망을 비율에 따라 일부러 활성화되지 않도록 꺼둠

예:

  • Dropout(0.3) → 30%의 뉴런을 무작위로 꺼서 70%만 사용
  • 결과적으로 모델이 더 단순해져서 과대적합을 방지

Dropout의 작동 원리

학습 시 (training):

  1. 각 배치마다 랜덤하게 일정 비율의 뉴런을 선택하여 비활성화 (출력을 0으로 설정)
  2. 활성화된 뉴런만으로 forward pass와 backpropagation 수행
  3. 다음 배치에서는 다른 뉴런들이 랜덤하게 비활성화됨
  4. 결과적으로 모든 뉴런이 다양한 조합으로 학습됨

예측 시 (inference):

  1. 모든 뉴런을 활성화 상태로 사용 (Dropout 비활성화)
  2. 학습된 모든 뉴런의 지식을 종합하여 예측
  3. 더 정확한 예측 가능

시각적 예시:

[학습 시 - Dropout(0.3)]
입력 → [뉴런1: 활성화] → [뉴런2: 비활성화(0)] → [뉴런3: 활성화] → [뉴런4: 활성화] → 출력
         (70% 사용)         (30% 꺼짐)          (70% 사용)         (70% 사용)

[예측 시 - Dropout 비활성화]
입력 → [뉴런1: 활성화] → [뉴런2: 활성화] → [뉴런3: 활성화] → [뉴런4: 활성화] → 출력
         (100% 사용)         (100% 사용)         (100% 사용)         (100% 사용)

왜 과대적합을 방지하나?

의존성 감소:

  • 특정 뉴런에 과도하게 의존하지 않게 됨
  • 예: "뉴런 A가 꺼져도 다른 뉴런들로 예측 가능해야 함"

앙상블 효과:

  • 매 배치마다 다른 서브네트워크를 학습하는 것과 같음
  • 여러 개의 작은 모델을 학습하고 예측 시 모두 사용하는 효과
  • 예: 100개의 서브네트워크를 학습 → 예측 시 100개 모두 사용

일반화 능력 향상:

  • 모델이 더 robust해짐 (일부 정보가 없어도 작동)
  • 노이즈에 덜 민감해짐
  • 새로운 데이터에 대한 일반화 성능 향상

Dropout 사용 위치

특성 추출부:

  • MaxPooling2D 이후에 Dropout 추가
  • 예: cnn_model.add(Dropout(0.3)) → pool 층에 의해 나온 feature map 중 30% 무작위로 0으로 만든 후 다음 층으로 넘김

분류부:

  • Dense 레이어 사이에 Dropout 추가
  • 예: Dense(256) → Dropout(0.3) → Dense(128)

주의사항:

  • Dropout은 학습 시에만 적용되므로, 예측 시에는 자동으로 비활성화됨
  • model.evaluate() 또는 model.predict() 호출 시 Dropout이 자동으로 꺼짐
  • 학습 시에는 model.fit() 내부에서 자동으로 활성화됨

4️⃣ 전이학습 (Transfer Learning)

전이학습의 개념

전이학습이란?

  • 다른 사람이 만들어놓은 모델을 사용하는 기법
  • 대규모 데이터셋(예: ImageNet)으로 사전 학습된 모델의 가중치를 활용
  • 새로운 작업에 맞게 모델의 일부만 재학습

왜 필요한가?

  • 딥러닝 모델의 학습용으로는 절대적으로 데이터가 부족한 경우가 많음
  • 이미지 증강으로도 한계가 있음
  • 자체적으로 설계한 모델은 여러 번 진행하고 수정하는 작업이 필요 → 시간이 오래 걸림
  • 사전 학습된 모델을 활용하면 적은 데이터로도 좋은 성능을 얻을 수 있음

VGG16 모델

VGG16이란?

  • ImageNet 데이터셋으로 사전 학습된 CNN 모델
  • 100만 장 정도의 사진으로 학습되어 있음
  • 16개의 층으로 구성된 깊은 신경망

VGG16 사용 방법:

from tensorflow.keras.applications import VGG16

vgg16 = VGG16(
    include_top=False,  # 전결합 분류층 제외 (VGG16은 다중분류 1000개 → 지금은 이진분류)
    weights='imagenet',  # 기존에 학습한 가중치를 불러온다
    input_shape=(224, 224, 3)
)

파라미터 설명:

  • include_top=False: 전결합 분류층을 제외 (우리가 직접 분류층을 만들 예정)
  • weights='imagenet': ImageNet으로 사전 학습된 가중치 사용
  • input_shape=(224, 224, 3): 입력 이미지 크기

가중치 동결 (Freeze)

가중치 동결이란?

  • 모든 Conv 레이어는 동결하고 가중치 갱신을 막는 것
  • 학습 불가능하게 설정

왜 필요한가?

  • VGG16은 100만 장 정도의 사진으로 학습되어 있음
  • 학습 시 가중치가 갱신되도록 설정해두면, 기존 학습된 내용이 훼손 → 성능이 떨어짐
  • 특성 추출부는 고정하고, 분류부만 학습

구현:

# 모든 conv 레이어는 동결하고 가중치 갱신을 막는다 > 학습 불가능하게 설정
for layer in vgg16.layers:
    layer.trainable = False

전이학습 모델 구조

모델 구성:

  1. VGG16 (특성 추출부) - 가중치 동결
  2. Flatten
  3. Dense 레이어 (분류부) - 새로 학습

모델 구조:

특징:

  • VGG16의 특성 추출부는 그대로 사용
  • 분류부만 우리의 작업(이진 분류)에 맞게 새로 설계
  • 적은 데이터로도 우수한 성능 기대

전이학습의 장점

성능:

  • 사전 학습된 모델의 강력한 특징 추출 능력 활용
  • 적은 데이터로도 좋은 성능

시간:

  • 처음부터 모델을 학습하는 것보다 훨씬 빠름
  • 특성 추출부는 학습하지 않으므로 학습 시간 단축

효율성:

  • 대규모 데이터셋으로 학습된 지식 활용
  • 우리의 작은 데이터셋으로는 학습하기 어려운 고수준 특징을 활용

💡 핵심 정리

배운 것

  1. CNN 모델

    • 공간적 구조가 중요한 데이터에 적합
    • Conv2D + MaxPooling2D로 특징 추출
    • MLP보다 이미지 분류에 우수한 성능

  2. 데이터 증강

    • ImageDataGenerator를 활용한 이미지 변형
    • 훈련 데이터 수를 늘리는 효과
    • 과대적합 방지에 도움

  3. Dropout

    • 학습 시 일부 뉴런을 무작위로 비활성화
    • 모델의 복잡도 감소로 과대적합 방지
    • 앙상블 효과로 일반화 성능 향상

  4. 전이학습

    • 사전 학습된 모델(VGG16) 활용
    • 적은 데이터로도 우수한 성능
    • 학습 시간 단축

인사이트

  1. CNN의 중요성

    • 이미지 데이터는 공간적 정보가 중요
    • MLP는 Flatten으로 인해 공간 정보 손실
    • CNN은 공간적 패턴을 효과적으로 학습

  2. 과대적합 해결 전략

    • 데이터 증강: 데이터 수 증가 효과
    • Dropout: 모델 복잡도 감소
    • 전이학습: 사전 학습된 모델 활용

  3. 전이학습의 효율성

    • 처음부터 학습하는 것보다 훨씬 효율적
    • 대규모 데이터셋으로 학습된 지식 활용
    • 실무에서 널리 사용되는 기법

주의사항

  1. 데이터 증강

    • 훈련 데이터에만 적용
    • 테스트 데이터에는 적용하지 않음 (단, rescale은 예외)

  2. Dropout

    • 학습 시에만 적용, 예측 시에는 자동으로 비활성화
    • 적절한 비율 선택 (보통 0.3~0.5)

  3. 전이학습

    • 사전 학습된 모델의 가중치는 동결
    • 분류부만 새로 학습
    • 입력 이미지 크기는 사전 학습 모델과 동일하게 맞춰야 함
