🐍 Python 소개

프로그래밍 언어란?

  • 사람의 언어와 기계어를 연결해주는 중간 단계의 언어
  • 컴퓨터를 이용하여 특정 문제를 해결하기 위한 프로그램을 작성하기 위해 사용되는 언어

언어 분류:

  • 고급언어: 사람의 언어와 유사 (C, Java, Python)
  • 저급언어: 기계어와 유사 (어셈블리어)

Compile vs Interpreter:

  • Compile (ex: Java): 빠르지만 복잡함
  • Interpreter (ex: Python): 쉬우나 상대적으로 느림

Python의 특징:

  • 장점: 인간다운 언어, 문법 쉽고 코드가 간결
  • 활용 분야: 웹 프로그래밍, 데이터 분석 및 수치 연산, GUI 프로그래밍, AI

📝 변수 (Variable)

변수명 규칙:

  • 영문자, 숫자, 언더바 사용 가능 (대소문자 구분)
  • 숫자로 시작 불가능
  • 키워드 사용 가능하나 권장하지 않음
  • 내장함수명 사용 권장하지 않음

권장사항:

  • 변수명의 첫 글자는 항상 소문자
  • 두 단어 이상 결합 시 구분 필요
    • number_list (Snake case)
    • NumberList (Pascal case)
    • numberList (Camel case - 첫 글자 소문자, 두 번째 단어부터 대문자)

Python 변수 선언 특징:

# 다중 할당
a, b = 2, 3

# 동일 값 할당
a = b = c = 1

# 튜플 언패킹을 이용한 값 교환
a, b = b, a  # 내부적으로 튜플을 임시 생성하여 값 교환

> **💡 튜플 언패킹이란?**
> 
> `a, b = b, a`는 내부적으로 다음과 같이 동작합니다:
> 1. 오른쪽 `b, a`가 먼저 평가되어 `(b, a)` 튜플 생성
> 2. 튜플의 값들이 임시 저장소(스택)에 저장됨
> 3. 왼쪽 `a, b`에 저장된 값들을 순서대로 할당
> 
> 물리적으로 "동시" 할당은 불가능하지만, 오른쪽 평가가 먼저 완료되고 그 값들이 임시 저장되어 있기 때문에 원래 변수 값이 덮어써지기 전에 사용됩니다.

📄 문자열 (String)

Escape 문자:

문자설명
\n줄바꿈
\t탭
\\역슬래시
\'작은따옴표
\"큰따옴표

문자열 인덱싱 & 슬라이싱:

  • 인덱스 접근: s[0], s[-1] (음수 인덱스 가능)
  • 슬라이싱: s[start:end:step]

문자열 포맷팅:

  1. % 기호 사용

    # 복수일 때는 괄호로 묶기
"오늘은 %d월 %d일 입니다" % (month, day)

# 1개일 때는 괄호 없이 사용 가능
"오늘은 %d일 입니다" % day
    기호설명
    %s문자열
    %c문자 1개
    %d정수
    %f실수
    %%Literal% (문자 %)

  2. format 함수 사용

    "오늘은 {}월 {}일 입니다".format(month, day)
"오늘은 {0}월 {1}일 입니다".format(month, day)  # 인덱스 지정
"오늘은 {month}월 {day}일 입니다".format(month=7, day=7)  # 이름 지정

  3. f-string 사용 (가장 권장)

    f"오늘은 {month}월 {day}일 입니다"
# 삼항 연산자와 함께 사용 가능
f"{'홀수' if num % 2 else '짝수'}"

🔢 연산자 (Operator)

산술 연산자:

연산자설명예시
+덧셈3 + 2 → 5
-뺄셈3 - 2 → 1
*곱셈3 * 2 → 6
/나눗셈 (실수 결과)3 / 2 → 1.5
//몫 (정수 나눗셈)3 // 2 → 1
%나머지3 % 2 → 1
**거듭제곱3 ** 2 → 9

비교 연산자:

  • 불리언 자료형 반환 (True, False)
  • >, >=, <, <=, ==, !=

논리 연산자:

  • and: 양항이 모두 True여야 True
  • or: 두 항 중 하나라도 True면 True

멤버 연산자:

  • in: 멤버십 확인 
    '소금' in '콩국수에 들어갈 건 소금뿐'  # True

삼항 연산자:

  • 조건문의 단순화: a if 조건식 else b
  • f-string 내 사용 가능: f"{'홀수' if num % 2 else '짝수'}"

대입 연산자:

  • =, +=, -=, *=, /=, //=, %=, **=

💡 핵심 정리

📖 배운 것

  • Python의 특징과 Compile vs Interpreter 언어의 차이
  • 변수명 규칙 및 Python만의 변수 선언 특징 (다중 할당, 튜플 언패킹)
  • 문자열 처리 (Escape 문자, 인덱싱, 슬라이싱, 포맷팅 3가지 방법)
  • 다양한 연산자 (산술, 비교, 논리, 멤버, 삼항, 대입)

💭 인사이트

  • 튜플 언패킹의 내부 동작 원리 이해: 오른쪽 표현식이 먼저 평가되고 임시 저장된 후 할당됨
  • a, b = b, a 같은 간결한 값 교환은 Python의 특징적인 문법
  • 문자열 포맷팅은 f-string이 가장 현대적이고 권장되는 방법
  • Python의 / 연산자가 항상 실수 결과를 반환하는 점을 주의해야 함

⚠️ 주의사항

  • ⚠️ 키워드나 내장함수명을 변수명으로 사용하지 않기 (가능하나 권장하지 않음)
  • ⚠️ 숫자와 문자열의 덧셈은 TypeError 발생 (형변환 필요)
  • ⚠️ / 연산자는 항상 실수 결과 반환, 정수 몫이 필요하면 // 사용
  • ✅ 변수명은 명확하고 의미있게 작성
  • ✅ 문자열 포맷팅은 f-string 사용 권장
