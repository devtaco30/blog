EST AI - Machine Learning 실습 (타이타닉 데이터 결측치 보정)

Kaggle 타이타닉 데이터로 승객의 생존 여부를 예측하려면 먼저 결측치를 채워야 합니다. | Embarked, Fare, Age, Cabin 컬럼을 상관관계와 그룹화, apply 함수로 하나씩 보정합니다.

Machine Learning

2025년 12월 10일 오후 06:49

📚 오늘의 학습 내용

Kaggle의 타이타닉 데이터셋을 활용하여 승객의 생존 여부를 예측하기 위한 데이터 전처리 실습을 진행했습니다.

결측치 처리 방법, 상관관계 분석, 그룹화를 통한 결측치 채우기, 그리고 apply 함수를 활용한 데이터 변환 등 다양한 전처리 기법을 학습했습니다.

1️⃣ 문제 정의

목표

  • Kaggle에서 제공하는 타이타닉 데이터를 사용해 승객의 생존 여부를 예측
  • live or death → 2중 분류 (지도학습)
  • 'Survived' Column: 수치형으로 되어 있지만 0, 1로 생존 여부만 구분

2️⃣ 데이터 수집

데이터 로드

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

train = pd.read_csv('../data/titanic_train.csv', index_col='PassengerId')
test = pd.read_csv('../data/titanic_test.csv', index_col='PassengerId')

데이터 크기

  • train data: (891, 11)
  • test data: (418, 10)

3️⃣ 데이터 전처리 및 데이터 탐색

컬럼 정보 정리

  • Survived: 생존/사망 결과 값 (0: 사망, 1: 생존)
  • Pclass: 객실 등급 (1: 일등석, 2: 이등석, 3: 삼등석)
  • SibSp: 형제자매/배우자 수 (같이 탑승한)
  • Parch: 부모/자식 수 (같이 탑승한)
  • Ticket: 티켓번호
  • Fare: 지불 요금
  • Cabin: 객실 번호 → 이름과 같이 다 다르지만, 이 번호가 가진 '층 정보'가 있다면 관계가 있을 수 있다
  • Embarked: 승선항 (S, C, Q)
    • Cherbourg, Queenstown, Southampton

결측치 확인

train 결측치 컬럼:

  • Age
  • Cabin
  • Embarked

test 결측치 컬럼:

  • Age
  • Fare
  • Cabin
  • Embarked

결측치 처리 방법

  1. 결측치가 있는 행 전체를 drop

    • 삭제하려는 데이터가 너무 많거나 모델링에 치명적이지 않은 데이터
    • 데이터가 많을수록 과대적합을 피할 수 있는데, 삭제하면 학습하는 데이터가 줄어든다

  2. 결측치를 다른 값을 대체

    • 평균, 최빈, 중앙, 다른 변수와의 관계를 보고 입력

4️⃣ 결측치 채우기

4-1. Embarked 결측치 보정 (train)

방법: 최빈값으로 채우기

# 사람이 가장 많이 탑승한 승선항 값으로 채워주기 -> 최빈값
# fillna('값'): 비어있는 값이 있다면 '값'으로 채워주는 함수
train['Embarked'].fillna('S', inplace=True)
  • 결과: Embarked 결측치 2개를 'S' (Southampton)로 채움

4-2. Fare 결측치 보정 (test)

방법: 상관관계를 활용한 그룹화 후 중앙값으로 채우기

상관관계 분석

# 상관 관계 확인
test.corr(numeric_only=True)  # 숫자로 된 컬럼만 포함

상관 계수 (Correlation Coefficient)

  • 범위: -1 ~ 1
  • -1 또는 1에 가까울수록 관계가 높음 (강한 선형관계)
  • 0에 가까울수록 해당 컬럼과 '선형관계'가 없음을 의미

예시: Pclass와 Fare의 상관관계

  • Pclass: 1등급, 2등급, 3등급 (숫자가 작을수록 고급)
  • Fare: 요금 (높을수록 비쌈)
  • 상관계수: -0.577147 (음수)
  • 해석: 요금이 높아질수록 등급이 높아짐 (1등급이 가장 비쌈)
    • Pclass가 작아질수록 (1등급) Fare가 커짐
    • 음수 상관관계이므로 반대 방향의 관계

그룹화를 통한 중앙값 확인

# Pclass와 성별을 기준으로 그룹핑하여 Fare의 중앙값을 확인
train[['Pclass', 'Sex', 'Fare']].groupby(['Pclass', 'Sex']).median()

결측치 채우기

# 현재 비어있는 row의 Pclass는 3이다.
# 해당 데이터에 해당하는 sex는 male이다.
# train 데이터에서 확인한 바에 따르면 3등석 male의 요금은 7.92500이다. (중앙값)
# 참고: test['Fare'].fillna(7.925, inplace=True) 는 FutureWarning 발생 (pandas 3.0에서 동작 안 함)
# 해결: test['Fare'] = test['Fare'].fillna(7.925) 사용 권장
test['Fare'].fillna(7.925, inplace=True)

4-3. Age 결측치 보정 (train, test)

방법: Pclass와 Sex를 그룹화하여 평균값으로 채우기

그룹화를 통한 Age 평균 확인

# Age는 Pclass와 상관관계가 상대적으로 높았음
# 나이가 많다 -> 돈을 모았다 -> 1등석 탔을 것이다.
# Pclass, Sex를 grouping해서 Age의 평균 출력
gb1 = train[['Pclass', 'Sex', 'Age']].groupby(['Pclass', 'Sex']).mean()

apply 함수를 활용한 결측치 채우기

# 규칙에 맞게 Pclass와 Sex를 보면서 Age를 채워넣는 함수 정의
def fill_age(row):
    # row: 받아오는 행
    # row의 Age가 결측치라면, gb1에서 매칭되는 값을 찾아서 대입하자.
    # 결측치가 아니라면, 그냥 두면 된다.
    
    ## 결측이라면
    if np.isnan(row['Age']):
        return gb1.loc[row['Pclass'], row['Sex']].iloc[0]
        # 해당 행에서 Pclass와 Sex 값을 가져와서 인덱싱
    else:
        return row['Age']

# apply 이용해서 fill_age 함수를 적용
# 데이터를 행 단위로 매개변수에 전달
# 결과값으로 Age를 채울 수 있는 대표값을 하나 return
# 정수형으로 변환을 해서 'Age' 컬럼에 넣어줌
train['Age'] = train.apply(fill_age, axis=1).astype(np.int64)
test['Age'] = test.apply(fill_age, axis=1).astype(np.int64)

정리:

  • apply 이용해서 fill_age 함수를 적용
  • 데이터를 행 단위로 매개변수에 전달
  • 결과값으로 Age를 채울 수 있는 대표값을 하나 return
  • 정수형으로 변환을 해서 'Age' 컬럼에 넣어줌

4-4. Cabin 결측치 보정 및 Deck 변환

방법: 임의의 값으로 채운 후 Deck 정보 추출

Cabin 결측치 채우기

# 특성의 범주가 너무 많아서 학습시 의미가 별로 없음
# 우선 임의의 값으로 train, test Cabin 결측치를 채워보자
# 'M' (Missing)

train['Cabin'] = train['Cabin'].fillna('M')
test['Cabin'] = test['Cabin'].fillna('M')

Deck 정보 추출

# 첫 글자 알파벳 1개만 추출 -> 객실 층 정보
train['Deck'] = train['Cabin'].str[0]
test['Deck'] = test['Cabin'].str[0]

# 필요한 층 정보는 얻었으니 필요 없는 Cabin 컬럼은 drop
train.drop('Cabin', axis=1, inplace=True)
test.drop('Cabin', axis=1, inplace=True)

💡 핵심 정리

배운 것

  • 결측치 처리 방법: drop vs 대체 (평균, 최빈, 중앙, 다른 변수와의 관계)
  • 상관관계 분석: corr(numeric_only=True)를 통한 컬럼 간 관계 파악
  • 그룹화 (Groupby): 특정 컬럼 기준으로 그룹화하여 집계값 확인
  • apply 함수: 행 단위로 함수를 적용하여 데이터 변환
  • 문자열 인덱싱: str[0]을 통한 첫 글자 추출

인사이트

  • 상관관계를 활용한 결측치 채우기: 단순 평균보다 다른 변수와의 관계를 고려한 값이 더 의미있음
  • 그룹화를 통한 결측치 채우기: Pclass와 Sex를 그룹화하여 Age를 채우는 것이 단순 평균보다 정확함
  • 데이터 변환: Cabin의 첫 글자만 추출하여 Deck 정보로 활용 (차원 축소)
