오늘은 **선형 회귀(Linear Regression)**의 개념과 구현 방법을 학습했습니다. 최소제곱법과 경사하강법을 통해 회귀 모델의 파라미터를 찾는 방법을 이해하고, 회귀 모델의 평가 지표를 학습했습니다.

1️⃣ 회귀(Regression)란?

회귀의 개념

  • 연속적인 '실수' 값을 예측하는 분야
  • 완전히 '정확'하게 맞추긴 힘들다
  • 예측값과 실제값 사이의 오차를 최소화하는 것이 목표

선형 회귀(Linear Regression)

  • '직선의 형태'를 가지는 1차식으로 연속적인 실수 값을 예측하는 모델
  • 여러 개의 독립변수 x (특성)와 종속변수 y (예측값)의 선형 상관 관계를 모델링

선형 회귀의 특징:

  • 선형 회귀는 규제가 있는 회귀 모델(Lasso, Ridge)과 '딥 러닝' 이론의 기초
  • 회귀는 현업에서 많이 사용되며 활용 분야가 매우 넓음
  • '수치' 데이터는 거의 다 회귀모델을 사용하면 어느정도 해결이 된다

2️⃣ 선형 회귀 모델

단순 선형 회귀

y = wx + b

  • w: 가중치(weight), 계수(coefficient), 기울기
  • b: 편향(bias), 절편(intercept)
  • x: 독립(입력) 변수, 특성값
  • y: 종속(응답) 변수, 예측값

다중 선형 회귀

y = w₁x₁ + w₂x₂ + w₃x₃ + ... + wₚxₚ + b

  • 여러 개의 특성을 사용하여 예측값을 계산
  • 각 특성마다 가중치(w)가 존재

scikit-learn에서 파라미터 확인:

  • 모델 w 파라미터: model.coef_
  • 모델 b 파라미터: model.intercept_

3️⃣ w와 b를 찾는 방법

1. 최소제곱법 (Ordinary Least Squares, OLS)

  • 수학적 공식을 이용한 해석적 방법
  • 정확한 해를 한 번에 구할 수 있음
  • 데이터가 많을 때 계산 비용이 높을 수 있음
  • scikit-learn의 LinearRegression이 내부적으로 최소제곱법을 사용

2. 경사하강법 (Gradient Descent)

  • w와 b 값의 변화에 따른 오차(loss)값의 기울기를 이용하여 찾는 방법
  • 반복적으로 파라미터를 업데이트하여 최적값을 찾음
  • 데이터가 많을 때 유리함

4️⃣ 회귀 모델 평가 지표

회귀 모델의 성능은 어떻게 평가해야 할까?

회귀 평가 지표와 분류 평가 지표는 다름:

  • 분류 평가 지표: 얼마나 잘 맞췄는가? (정확도, 정밀도, 재현율 등)
  • 회귀 평가 지표: 오차값, 데이터의 분포를 잘 이해하고 있는가? (MSE, RMSE, R² Score 등)

주요 평가 지표

1. MSE (Mean Squared Error, 평균제곱오차)

MSE = (1/m) × Σ(H(xᵢ) - yᵢ)²

  • 예측값과 실제값의 차이를 제곱한 후 평균을 낸 값
  • 값이 작을수록 좋음
  • 단위가 제곱이 되어 해석이 어려울 수 있음
  • 평균제곱오차가 최소인 w와 b를 찾는다

2. RMSE (Root Mean Squared Error, 평균제곱근오차)

RMSE = √[(1/m) × Σ(H(xᵢ) - yᵢ)²]

  • MSE에 제곱근을 씌운 값
  • 원래 데이터와 같은 단위로 해석 가능
  • 값이 작을수록 좋음

RMSE/MSE의 단점:

  • 예측 대상의 크기에 영향을 받음
  • 예: 비트코인과 이더리움의 시세예측 RMSE가 50000이 나왔다면 두 모델의 성능은 동일할까요?
    • 비트코인: 147,099,000원 → 50,000원 오차는 0.03%
    • 이더리움: 3,763,000원 → 50,000원 오차는 1.33%
    • 같은 RMSE 값이지만 실제 성능은 다를 수 있음

3. R² Score (결정계수, Coefficient of Determination)

R² = 1 - (SS_res / SS_tot)

  • SS_res: 잔차 제곱합 = Σ(yᵢ - ŷᵢ)² (실제값과 예측값의 차이 제곱합)
  • SS_tot: 총 제곱합 = Σ(yᵢ - ȳ)² (실제값과 평균값의 차이 제곱합)
  • ȳ: 실제값의 평균

또는

R² = 1 - (MSE / Var(y))

  • 0~1 사이의 값
  • 1에 가까울수록 회귀직선이 데이터의 분포를 잘 이해하고 있다
  • 모델이 데이터의 분산을 얼마나 잘 설명하는지를 나타냄
  • R² = 1: 완벽한 예측 (SS_res = 0)
  • R² = 0: 평균값으로 예측하는 것과 동일한 성능
  • R² < 0: 모델이 평균값보다 못함

scikit-learn에서 사용:

model.score(X_test, y_test)  # R² Score 반환

5️⃣ LinearRegression 모델 사용

데이터 준비

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

data = pd.DataFrame(
    {
        '시간': [2, 4, 8, 9],
        '성적': [20, 40, 80, 90]
    }
)

LinearRegression 모델 사용

참고: LinearRegression은 내부적으로 최소제곱법을 사용하여 파라미터를 찾습니다.

# 모델 초기화(생성)
lr_rg = LinearRegression()

# 학습
# 모델 학습: 문제(2차원으로 입력해야 함), 정답(정답은 하나니까 1차원)
lr_rg.fit(data[['시간']], data['성적'])

# 예측
lr_rg.predict([[7]])  # 70.0

# 가중치 (w), 절편(b) 확인하기
print(f'가중치(w) : {lr_rg.coef_}')      # [10.]
print(f'절편(b) : {lr_rg.intercept_}')   # 0.0

결과:

  • 가중치 w = 10
  • 절편 b = 0 (실제로는 0에 가까운 값)
  • 따라서 모델: y = 10x + 0

참고:

  • 최소제곱법의 수학적 공식이나 직접 구현은 다루지 않았습니다
  • LinearRegression이 내부적으로 최소제곱법을 사용하여 파라미터를 찾습니다

6️⃣ 경사하강법 (Gradient Descent)

경사하강법이란?

경사하강법은 MSE(평균제곱오차)를 최소화하는 w와 b를 찾는 방법입니다.

  • MSE를 손실함수(비용함수)로 사용
  • MSE의 기울기를 계산하여 값이 낮아지는 방향으로 파라미터를 업데이트
  • 반복적으로 업데이트하여 최적의 w와 b를 찾음

경사하강법의 과정

  1. 파라미터 (w, b) 임의의 값으로 초기화
  2. 예측: 현재 w와 b 값을 사용해서 예측을 수행
  3. 오차 계산: 예측값과 실제값 사이의 오차를 계산 (MSE)
  4. 손실 함수의 기울기 계산 → MSE를 w와 b에 대해 편미분한 값
  5. 파라미터 업데이트: 기울기의 반대 방향으로 w와 b를 업데이트
  6. 2~5번 과정을 반복하여 MSE가 최소가 되는 w와 b를 찾음

기울기를 이용한 파라미터 업데이트

경사하강법에서 보이는 "기울기"는 MSE를 w와 b에 대해 편미분한 값입니다.

  • 기울기 계산: MSE를 w에 대해 편미분 → ∂MSE/∂w
  • 기울기 계산: MSE를 b에 대해 편미분 → ∂MSE/∂b

파라미터 업데이트 공식:

  • w = w - α × (∂MSE/∂w)
  • b = b - α × (∂MSE/∂b)
  • α: 학습률(learning rate) - 기울기의 보폭을 조절

작동 원리:

  • 기울기가 양수면: MSE가 증가하는 방향 → w를 감소시켜 MSE를 낮춤
  • 기울기가 음수면: MSE가 감소하는 방향 → w를 증가시켜 MSE를 낮춤
  • 학습률(α)은 업데이트의 크기를 조절 (너무 크면 발산, 너무 작으면 느림)

MSE (Mean Squared Error, 평균 제곱 오차)

경사하강법에서 손실함수/비용함수로 사용

# 가설함수 정의
def h(w, x):
    return w * x + 0

# MSE (Mean Squared Error, 평균 제곱 오차) : 손실함수, 비용함수
def cost(data, target, weight):
    # 입력특성(시간), 실제값 (성적), 가중치
    y_pred = h(weight, data)  # 가설함수 사용해서 예측값 구하기
    mse = ((target - y_pred) ** 2).mean()
    return mse

# MSE 계산
cost(data['시간'], data['성적'], 10)  # 0.0

w 값에 따른 MSE 변화 시각화

# x 축의 범위
w_arr = range(-10, 31)  # -10 ~ 30 까지 범위

cost_list = []  # 비용함수(mse) 리스트

for w in w_arr:
    c = cost(data['시간'], data['성적'], w)
    cost_list.append(c)

plt.plot(w_arr, cost_list)
plt.xlabel('weight')
plt.ylabel('loss')
plt.show()

해석:

  • w = 10일 때 MSE가 0으로 최소값을 가짐
  • 경사하강법은 이 최소값을 찾아가는 과정

7️⃣ 경사하강법의 종류

경사하강법 (Gradient Descent)

  • 전체 데이터를 한 번에 사용하여 기울기를 계산
  • 정확하지만 느림
  • 메모리 사용량이 많음

확률적 경사하강법 (Stochastic Gradient Descent, SGD)

  • 한 번에 하나의 샘플만 사용하여 기울기를 계산
  • 빠르지만 노이즈가 많음
  • 일부 데이터로 판단하기 때문에 속도가 빠름 (데이터 수가 많을 때 유리)
  • 항상 좋은 방향으로만 업데이트가 일어나지는 않음

8️⃣ SGDRegressor 사용

SGDRegressor 모델

Stochastic Gradient Descent Regressor - 확률적 경사하강법을 사용하는 회귀 모델

from sklearn.linear_model import SGDRegressor

# 모델 초기화
sgd_rg = SGDRegressor(
    eta0=0.01,      # 학습률(learning rate, 기울기의 보폭)
    max_iter=5000,  # w 값의 업데이트 회수 limit, 그 전에 끝날 수도 있다
    verbose=1,      # 학습 과정 출력 여부
)

# 모델 학습
sgd_rg.fit(data[['시간']], data['성적'])

# 가중치와 절편 확인
sgd_rg.coef_, sgd_rg.intercept_

# 성능 확인
sgd_rg.score(data[['시간']], data['성적'])

주요 파라미터:

  • eta0: 학습률 (learning rate) - 기울기의 보폭
  • max_iter: 최대 반복 횟수
  • verbose: 학습 과정 출력 여부

💡 핵심 정리

배운 것

  • 회귀: 연속적인 실수 값을 예측하는 분야
  • 선형 회귀: y = wx + b 형태의 직선으로 예측하는 모델
  • LinearRegression: 최소제곱법을 내부적으로 사용하는 scikit-learn 모델
  • 경사하강법: 오차의 기울기를 이용하여 파라미터를 찾는 방법
  • MSE: 평균 제곱 오차, 회귀 모델의 손실함수
  • RMSE: 평균 제곱근 오차, MSE에 제곱근을 씌운 값
  • R² Score: 결정계수, 0~1 사이의 값으로 모델 성능 평가

인사이트

  • 회귀와 분류의 평가 지표는 다름: 회귀는 오차를, 분류는 정확도를 평가
  • LinearRegression vs SGDRegressor: LinearRegression은 최소제곱법을, SGDRegressor는 경사하강법을 사용
  • 학습률(learning rate): 경사하강법에서 중요한 하이퍼파라미터
  • R² Score: 회귀 모델의 성능을 직관적으로 이해할 수 있는 지표
  • MSE 시각화: w 값에 따른 손실함수 변화를 시각화하여 최적값을 이해할 수 있음

주의사항

  • ⚠️ 입력 데이터 형태: fit() 시 문제는 2차원, 정답은 1차원으로 입력
  • ⚠️ RMSE의 단점: 예측 대상의 크기에 영향을 받으므로 상대적 오차를 고려해야 함
  • ✅ 모델 파라미터 확인: coef_와 intercept_로 학습된 가중치와 절편 확인 가능
  • ✅ R² Score 해석: 1에 가까울수록 좋지만, 과대적합 여부도 확인 필요
