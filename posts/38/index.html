📚 오늘의 학습 내용

오늘은 **비지도 학습(Unsupervised Learning)**의 개념을 학습하고, K-Means 클러스터링 알고리즘을 실습했습니다. 붓꽃 데이터셋을 이용하여 군집화를 수행하고, 비지도 학습의 평가 지표(ARI, AMI, Silhouette)와 최적 클러스터 수를 결정하는 방법(엘보우 기법)을 배웠습니다.

1️⃣ 비지도 학습 개요

비지도 학습이란?

  • 정답 레이블이 없는 데이터로부터 패턴을 찾아내는 학습 방법
  • 데이터의 숨겨진 구조나 패턴을 발견하는 것이 목적
  • 지도 학습과 달리 정답이 없기 때문에 평가가 어려움

지도 학습 vs 비지도 학습

지도 학습 (Supervised Learning):

  • 정답 레이블이 있는 데이터로 학습
  • 분류(Classification): 이메일 스팸 여부, 고객 이직 여부 등
  • 회귀(Regression): 집 가격 예측, 매출 예측 등
  • 평가 지표: Accuracy, Precision, Recall, F1-Score, R² 등

비지도 학습 (Unsupervised Learning):

  • 정답 레이블이 없는 데이터로 학습
  • 군집화(Clustering): 고객 세분화, 문서 그룹화 등
  • 차원 축소(Dimensionality Reduction): 시각화, 노이즈 제거 등
  • 평가 지표: ARI, AMI, Silhouette Score 등 (정확한 평가는 어려움)

비지도 학습의 주요 목적

  1. 데이터 탐색: 데이터의 숨겨진 패턴 발견
  2. 데이터 압축: 차원 축소를 통한 효율적인 표현
  3. 이상치 탐지: 정상 패턴과 다른 데이터 발견
  4. 전처리: 지도 학습 전에 데이터 구조 파악

2️⃣ 군집화 (Clustering)

군집화란?

  • 비슷한 특성을 가진 데이터 포인트들을 그룹으로 묶는 작업
  • 같은 군집 내의 데이터는 서로 비슷하고, 다른 군집의 데이터는 서로 다름
  • 정답 레이블 없이 데이터의 자연스러운 그룹을 찾아냄

군집화의 활용 사례

  • 고객 세분화: 구매 패턴이 비슷한 고객들을 그룹화
  • 이미지 분할: 비슷한 픽셀들을 묶어서 객체 식별
  • 문서 분류: 주제가 비슷한 문서들을 그룹화
  • 유전자 분석: 유사한 유전자 패턴을 가진 그룹 식별

3️⃣ K-Means 알고리즘

K-Means란?

  • 가장 널리 사용되는 군집화 알고리즘
  • **Centroid(군집 중심점)**를 통해 비슷한 샘플끼리 그룹을 형성
  • 거리 기반 알고리즘으로, 유클리드 거리를 사용하여 데이터 포인트를 가장 가까운 중심점에 할당

K-Means 알고리즘 동작 과정

  1. 임의의 Centroid 설정

    • K개의 초기 중심점을 무작위로 선택
    • n_init 파라미터로 여러 번 시도하여 최적 결과 선택

  2. 거리 계산 및 할당

    • 각 데이터 포인트로부터 모든 Centroid까지의 거리 계산
    • 가장 가까운 Centroid에 데이터 포인트 할당

  3. Centroid 업데이트

    • 할당된 데이터 포인트들의 평균값으로 새로운 Centroid 계산
    • 각 군집의 중심점을 재조정

  4. 수렴 확인

    • Centroid의 이동이 없을 때까지 2~3 단계 반복
    • 또는 최대 반복 횟수에 도달할 때까지 반복

K-Means의 장단점

장점:

  • 쉽고 간결함
  • 일반적인 군집화에 많이 사용됨
  • 계산 속도가 빠름
  • 구현이 간단함

단점:

  • 거리 기반 알고리즘이므로 속성의 개수(차원의 수)가 많은 경우 군집화 정확도가 떨어짐
  • 몇 개의 군집(k 수)를 선택해야 하는지 알 수 없음 → 엘보우 기법 등으로 결정 필요
  • 초기 중심점 선택에 따라 결과가 달라질 수 있음
  • 원형(구형) 군집에만 잘 작동함 (비선형 군집에는 부적합)

4️⃣ K-Means 실습 - 붓꽃 데이터셋

데이터 준비

from sklearn.datasets import load_iris
import pandas as pd
import numpy as np

# 붓꽃 데이터셋 로드
iris = load_iris()

# 문제 데이터 (X) 생성
data = pd.DataFrame(iris.data, columns=iris.feature_names)

# 정답 데이터 (y) 생성
# 주의: Clustering은 비지도 학습이므로 정답을 주지 않는 학습 방법
# 하지만 완료 후 '비교'를 위해 빼놓음
labels = pd.DataFrame(iris.target, columns=['labels'])

# 2차원으로 시각화하기 위해 2개의 특징만 사용
feature = data[['sepal length (cm)', 'sepal width (cm)']]

K-Means 모델 생성 및 학습

from sklearn.cluster import KMeans

# 모델 초기화(생성)
model = KMeans(
    n_clusters=3,        # cluster 개수(k 수) 설정
    algorithm='lloyd',    # 기본값이기도 함
    n_init=10,           # 초기 중심점을 무작위로 선택하는 횟수 -> 그 중 가장 좋은 결과를 선택
    random_state=2025
)

# 학습
model.fit(feature)

# 예측
pred = model.predict(feature)

주요 파라미터:

  • n_clusters: 군집의 개수 (k 값)
  • n_init: 초기 중심점을 무작위로 선택하는 횟수 (기본값: 10)
  • random_state: 재현 가능한 결과를 위한 시드 값
  • algorithm: 알고리즘 선택 ('lloyd' 또는 'elkan')

결과 확인

# 예측한 컬럼을 feature에 합치기
pred_df = pd.DataFrame(pred, columns=['predict'])
df = pd.concat([feature, pred_df], axis=1)

# 교차표: 두 열의 값들이 각각 몇 번 나타나는지 카운팅
ct = pd.crosstab(labels['labels'], df['predict'])
ct

교차표 해석:

  • 실제 레이블과 예측 레이블의 매칭 정도를 확인
  • 클러스터 번호는 다를 수 있지만, 군집 자체는 일치할 수 있음

Centroid 확인

# 클러스터 중심점 좌표
model.cluster_centers_

# DataFrame으로 변환
centers = pd.DataFrame(model.cluster_centers_, columns=feature.columns)
centers

시각화

import matplotlib.pyplot as plt

plt.scatter(
    df['sepal length (cm)'],  # x 축
    df['sepal width (cm)'],   # y 축
    c=df['predict'],          # 예측된 군집 레이블에 따라 색상 다르게
    alpha=0.5
)

# Centroid의 좌표
center_x = centers['sepal length (cm)']
center_y = centers['sepal width (cm)']

plt.scatter(
    center_x,
    center_y,
    marker='D',      # 다이아몬드 모양
    c='red',
    s=50
)
plt.show()

5️⃣ 비지도 학습 평가 지표

평가 지표의 한계

  • 군집화가 어느 정도 효율적으로 잘 되었는지를 평가할 수 있는 지표들이 별도로 존재
  • 지도학습과 비지도 학습의 평가 지표는 다름
  • Clustering의 경우 같은 클러스터에 같은 포인트가 들어가 있는지, 다른 Cluster 간에 다른 포인트가 들어 있는지가 중요
  • 비지도 학습 특성상, 어떠한 지표값이라도 정확하게 성능을 평가하기는 어려움

ARI (Adjusted Rand Index)

개념:

  • 실제 라벨(또는 다른 비지도 예측 레이블)이 필요함
  • Rand Index (RI): 가능한 모든 쌍의 경우에 대해 정답인 쌍의 개수를 비율로 계산
  • ARI: RI의 기댓값을 RI 값에서 빼서, 기댓값과 분산을 재조정 (-1 ~ 1)
    • 1에 가까울수록 완벽한 일치
    • 0에 가까울수록 무작위 할당
    • 음수는 무작위보다 나쁨

사용법:

from sklearn.metrics import adjusted_rand_score

# ARI 계산
ari_score = adjusted_rand_score(labels['labels'], model.labels_)
ari_score  # 약 0.6 정도

AMI (Adjusted Mutual Information)

개념:

  • ARI와 비슷한 지표 (두 clustering 결과 간의 유사성을 측정)
  • **MI (Mutual Information)**를 보정한 지표
  • ARI: 각 일치하는 쌍의 비율 → 클러스터 간 쌍을 비교해서 일치하는 비율
  • AMI: 두 clustering에서 겹치는 정보의 비율

사용법:

from sklearn.metrics import adjusted_mutual_info_score

# AMI 계산
ami_score = adjusted_mutual_info_score(labels['labels'], model.labels_)
ami_score  # 약 0.6 정도

ARI vs AMI:

  • 둘 다 0.6 정도 근사치로, 실제값과 어느 정도 일치하기는 하나 완벽하지는 않음
  • 대부분의 군집화 데이터셋은 ARI나 AMI처럼 비교할만한 실제 레이블을 가지고 있지 않음
  • 실제 레이블 값이 있으면, 지도학습 모델을 만들기에 비지도 학습 모델에 적합하다고는 볼 수 없음
  • ARI나 AMI의 경우에는 성능 평가보다는, 알고리즘을 개발하거나 특정 프로세스에서 사용됨

Silhouette Analysis (실루엣 분석)

실루엣 계수란?

  • 클러스터링이 잘 되었는지 확인할 수 있는 지표 (-1 ~ 1)
  • 1에 가까움: 잘 분리되어 있음
  • 0에 가까움: 클러스터의 경계에 위치
  • -1에 가까움: 이 데이터 포인트는 잘못 군집화되어 있음

계산 방법:

  • 각 데이터 포인트에 대해:
    • a: 같은 클러스터 내 다른 포인트들과의 평균 거리
    • b: 가장 가까운 다른 클러스터의 포인트들과의 평균 거리
    • 실루엣 계수 = (b - a) / max(a, b)

사용법:

from sklearn.metrics import silhouette_score, silhouette_samples

# 평균 실루엣 확인
silhouette_score(feature, pred)

# 각 데이터 포인트의 실루엣 계수
silhouette_vals = silhouette_samples(feature, pred)

# 각 클러스터별 실루엣 계수의 평균값
df_sill = pd.concat([df, pd.DataFrame(silhouette_vals, columns=['silhouette_coeff'])], axis=1)
df_sill.groupby('predict')['silhouette_coeff'].mean()

해석:

  • 어떠한 레이블 상관없이, 실루엣 계수가 낮으면 군집화가 잘 되지 않았음을 의미
  • 실루엣 계수가 높을수록 군집 간 분리가 잘 되어 있음

6️⃣ 최적의 클러스터 수 결정 - 엘보우 기법 (Elbow Method)

엘보우 기법이란?

  • 최적의 클러스터 개수를 결정하는 방법
  • SSE (Sum of Squared Errors): 클러스터 내 데이터 포인트들이 클러스터 중심으로부터 얼마나 떨어져 있는지를 나타내는 값
  • 군집화 이후에, 각 중심점에서 데이터 포인트 간의 거리의 제곱을 합산한 값

SSE 계산

# SSE 값 확인
model.inertia_  # inertia_ 속성이 SSE 값을 반환

엘보우 그래프 그리기

# 군집 개수 범위 설정
ks = range(1, 10)  # 군집 개수 k (1~9)
inertias = []      # SSE를 담아줄 리스트

for k in ks:
    model = KMeans(
        n_clusters=k,
        n_init=10,
        random_state=2025
    )
    model.fit(feature)
    inertias.append(model.inertia_)

# 엘보우 그래프
plt.figure(figsize=(10, 5))
plt.plot(ks, inertias, marker='o')
plt.xlabel('Number of clusters, k')
plt.ylabel('inertias, SSE')
plt.show()

엘보우 기법 해석

  • 클러스터의 수가 3일 때, 그래프의 기울기가 크게 완만해짐을 관측
  • k=3일 때, 급격한 감소가 멈추고, 그 이후부터는 더 많은 클러스터를 추가하더라도 SSE가 크게 감소하지 않음
  • 3이 가장 합리적인 군집 개수라고 볼 수 있음
  • 엘보우 기법에서 가장 큰 값이 나오는 지점이 최적의 군집 개수

주의사항:

  • 엘보우 기법은 명확한 "팔꿈치"가 보이지 않을 수도 있음
  • 이 경우 다른 방법(실루엣 분석 등)과 함께 고려해야 함

배운 것

  • **군집화(Clustering)**의 목적과 활용 사례
  • K-Means 알고리즘의 동작 원리와 과정
  • **Centroid(군집 중심점)**의 개념과 업데이트 방법
  • 비지도 학습 평가 지표: ARI, AMI, Silhouette Score
  • 엘보우 기법을 통한 최적 클러스터 수 결정
  • **SSE (Sum of Squared Errors)**의 개념과 활용

인사이트

  • 비지도 학습은 정답 레이블이 없어도 데이터의 숨겨진 패턴을 발견할 수 있음
  • K-Means는 간단하지만 차원이 많아질수록 성능이 떨어짐
  • 최적의 클러스터 수는 데이터에 따라 다르며, 엘보우 기법으로 찾을 수 있음
  • 비지도 학습의 평가는 지도 학습보다 어렵고, 여러 지표를 종합적으로 고려해야 함
  • 실제 레이블이 있는 데이터는 지도 학습에 더 적합함

주의사항

  • ⚠️ 차원의 저주: K-Means는 거리 기반이므로 차원이 많을수록 성능 저하
  • ⚠️ 초기값 의존성: 초기 중심점 선택에 따라 결과가 달라질 수 있음 → n_init으로 여러 번 시도
  • ⚠️ 클러스터 수 결정: 최적의 k 값을 미리 알 수 없음 → 엘보우 기법, 실루엣 분석 등 활용
  • ⚠️ 평가의 어려움: 비지도 학습은 정확한 성능 평가가 어려움 → 여러 지표를 종합적으로 고려
  • ✅ 실루엣 분석: 레이블이 없어도 군집화 품질을 평가할 수 있는 유용한 방법
  • ⚠️ 원형 군집 가정: K-Means는 원형(구형) 군집에만 잘 작동, 비선형 군집에는 부적합
  • ✅ 비교 목적의 레이블: 실습에서 정답 레이블을 사용했지만, 이는 비교 목적일 뿐 실제 비지도 학습에서는 사용하지 않음
