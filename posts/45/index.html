EST AI - 딥러닝 기초 (TensorFlow, Keras)

딥러닝이 무엇인지, 머신러닝과 어디서 갈리는지 설명하고 TensorFlow와 Keras로 신경망을 구성합니다. | 학생의 공부 시간으로 수학 성적을 예측하는 회귀 모델을 선형 회귀와 신경망 두 방식으로 만들어 비교합니다.

📚 오늘의 학습 내용

오늘은 딥러닝의 기본 개념을 학습하고, TensorFlow와 Keras를 활용하여 신경망 모델을 구성하는 방법을 실습했습니다. 학생의 공부시간(studytime)을 입력으로 받아 수학 성적(G3)을 예측하는 회귀 모델을 머신러닝과 딥러닝 방식으로 각각 구현하여 비교했습니다.

1️⃣ 딥러닝 개요

딥러닝이란?

  • 인간의 신경망을 모방하여, 학습 및 예측하고 판단하는 기술
  • 영상처리, 음성처리, 이미지 분야, 텍스트, 자연어 처리 등 다양한 분야에 활용
  • 인간의 뇌 구조를 수학적으로 모델링한 인공신경망을 깊게 쌓아 올린 구조

주요 도구

  • TensorFlow: 구글이 만든 딥러닝 프레임워크 (저수준 API 제공)
  • Keras: TensorFlow 위에서 동작하는 사용자 친화적 고수준 API
    • TensorFlow 2.x부터는 Keras가 내장되어 별도 설치 불필요
    • 직관적이고 간단한 API로 신경망 모델을 빠르게 구성 가능

딥러닝의 핵심 특징

  • 모델 구조를 직접 설계할 수 있어 유연성이 매우 높음
  • 단순한 다층 퍼셉트론(MLP)부터 복잡한 컨볼루션 신경망(CNN), 순환 신경망(RNN)까지 다양한 모델 설계 가능
  • 데이터로부터 계층적인 특징(feature)을 자동으로 학습하는 능력

2️⃣ 머신러닝 vs 딥러닝: 근본적인 차이

머신러닝 (Scikit-learn) - 완성품 활용

  • 모델 생성 → 모델 학습 → 모델 예측 → 모델 평가
  • 이미 구현된 알고리즘 클래스를 선택하여 사용
  • 비유: 완제품 피규어를 색칠하는 느낌
    • 피규어의 기본 형태는 이미 정해져 있고, 색상(하이퍼 파라미터)만 조절
  • 특정 알고리즘을 선택하고 그 알고리즘의 하이퍼 파라미터를 조정하는 과정에 집중
  • 장점: 빠르고 간단하게 모델 구축 가능
  • 단점: 모델 구조의 유연성이 제한적

딥러닝 (TensorFlow, Keras) - 직접 설계

  • 모델 생성 (모델 구조 직접 구성) → 모델 학습 → 예측 → 평가
  • 신경망의 각 층(layer)을 직접 정의하고 조합하여 모델 설계
  • 비유: 레고 블록을 하나하나 쌓아 올려 구조물을 만드는 느낌
    • 어떤 블록을 몇 개 쌓을지, 어떻게 연결할지 모두 직접 결정
  • 모델 학습, 예측, 평가 과정은 머신러닝과 유사하지만, 모델 구조 설계의 자유도가 매우 높음
  • 장점: 문제에 맞는 맞춤형 모델 구조 설계 가능
  • 단점: 구조 설계에 대한 이해와 경험이 필요, 과대적합 위험

왜 딥러닝을 사용하는가?

  • 복잡한 비선형 관계를 학습할 수 있음
  • 특징 추출을 자동화 (전처리 단계에서 수동으로 특징을 만들 필요가 적음)
  • 대용량 데이터에서 강력한 성능 발휘
  • 이미지, 텍스트, 음성 등 비정형 데이터 처리에 특화

3️⃣ 신경망 구조의 핵심 요소

Sequential 모델

  • 역할: 층을 순차적으로 쌓아 올리는 구조를 만드는 뼈대
  • 특징: 입력 → 은닉층1 → 은닉층2 → ... → 출력층 형태로 단방향 흐름
  • 사용 시점: 대부분의 기본적인 신경망 모델에 적합

Dense (완전연결층)

  • 역할: 모든 입력 뉴런이 모든 출력 뉴런과 연결되는 층
  • 특징:
    • units: 출력 뉴런의 개수 (층의 크기 결정)
    • activation: 활성화 함수 (비선형성 추가)
  • 왜 완전연결인가?: 입력의 모든 정보를 다음 층으로 전달하여 복잡한 패턴 학습 가능

InputLayer (입력층)

  • 역할: 모델의 입력 형태를 명시적으로 정의
  • 특징: input_shape 파라미터로 입력 데이터의 차원 지정
  • 왜 필요한가?: 모델이 첫 번째 데이터를 받을 때 입력 형태를 알 수 있도록 함

활성화 함수 (Activation Function)

  • sigmoid: 0~1 사이의 값을 출력 (이진 분류, 과거에 많이 사용)
  • relu: 음수는 0으로, 양수는 그대로 (현재 가장 많이 사용, 학습 속도 빠름)
  • 왜 필요한가?: 선형 변환만으로는 복잡한 비선형 관계를 학습할 수 없음

4️⃣ 실습: 학생 성적 예측 모델

데이터 개요

  • 입력 특성: studytime (주간 공부 시간, 1~4 범위)
  • 정답 레이블: G3 (최종 수학 성적, 0~20 범위)
  • 데이터 크기: 395명, train: 276명, test: 119명

머신러닝 방식 (Linear Regression)

  • 결과: MSE = 21.78
  • 특징: 단순한 선형 관계만 학습 가능
  • 한계: 공부시간과 성적의 복잡한 비선형 관계를 포착하기 어려움

딥러닝 방식 (신경망)

  • 구조: 입력층(1) → 은닉층1(32) → 은닉층2(64) → 은닉층3(32) → 출력층(1)
  • 설계 의도:
    • 은닉층을 여러 개 쌓아 복잡한 패턴 학습
    • 중간에 64개 뉴런으로 확장했다가 다시 32개로 축소 (정보 압축 및 추상화)
  • 주의사항: 과대적합 위험 (데이터가 적은 경우)

신경망 구조 설계 시 고려사항

  1. 층의 개수: 너무 많으면 과대적합, 너무 적으면 학습 부족
  2. 뉴런의 개수: 입력 특성 수와 데이터 크기를 고려
  3. 활성화 함수: 문제 유형에 따라 선택 (회귀는 출력층에 활성화 함수 없음)
  4. 과대적합 방지: 드롭아웃, 정규화, 조기 종료 등 필요

💡 핵심 정리

배운 것

  • 딥러닝은 모델 구조를 직접 설계할 수 있어 유연성이 매우 높음
  • Sequential 모델을 통해 층을 순차적으로 쌓아 올리는 기본 구조
  • Dense, InputLayer를 활용한 신경망 구성 방법
  • 머신러닝과 딥러닝의 근본적인 차이 (완성품 활용 vs 직접 설계)

인사이트

  • 왜 딥러닝인가?: 복잡한 비선형 관계를 학습하고, 특징 추출을 자동화할 수 있음
  • 구조 설계의 중요성: 문제와 데이터에 맞는 신경망 구조 설계가 성능에 큰 영향
  • 과대적합 주의: 특히 데이터가 적을 때는 모델 구조를 단순하게 유지하는 것이 중요

주의사항

  • ⚠️ 입력 데이터는 2차원 배열 형태로 입력해야 함 (scikit-learn과 동일)
  • ⚠️ 신경망 구조 설계 시 과대적합에 주의 (데이터 크기 대비 모델이 너무 복잡하면 안 됨)
  • ⚠️ InputLayer의 input_shape는 키워드 인자로 전달해야 함 (input_shape=(1,) 형태)
