#

# 국적에 따른 평균 성과평가점수와 최대 연봉 확인

    df.groupby('컬럼').agg({'컬럼1': 'mean', '컬럼2': 'max'})

📋 상관계수 분석

상관계수를 이해하기 위해 먼저 기술통계의 기본 개념들을 알아보겠습니다.

📊 분산과 표준편차

1. 편차 (Deviation)

편차란? 각 데이터와 평균의 차이

  • 데이터: x1,x2,x3,⋯ ,xnx_1, x_2, x_3, \cdots, x_nx1​,x2​,x3​,⋯,xn​
  • 평균: m=x1+x2+⋯+xnnm = \frac{x_1 + x_2 + \cdots + x_n}{n}m=nx1​+x2​+⋯+xn​​
  • 편차: x1−m,x2−m,x3−m,⋯ ,xn−mx_1 - m, x_2 - m, x_3 - m, \cdots, x_n - mx1​−m,x2​−m,x3​−m,⋯,xn​−m

2. 편차의 합이 0이 되는 이유

편차들의 합을 구하면: (x1−m)+(x2−m)+(x3−m)+⋯+(xn−m)=0(x_1 - m) + (x_2 - m) + (x_3 - m) + \cdots + (x_n - m) = 0(x1​−m)+(x2​−m)+(x3​−m)+⋯+(xn​−m)=0

왜 0이 될까?

  • 양수 편차와 음수 편차가 서로 상쇄되기 때문
  • 평균보다 큰 값의 편차(양수)와 평균보다 작은 값의 편차(음수)가 합쳐져서 0이 됨

3. 분산 (Variance)

분산이 필요한 이유:

  • 편차들의 평균을 구하고 싶지만, 편차의 합이 0이 되어 평균을 구할 수 없음
  • 따라서 편차를 제곱하여 항상 양수로 만든 후 평균을 구함

분산의 정의:

  • 확률변수가 기댓값(평균)으로부터 얼마나 떨어진 곳에 분포하는지 가늠하는 숫자
  • 편차 제곱의 평균

분산 공식 (표본 분산): s2=(x1−m)2+(x2−m)2+⋯+(xn−m)2n−1=∑i=1n(xi−m)2n−1s^2 = \frac{(x_1 - m)^2 + (x_2 - m)^2 + \cdots + (x_n - m)^2}{n-1} = \frac{\sum_{i=1}^{n}(x_i - m)^2}{n-1}s2=n−1(x1​−m)2+(x2​−m)2+⋯+(xn​−m)2​=n−1∑i=1n​(xi​−m)2​

참고: 분모가 n−1n-1n−1인 이유는 표본 분산을 구할 때 자유도(degree of freedom)를 고려하기 때문입니다.

4. 표준편차 (Standard Deviation)

표준편차란? 분산의 제곱근

s=s2=∑i=1n(xi−m)2n−1s = \sqrt{s^2} = \sqrt{\frac{\sum_{i=1}^{n}(x_i - m)^2}{n-1}}s=s2​=n−1∑i=1n​(xi​−m)2​​

왜 표준편차를 사용할까?

  • 분산은 제곱 단위이므로 원래 데이터의 단위와 다름 (예: 연봉의 분산은 "원²")
  • 표준편차는 원래 데이터와 같은 단위를 가지므로 해석이 용이함 (예: 연봉의 표준편차는 "원")

📊 공분산과 상관계수

1. 공분산 (Covariance)

공분산이란?

  • 하나의 변수가 아닌, 두 개의 변수로 구한 분산 값
  • 예: 키와 몸무게가 있다면 그 두 개로 구한 분산값

공분산의 특징:

  • 두 변수가 함께 변하는 정도를 측정
  • 양수: 한 변수가 증가하면 다른 변수도 증가하는 경향
  • 음수: 한 변수가 증가하면 다른 변수는 감소하는 경향

2. 정규화 (Normalization)

정규화가 필요한 이유:

  • 일반적으로 공분산은 데이터의 스케일(단위)에 영향을 받음 → 비교하기가 힘듦
  • 예: 키(cm)와 몸무게(kg)의 공분산 200 vs 시력과 눈의 굴절률의 공분산 2
  • 단위가 다르면 공분산 값만으로는 비교하기 어려움

해결 방법:

  • 각 변수의 표준편차의 곱으로 나눔
  • 이를 통해 상관계수를 구함

3. 상관계수 (Correlation Coefficient)

상관계수란?

  • 공분산 값을 -1 ~ 1 사이의 값으로 정규화한 값
  • 단위에 영향받지 않아 비교하기 쉬움
  • 두 변수 사이의 관계를 수치화하는 방법
  • 선형 관계를 측정 (한 변수가 증가할 때 다른 변수가 증가/감소하는 경향)

상관계수 해석:

범위해석설명
0.0≤∥r∥<0.20.0 \leq \|r\| < 0.20.0≤∥r∥<0.2상관관계가 없다선형의 관계가 없다
0.2≤∥r∥<0.40.2 \leq \|r\| < 0.40.2≤∥r∥<0.4약한 상관관계가 있다약한 선형 관계
0.4≤∥r∥<0.60.4 \leq \|r\| < 0.60.4≤∥r∥<0.6보통의 상관관계가 있다중간 정도의 선형 관계
0.6≤∥r∥<0.80.6 \leq \|r\| < 0.80.6≤∥r∥<0.8강한 (높은) 상관관계가 있다강한 선형 관계
0.8≤∥r∥≤1.00.8 \leq \|r\| \leq 1.00.8≤∥r∥≤1.0매우 강한 (매우 높은) 상관관계가 있다매우 강한 선형 관계

상관계수의 부호:

  • 양수 (r>0r > 0r>0): 양의 상관관계
    • 한 변수가 증가하면 다른 변수도 증가하는 경향
    • 예: 연봉과 근속연수, 키와 몸무게
  • 음수 (r<0r < 0r<0): 음의 상관관계
    • 한 변수가 증가하면 다른 변수는 감소하는 경향
    • 예: 운동량과 체중, 공부시간과 게임시간

HR 데이터에서의 상관계수 분석

단일 상관계수 확인:

# 직원 성과평가점수와 연봉의 상관계수 확인
hr_info[['PERFORMANCE_SCORE', 'SALARY']].corr()

출력 결과:

                   PERFORMANCE_SCORE    SALARY
PERFORMANCE_SCORE           1.000000  0.609152
SALARY                      0.609152  1.000000

💡 상관계수 해석:

  • 표를 볼 때는 대각선으로 보면 됩니다
  • PERFORMANCE_SCORE와 SALARY의 상관계수는 약 0.609로 보통의 상관관계가 있습니다

다중 변수 상관계수 확인:

# 수치 데이터의 전체 상관계수 확인
hr_info[['PERFORMANCE_SCORE', 'SALARY', 'AGE', 'SERVICE_YEAR', 'TRAINING_HOURS']].corr()

상관관계 해석:

  • 상관관계를 볼 때에는 선형상 관계를 봅니다
  • 다른 게 증가할 때 같이 증가/감소하게 되면 선형상 관계가 있다고 볼 수 있습니다
  • 이번 케이스에서는 (AGE, SALARY), (SERVICE_YEAR, SALARY)가 강한 선형 관계를 보입니다

주의사항:

  • 상관계수는 선형 관계만 측정합니다
  • 비선형 관계나 인과관계를 의미하지는 않습니다
  • r=0r = 0r=0이어도 관계가 전혀 없다는 의미는 아닙니다 (비선형 관계일 수 있음)

인사이트

  • 다중 기준 분석: 여러 기준으로 그룹화하면 더 세밀한 인사이트 도출 가능
  • 상관관계 vs 인과관계: 상관계수가 높다고 해서 인과관계를 의미하지는 않음
  • 정규화의 필요성: 공분산은 단위에 영향받지만, 상관계수는 정규화되어 비교 가능
  • 표준편차의 장점: 분산과 달리 원래 데이터와 같은 단위를 가져 해석이 용이함
  • f-string 포맷팅: 출력 형식을 제어하여 가독성 향상
  • agg() 딕셔너리 형태: 컬럼별로 다른 집계 함수 적용 시 딕셔너리 형태 사용

주의사항

  • ⚠️ 상관계수 해석: 선형 관계만 측정하며, 인과관계를 의미하지는 않음
  • ⚠️ 상관관계 ≠ 인과관계: 상관계수가 높다고 해서 한 변수가 다른 변수의 원인은 아님
  • ⚠️ 비선형 관계: r=0r = 0r=0이어도 비선형 관계가 있을 수 있음
  • ⚠️ mean() 반환 타입: 항상 float64를 반환하므로 소수점이 길게 표시될 수 있음
  • ✅ f-string 포맷팅 권장: {값:,.2f} 형태로 가독성 향상
  • ✅ agg() 딕셔너리 형태: 컬럼별로 다른 집계 함수 적용 시 딕셔너리 형태 사용
