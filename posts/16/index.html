반복문에서 인덱스를 얻는 세 가지 방법 중 enumerate()가 권장되는 이유를 range(len())과 비교합니다. | 이중 for문과 zip() 함수 언패킹 조합까지 실습 예제로 확인합니다.

📚 오늘의 학습 내용

📋 반복문 심화 개념

예제:

score_list = [90, 45, 70, 60, 55]

# idx를 별도로 선언하고 증가시키는 방식 (비권장: 실제 인덱스가 아닌 별개 변수 사용)
idx = 0
for score in score_list:
    if score >= 60:
        print(f"{idx+1}번째 학생은 {score}점으로 합격입니다.")
    else:
        print(f"{idx+1}번째 학생은 {score}점으로 불합격입니다.")
    idx += 1

💡 궁금해서 찾아본 내용: enumerate()와 range(len())

방법 2: range(len()) 방식

for i in range(len(score_list)):
    if score_list[i] >= 60:
        print(f"{i+1}번째 학생은 {score_list[i]}점으로 합격입니다.")
    else:
        print(f"{i+1}번째 학생은 {score_list[i]}점으로 불합격입니다.")

방법 3: enumerate() 방식 (권장)

enumerate() 함수 기본 문법:

for 인덱스, 값 in enumerate(iterable):
    실행문장

예제:

for i, score in enumerate(score_list):
    if score >= 60:
        print(f"{i+1}번째 학생은 {score}점으로 합격입니다.")
    else:
        print(f"{i+1}번째 학생은 {score}점으로 불합격입니다.")

range(len()) vs enumerate() 비교:

방법장점단점
range(len())인덱스로 직접 접근 가능list[i]를 두 번 접근해야 함 (비효율적)
enumerate()인덱스와 값을 동시에 받아서 효율적-

특징:

  • 인덱스와 값을 동시에 받아서 효율적으로 처리
  • range(len()) 방식보다 더 파이썬스러운 방법
  • 실제 인덱스를 사용하므로 실수 가능성 낮음

강사 방식의 문제점:

  • idx = 0로 별개 변수 선언 → 실제 인덱스가 아닌 별개 변수를 사용 (실수 위험)
  • idx += 1로 수동 증가 → 비효율적
  • 인덱스와 실제 리스트 요소가 분리되어 있음 → 유지보수 어려움

튜플 언패킹을 이용한 반복문

기본 문법:

for 변수1, 변수2 in 이차원리스트:
    실행문장

예제:

list2 = [[1,2], [3,4], [5,6]]

for i, j in list2:
    print(i, j)  # 1 2, 3 4, 5 6 출력

# j만 사용하고 싶을 때
for i, j in list2:
    print(j)  # 2, 4, 6 출력 (i는 할당되지만 사용 안 함)

# i를 명시적으로 무시
for _, j in list2:
    print(j)  # 동일한 결과

💡 궁금해서 찾아본 내용: 튜플 언패킹의 동작 원리

특징:

  • Python은 for문에서 변수가 2개 이상(쉼표로 구분)이면 자동으로 언패킹을 시도
  • 변수명은 의미가 없고, 위치(첫 번째, 두 번째)가 중요
  • 각 리스트 요소가 자동으로 변수에 할당됨

동작 원리:

  • 첫 번째 반복: i, j = [1, 2] → i=1, j=2
  • 두 번째 반복: i, j = [3, 4] → i=3, j=4
  • 세 번째 반복: i, j = [5, 6] → i=5, j=6

print() 함수의 end 파라미터

기본 사용법:

print(값, end='구분자')

특징:

  • 기본값: end='\n' (줄바꿈)
  • end=' '로 설정하면 공백으로 구분하여 출력
  • end=''로 설정하면 구분자 없이 연속 출력

📋 이중 for문 (Nested Loop)

기본 개념: 반복문 안에 또 다른 반복문을 사용하는 구조입니다. 외부 반복문이 한 번 실행될 때마다 내부 반복문이 완전히 실행됩니다.

예제 1: 구구단

for i in range(2, 10):      # 외부 반복문: 단 (2~9)
    for j in range(1, 10):  # 내부 반복문: 곱하는 수 (1~9)
        print(f'{i} x {j} = {i*j}')
    print()  # 각 단이 끝날 때마다 빈 줄 출력

예제 2: 별찍기 패턴 (이중 for문 활용)

단순 별찍기:

# 이중 for문 방식
for i in range(1, 6):
    for j in range(i):
        print('*', end='')
    print()
# 출력: *, **, ***, ****, *****

# Python의 문자열 곱셈 활용 (더 간결)
for i in range(1, 6):
    print('*' * i)

피라미드 형태 (오른쪽 정렬):

row = 10

# 이중 for문 방식
for i in range(1, row+1):
    for j in range(row-i):      # 공백 출력
        print(' ', end='')
    for j in range(i):          # 별 출력
        print('*', end='')
    print()

# Python의 문자열 곱셈 활용 (더 간결)
for i in range(1, row+1):
    print(' ' * (row-i) + '*' * i)

역삼각형 피라미드:

row = 10

# 이중 for문 방식
for i in range(1, row+1):
    for j in range(row-i):
        print(' ', end='')
    for j in range(i*2-1):
        print('*', end='')
    print()

# Python의 문자열 곱셈 활용 (더 간결)
for i in range(1, row+1):
    print(' ' * (row-i) + '*' * (i*2-1))

동작 원리:

  • 외부 반복문이 한 번 실행될 때마다 내부 반복문이 완전히 실행됨
  • 예: 외부 i=2 → 내부 j=1~9 모두 실행 → 외부 i=3 → 내부 j=1~9 모두 실행 → ...

Java/Kotlin과의 차이:

  • Java/Kotlin: 이중 for문으로 공백과 별을 각각 출력해야 함
  • Python: 문자열 곱셈('*' * i)으로 이중 for문 없이도 패턴 생성 가능 (더 간결)

📋 zip() 함수와 언패킹 조합

기본 문법:

for 변수1, 변수2 in zip(리스트1, 리스트2):
    실행문장

특징:

  • 두 개 이상의 리스트를 동시에 순회할 때 사용
  • 인덱스 없이 깔끔하게 처리 가능
  • zip()은 튜플들의 이터레이터를 반환하고, for문에서 자동 언패킹됨

예제:

names = ['민수', '지영', '현우', '수진']
genders = ['남', '여', '남', '여']

# zip과 언패킹을 함께 사용
for name, gender in zip(names, genders):
    print(f'{name}은 {gender}입니다.')

# zip 객체 확인
print(list(zip(names, genders)))
# 출력: [('민수', '남'), ('지영', '여'), ('현우', '남'), ('수진', '여')]

동작 원리:

  • zip(names, genders)는 ('민수', '남'), ('지영', '여'), ... 튜플들을 생성
  • for name, gender in zip(...)에서 각 튜플이 자동으로 언패킹됨
  • 인덱스 관리가 필요 없어 코드가 간결해짐

🔧 실습 예제

  • 최대값/최소값 찾기 (첫 번째 요소를 초기값으로 설정하고 반복문으로 비교)
  • 3의 배수 합 구하기 (range(1,101)와 % 연산자 활용)
  • Up/Down 게임 (while True와 break를 활용한 반복문 제어, 기회 제한)
  • 구구단 출력 (이중 for문 활용)
  • 별찍기 패턴 (단순, 피라미드, 역삼각형, 2중 for문 이용)
  • 길이가 다른 두 리스트 합치기 (len(), if, range() 활용)

💡 핵심 정리

📖 주요 학습 내용

  • enumerate(): 인덱스와 값을 동시에 받아 range(len())보다 효율적
  • 튜플 언패킹: 이차원 리스트를 간결하게 순회
  • 이중 for문: 외부 반복문이 한 번 실행될 때마다 내부 반복문 완전 실행
  • Python 문자열 곱셈: '*' * i로 이중 for문 없이 패턴 생성 가능
  • zip(): 여러 리스트를 인덱스 없이 동시에 순회

⚠️ 주의사항

  • 튜플 언패킹: 변수 개수와 리스트 요소 개수가 일치해야 함
  • zip(): 가장 짧은 리스트의 길이만큼만 순회함
