1️⃣ 문장 임베딩(Sentence Embedding) 심화

임베딩이란?

개념:

  • 텍스트(문장, 단어)를 고차원 수치 벡터로 변환하는 과정
  • 의미적으로 유사한 텍스트들이 벡터 공간에서 가까이 위치
  • 문장 간 비교, 클러스터링, 유사도 검색 등에 활용

왜 필요한가?

컴퓨터는 텍스트를 직접 이해할 수 없음
→ 수치로 변환 필요
→ 단, 단순 변환이 아니라 "의미"를 보존해야 함

예시:
"나는 밥을 먹었다" → [0.1, 0.2, 0.3, ..., 0.768]
"나는 식사를 했다"   → [0.12, 0.19, 0.31, ..., 0.765]
→ 두 벡터 간 거리가 가까움 (의미가 비슷하므로)

"나는 공부를 했다"   → [0.8, 0.3, 0.1, ..., 0.123]
→ 위 두 벡터와 거리가 멈 (의미가 다르므로)

Sentence-BERT (SBERT)

일반 BERT vs SBERT

일반 BERT의 문제점:

입력: "나는 밥을 먹었다"
토큰화: [나는] [밥을] [먹었다]

BERT 출력:
[나는]   → 벡터 1 (768차원)
[밥을]   → 벡터 2 (768차원)
[먹었다] → 벡터 3 (768차원)

문제:
- 토큰별로 벡터가 생성됨
- "문장 하나"를 대표하는 벡터가 없음
- 문장 간 유사도 계산이 어려움

SBERT의 해결책: Average Pooling

1. BERT로 각 토큰 벡터 생성
   [나는]   → [0.1, 0.2, 0.3, ...]
   [밥을]   → [0.4, 0.5, 0.6, ...]
   [먹었다] → [0.7, 0.8, 0.9, ...]

2. Average Pooling (평균 계산)
   각 차원별로 평균:
   1차원: (0.1 + 0.4 + 0.7) / 3 = 0.4
   2차원: (0.2 + 0.5 + 0.8) / 3 = 0.5
   3차원: (0.3 + 0.6 + 0.9) / 3 = 0.6
   ...

3. 결과: 문장 하나 = 벡터 하나 (768차원)
   "나는 밥을 먹었다" → [0.4, 0.5, 0.6, ...]

핵심:

  • 문장 전체 토큰의 정보를 균등하게 반영
  • 하나의 문장 → 하나의 벡터
  • 문장 간 유사도 계산 가능 (코사인 유사도, 유클리드 거리 등)

한국어 특화 KR-SBERT

모델 정보:

  • Hugging Face: snunlp/KR-SBERT-V40K-klueNLI-augSTS
  • 서울대 자연어처리 연구실에서 개발
  • 한국어 문장 임베딩에 최적화

사전 학습 (Pre-training):

Base Model: KR-BERT-V40K
Tokenizer: WordPiece (한국어 특화)
Pooling: Average Pooling
Output: 768차원 밀집 벡터

파인튜닝 (Fine-tuning):

데이터셋:
1. KLUE-NLI (한국어 자연어 추론)
   - 두 문장의 관계 판단: 함의/모순/중립
   
2. KorSTS (한국어 의미 유사도)
   - 두 문장의 유사도 점수 (0~5점)
   
3. In-domain 증강
   - 한국어 문체 다양화 (구어/문어/신조어 등)

학습 방법: Siamese Network (다음 섹션 참조)

2️⃣ Siamese 네트워크 (Siamese Network)

개념

Siamese (샴: 쌍둥이) 네트워크:

  • 두 개의 입력을 **동일한 네트워크(가중치 공유)**에 통과시켜 임베딩 생성
  • 두 임베딩 간 거리를 학습하여 "비슷한 것은 가깝게, 다른 것은 멀게" 배치
  • 이미지 인식, 얼굴 인증, 문장 유사도 학습 등에 활용

구조

┌─────────────┐                    ┌─────────────┐
│  Input 1    │                    │  Input 2    │
│ "밥 먹었다"  │                    │ "식사 했다"  │
└──────┬──────┘                    └──────┬──────┘
       │                                  │
       │         (가중치 공유)              │
       ▼                                  ▼
┌─────────────────────────────────────────────────┐
│         Siamese Subnetwork (BERT)               │
│                (동일한 모델)                      │
└──────┬──────────────────────────────────┬───────┘
       │                                  │
       ▼                                  ▼
┌─────────────┐                    ┌─────────────┐
│ Embedding 1 │                    │ Embedding 2 │
│ [0.1, 0.2,  │                    │ [0.11, 0.19,│
│  ..., 0.7]  │                    │  ..., 0.69] │
└──────┬──────┘                    └──────┬──────┘
       │                                  │
       └──────────────┬───────────────────┘
                      │
                      ▼
              ┌──────────────┐
              │   Distance   │
              │  (거리 계산)  │
              └──────┬───────┘

작동 원리

1단계: 두 입력을 동일한 모델에 통과

문장 A: "나는 밥을 먹었다"
문장 B: "나는 식사를 했다"

# 같은 BERT 모델 사용 (가중치 공유)
임베딩 A = SBERT(문장 A)  # [0.1, 0.2, ..., 0.7]
임베딩 B = SBERT(문장 B)  # [0.11, 0.19, ..., 0.69]

2단계: 거리 계산

# 유클리드 거리
Distance = ||임베딩 A - 임베딩 B||
         = √((0.1-0.11)² + (0.2-0.19)² + ... + (0.7-0.69)²)
         = 0.08  # 거리가 작음 → 비슷한 문장

# 코사인 유사도
Similarity = cos(임베딩 A, 임베딩 B)
           = (임베딩 A · 임베딩 B) / (||임베딩 A|| * ||임베딩 B||)
           = 0.95  # 1에 가까움 → 비슷한 문장

3단계: 분류 또는 회귀

# 이진 분류 (같은 클래스인가?)
Probability = sigmoid(Distance)
            = 1 / (1 + e^(-Distance))
            = 0.92  # 92% 확률로 "같음"

# 또는 유사도 점수 회귀 (0~5점)
Score = MLP(Distance)
      = 4.2 / 5.0

학습 목표

비슷한 문장 쌍:
문장 A: "나는 밥을 먹었다"
문장 B: "나는 식사를 했다"
→ 거리: 작게 (예: 0.1)
→ Loss: 거리를 0에 가깝게 만들도록 학습

다른 문장 쌍:
문장 A: "나는 밥을 먹었다"
문장 B: "나는 공부를 했다"
→ 거리: 크게 (예: 2.5)
→ Loss: 거리를 크게 만들도록 학습

결과:
- 비슷한 문장들은 벡터 공간에서 뭉침
- 다른 문장들은 벡터 공간에서 멀어짐

시각화 예시

학습 전:
                       ●(밥 먹었다)
    ●(식사 했다)
                            ●(공부 했다)
            ●(운동 했다)
(무작위 배치)

학습 후:
    ●(밥 먹었다)  ●(식사 했다)
    (음식 클러스터)
    
    
                    ●(공부 했다)  ●(시험 봤다)
                    (학업 클러스터)
    
    
    ●(운동 했다)  ●(달리기 했다)
    (활동 클러스터)

핵심 포인트

  1. 가중치 공유 (Weight Sharing)

    • 두 입력에 같은 모델 적용
    • 모델 파라미터가 2배로 늘지 않음
    • 일관된 임베딩 공간 형성

  2. 대조 학습 (Contrastive Learning)

    • Positive Pair (비슷한 쌍): 거리 ↓
    • Negative Pair (다른 쌍): 거리 ↑
    • 상대적 관계를 학습

  3. 의미 공간 형성

    • 학습 후 임베딩 공간이 의미론적으로 구조화됨
    • 같은 의미 → 가까이
    • 다른 의미 → 멀리

3️⃣ BERTopic 토픽 모델링 심화

BERTopic이란?

정의:

  • BERT 기반 임베딩 + 밀도 기반 군집화를 결합한 토픽 모델링 기법
  • 전통적 LDA와 달리 문서의 의미적 유사성을 반영

LDA vs BERTopic:

구분LDABERTopic
임베딩Bag of Words (단어 빈도)BERT 임베딩 (의미 벡터)
클러스터링확률 분포 기반HDBSCAN (밀도 기반)
주제 표현단어 분포c-TF-IDF 키워드
토픽 수수동 지정 필요자동 결정
의미 파악단어 동시 출현문맥 이해

BERTopic 파이프라인

[문서 입력]
    ↓
1️⃣ 문서 임베딩 (Embed Documents)
   BERT/SBERT로 768차원 벡터 변환
    ↓
2️⃣ 차원 축소 (UMAP)
   768차원 → 5차원 (계산 효율 ↑, 시각화 가능)
    ↓
3️⃣ 밀도 기반 군집화 (HDBSCAN)
   유사 문서끼리 자동 클러스터링
   노이즈(outlier) 자동 제거
    ↓
4️⃣ 토픽 키워드 생성 (c-TF-IDF)
   각 클러스터의 대표 키워드 추출
    ↓
5️⃣ 결과 정제 (MMR, 선택적)
   중복 키워드 제거, 다양성 확보
    ↓
[토픽 결과]

1️⃣ 문서 임베딩 (Embed Documents)

과정:

from sentence_transformers import SentenceTransformer

# 모델 로드
embedding_model = SentenceTransformer('snunlp/KR-SBERT-V40K-klueNLI-augSTS')

# 문서들을 벡터로 변환
documents = [
    "나는 밥을 먹었다",
    "나는 식사를 했다",
    "나는 공부를 했다"
]

embeddings = embedding_model.encode(documents)
# shape: (3, 768)

결과:

문서 1: "나는 밥을 먹었다"   → [0.1, 0.2, ..., 0.7]
문서 2: "나는 식사를 했다"   → [0.11, 0.19, ..., 0.69]
문서 3: "나는 공부를 했다"   → [0.8, 0.3, ..., 0.1]

문서 1 ↔ 문서 2 거리: 0.05 (가까움)
문서 1 ↔ 문서 3 거리: 2.3 (멈)

2️⃣ 차원 축소 (UMAP)

UMAP이란?

Uniform Manifold Approximation and Projection:

  • 고차원 데이터를 저차원으로 축소하는 알고리즘
  • t-SNE보다 빠르고, 전역 구조(global structure) 보존이 우수

왜 필요한가?

문제:
768차원 벡터로 클러스터링하면:
- 계산량 많음
- "차원의 저주" (curse of dimensionality)
  → 고차원에서는 모든 점이 멀어 보임
- 시각화 불가능

해결:
768차원 → 5차원 (또는 2차원)으로 축소
- 계산 효율 ↑
- 의미적 거리 관계 유지
- 시각화 가능

UMAP 파라미터:

from umap import UMAP

umap_model = UMAP(
    n_neighbors=15,      # 지역 구조를 볼 이웃 개수
    n_components=5,      # 축소할 차원 수
    min_dist=0.0,        # 점 간 최소 거리 (0: 빽빽하게)
    metric='cosine'      # 거리 측정 방법
)

시각화:

768차원 공간 (상상 불가)
[0.1, 0.2, 0.3, ..., 0.768]

      ↓ UMAP

5차원 공간 (계산 가능)
[0.5, 1.2, -0.3, 0.8, -1.1]

      ↓ 2차원으로 추가 축소

2차원 공간 (시각화 가능)
     y
     ▲
   3 │    ●(공부)
   2 │
   1 │  ●(밥)  ●(식사)
   0 │
  -1 └────────────────► x
     0  1  2  3  4  5

3️⃣ 밀도 기반 군집화 (HDBSCAN)

HDBSCAN이란?

Hierarchical Density-Based Spatial Clustering of Applications with Noise:

  • 계층적 밀도 기반 클러스터링 알고리즘
  • 클러스터 개수를 자동으로 결정
  • 노이즈(outlier)를 자동으로 걸러냄

K-Means vs HDBSCAN:

K-Means:
- 클러스터 개수(K)를 미리 지정해야 함
- 모든 점을 클러스터에 할당
- 구형(spherical) 클러스터만 잘 찾음

HDBSCAN:
- 클러스터 개수 자동 결정
- 노이즈 점은 클러스터에 미포함 (토픽 -1)
- 임의 형태의 클러스터 발견 가능

작동 원리:

1단계: 밀도 계산
   점들이 빽빽하게 모여있는 영역 찾기
   
2단계: 계층적 클러스터링
   밀도 높은 영역부터 점진적으로 병합
   
3단계: 클러스터 추출
   안정적인 클러스터만 선택
   
4단계: 노이즈 판단
   어떤 클러스터에도 속하지 않는 점 → 토픽 -1

시각화:

     y
     ▲
   3 │    ●      ● (노이즈)
   2 │  ●●●●
   1 │ ●●●●●●  ⟵ 클러스터 1
   0 │           ●●
  -1 │          ●●●●  ⟵ 클러스터 2
  -2 │           ●●
  -3 └────────────────► x
     0  1  2  3  4  5

결과:
- 클러스터 0: 5개 문서
- 클러스터 1: 4개 문서
- 토픽 -1 (노이즈): 1개 문서

파라미터:

from hdbscan import HDBSCAN

hdbscan_model = HDBSCAN(
    min_cluster_size=10,              # 최소 클러스터 크기
    metric='euclidean',               # 거리 측정 방법
    cluster_selection_method='eom'    # 클러스터 선택 전략
)

4️⃣ 토픽 키워드 생성 (c-TF-IDF)

c-TF-IDF란?

class-based TF-IDF:

  • 클러스터(토픽)별로 대표 키워드를 추출하는 방법
  • 일반 TF-IDF를 클러스터 단위로 확장

일반 TF-IDF vs c-TF-IDF:

일반 TF-IDF:
- 문서 단위로 중요 단어 추출
- TF: 해당 문서에서 단어 빈도
- IDF: 전체 문서에서 단어 희귀도

c-TF-IDF:
- 클러스터(토픽) 단위로 중요 단어 추출
- TF: 해당 클러스터 전체에서 단어 빈도
- IDF: 다른 클러스터에서 단어 희귀도

계산 과정:

1단계: 클러스터별 가상 문서 생성
   클러스터 0: [문서1, 문서2, 문서3] → "밥 먹었다 식사 했다 배불러"
   클러스터 1: [문서4, 문서5] → "공부 했다 시험 봤다"

2단계: 단어 빈도 계산 (TF)
   클러스터 0:
   - 밥: 3회
   - 먹다: 2회
   - 식사: 2회
   
   클러스터 1:
   - 공부: 3회
   - 시험: 2회

3단계: 클러스터 간 희귀도 계산 (IDF)
   "밥"이 나타난 클러스터: 1개 (클러스터 0만)
   → IDF 높음 (희귀함)
   
   "했다"가 나타난 클러스터: 2개 (모든 클러스터)
   → IDF 낮음 (흔함)

4단계: c-TF-IDF 계산
   c-TF-IDF("밥", 클러스터 0) = TF("밥") * IDF("밥")
                               = 3 * log(2/1)
                               = 3 * 0.693
                               = 2.08

5단계: 상위 키워드 선택
   클러스터 0: [밥, 식사, 먹다, ...]
   클러스터 1: [공부, 시험, 책, ...]

예시:

# BERTopic 결과
topic_model.get_topic(0)
# [('밥', 2.08), ('식사', 1.95), ('먹다', 1.72), ...]

topic_model.get_topic(1)
# [('공부', 2.31), ('시험', 2.15), ('책', 1.88), ...]

5️⃣ 결과 정제 (MMR)

MMR이란?

Maximal Marginal Relevance:

  • 관련성(Relevance)과 다양성(Diversity)을 균형있게 선택
  • 비슷한 키워드 중복 제거

문제:

c-TF-IDF 결과:
[국어, 영어, 수학, 과학, 산수, 숫자, 계산, 덧셈, 뺄셈]

문제:
- 산수, 수학, 계산, 덧셈, 뺄셈 → 모두 비슷한 의미
- 중복이 많아 다양성 ↓

MMR 적용:

1단계: 첫 번째 키워드 선택
   가장 관련성 높은 키워드: "국어"

2단계: 다음 키워드 선택
   후보: [영어, 수학, 과학, 산수, ...]
   
   각 후보에 대해:
   Score = λ * Relevance - (1-λ) * MaxSimilarity
   
   "영어":
   - Relevance: 0.95 (관련성 높음)
   - MaxSimilarity: 0.3 (기존 키워드와 유사도)
   - Score = 0.7 * 0.95 - 0.3 * 0.3 = 0.575
   
   "수학":
   - Relevance: 0.90
   - MaxSimilarity: 0.2
   - Score = 0.7 * 0.90 - 0.3 * 0.2 = 0.57
   
   "산수":
   - Relevance: 0.85
   - MaxSimilarity: 0.85 ("수학"과 매우 유사)
   - Score = 0.7 * 0.85 - 0.3 * 0.85 = 0.34 (낮음!)
   
   → "영어" 선택 (Score 가장 높음)

3단계: 반복
   선택된 키워드: [국어, 영어]
   다음 후보 평가...

최종 결과:
[국어, 영어, 수학, 과학, 숫자]
→ 비슷한 단어(산수, 계산, 덧셈, 뺄셈) 제거됨

차이점:

📝 요약

핵심 개념

  1. Sentence-BERT (SBERT)

    • Average Pooling으로 문장 하나 = 벡터 하나
    • 한국어 특화: KR-SBERT (snunlp/KR-SBERT-V40K-klueNLI-augSTS)

  2. Siamese 네트워크

    • 두 입력을 동일한 모델(가중치 공유)에 통과
    • 대조 학습: 비슷한 것은 가깝게, 다른 것은 멀게
    • 문장 임베딩 학습에 효과적

  3. BERTopic 파이프라인

    • 1️⃣ 문서 임베딩 (SBERT, 768차원)
    • 2️⃣ 차원 축소 (UMAP, 768→5차원)
    • 3️⃣ 밀도 기반 군집화 (HDBSCAN, 자동 클러스터링)
    • 4️⃣ 토픽 키워드 생성 (c-TF-IDF, 클러스터별 대표 키워드)
    • 5️⃣ 결과 정제 (MMR, 중복 제거)

  4. BERTopic 특징

    • 클러스터 개수 자동 결정
    • 노이즈(Outlier, 토픽 -1) 자동 처리
    • 의미적 유사도 반영
    • 시각화 용이

실습 내용

  • KR-SBERT로 한국어 문장 임베딩
  • BERTopic으로 원문/요약문 토픽 모델링
  • 토픽 분포 비교 및 분석
  • macOS 한글 폰트 설정

주요 학습 포인트

1. Average Pooling

토큰별 벡터 → 평균 계산 → 문장 하나 = 벡터 하나

2. Siamese 네트워크 학습

비슷한 쌍 → 거리 ↓
다른 쌍 → 거리 ↑

3. HDBSCAN의 장점

- 클러스터 개수 자동
- 노이즈 자동 제거
- 임의 형태 클러스터 발견

4. c-TF-IDF

클러스터 단위 TF-IDF
→ 해당 클러스터를 대표하는 키워드 추출

도서관 비유로 이해하는 BERTopic

도서관에 1000권의 책이 있다고 가정:

1️⃣ 문서 임베딩:
   → 모든 책을 한국어로 번역 (읽을 수 있게)
   
2️⃣ 차원 축소 (UMAP):
   → 비슷한 책끼리 책상 위에 쌓음
   
3️⃣ 밀도 기반 군집화 (HDBSCAN):
   → 쌓인 책 묶음 → 클러스터 (주제)
   → 혼자 떨어진 책 → 노이즈 (토픽 -1)
   
4️⃣ 토픽 키워드 생성 (c-TF-IDF):
   → 각 묶음을 대표하는 키워드 추출
   → [국어, 문법, 작문] / [영어, 단어, 회화]
   
5️⃣ 결과 정제 (MMR):
   → 비슷한 단어 제거
   → [국어, 영어, 수학] (산수, 계산 제외)
