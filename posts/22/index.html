📋 Pandas Series

Series 클래스:

  • index + value 구조의 1차원 데이터
  • 인덱스에 이름 부여 가능
  • NumPy 배열과 유사하지만 라벨 기반 접근 가능

Series 생성 방법:

import pandas as pd

# 리스트로 생성
pop = pd.Series([9901232, 3441423, 2891323, 2462123])

# 인덱스 지정하여 생성
pop = pd.Series([9901232, 3441423, 2891323, 2462123], 
                index=['서울', '부산', '인천', '대구'])

# 딕셔너리로 생성
pop = pd.Series({'서울': 9901232, '부산': 3441423, '인천': 2891323, '대구': 2462123})

인덱스 설정 및 변경:

# 인덱스 설정
pop.index = ['서울', '부산', '인천', '대구']

# 인덱스 이름 변경 (반환값을 받아야 함)
pop_renamed = pop.rename({'서울': 'SEOUL', '부산': 'BUSAN'})
# 또는 inplace=True로 원본 변경
pop.rename({'서울': 'SEOUL'}, inplace=True)

Series 속성:

  • series.values: 값만 추출 (NumPy 배열)
  • series.index: 인덱스 정보
  • series.dtype: 데이터 타입
  • series.name: Series 이름
pop.name = '인구'  # Series에 이름 부여

📋 Series 인덱싱과 슬라이싱

인덱싱:

  • 이름으로 접근 가능
  • 여러 개 선택 시 리스트 형태로 전달
pop['부산']              # 단일 값
pop[['부산', '대구']]     # 여러 값 (리스트 형태)

슬라이싱:

  • 이름으로 슬라이싱 시 끝 값이 포함됨 (기존 Python과 다름)
  • 위치 기반 슬라이싱도 가능
pop['부산':'인천']  # 부산, 인천 포함 (끝 값 포함)
pop[1:3]           # 위치 기반 슬라이싱

주의사항:

  • 정수 인덱스로 접근 시 위치가 아닌 라벨로 인식됨 (deprecated)
  • 위치 기반 접근은 iloc 사용 권장

📋 Series Boolean Indexing

사용법:

  • 조건식으로 필터링 가능
  • NumPy와 동일한 방식
pop[pop > 5000000]  # 500만 이상인 값만 추출

💡 핵심 정리

📖 주요 포인트

  • Series: index + value 구조의 1차원 데이터
  • 인덱싱: 이름으로 접근 가능, 여러 개 선택 시 리스트 형태
  • 슬라이싱: 이름으로 슬라이싱 시 끝 값 포함 (Python과 다름)
  • rename(): 반환값을 받거나 inplace=True 사용
  • 속성: values, index, dtype, name으로 데이터 정보 확인

⚠️ 주의사항

  • Pandas rename()은 기본적으로 원본을 변경하지 않음 (반환값 필요)
  • Series 이름 슬라이싱 시 끝 값이 포함됨 (Python과 다름)
  • 정수 인덱스 접근 시 라벨로 인식될 수 있음 (deprecated)

✅ 권장 사항

  • Pandas Series는 라벨 기반 접근의 장점을 활용
  • 여러 값 선택 시 리스트 형태 사용
  • 위치 기반 접근이 필요하면 iloc 사용
  • rename() 사용 시 반환값을 받거나 inplace=True 옵션 활용
