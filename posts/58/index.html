EST AI - OpenCV : NumPy 리뷰 & 이미지 기초

이미지가 NumPy 배열로 표현된다는 점을 확인하고, OpenCV로 이미지를 읽어 화면에 표시합니다. | BGR과 RGB의 차이, 색상 공간 변환, OTSU 이진화, 히스토그램이 나옵니다.

2026년 3월 9일 오후 12:33

📚 오늘의 학습 내용

오늘은 NumPy 배열 복습과 OpenCV 이미지 처리 기초를 학습했습니다. 이미지가 NumPy 배열로 표현된다는 점을 이해하고, 색상 공간 변환·이진화·데이터 접근 방법을 익혔습니다.

1️⃣ NumPy와 이미지

NumPy 배열 특징

  • 자료 형태: 동질적 타입, 다차원 배열
  • 이미지: 2차원(흑백) 또는 3차원(컬러: height × width × channels) 배열
  • shape: (height, width) 또는 (height, width, 3) — 행·열 순서이며, 이미지에서는 (세로, 가로) 순서

데이터 접근

  • indexing / slicing: 위치(index) 기반 — arr[3], arr[2:5], arr[[3,5]]
  • boolean indexing: 조건이 True인 위치의 데이터만 추출 — tmp_data[bool_arr]

2️⃣ OpenCV 이미지 읽기·표시

imread 옵션

  • cv2.IMREAD_COLOR: 컬러 이미지 (기본값), 투명 영역 무시
  • cv2.IMREAD_GRAYSCALE: 흑백 이미지
  • cv2.IMREAD_UNCHANGED: 투명 영역까지 포함

BGR vs RGB

  • OpenCV: 채널 순서 BGR
  • Matplotlib: RGB
  • plt.imshow()로 컬러 이미지 표시 시 색이 반전되므로, cv2.cvtColor(img, cv2.COLOR_BGR2RGB)로 변환 후 표시
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
plt.imshow(img_rgb)
  • waitKey: cv2.waitKey(0) — 0이면 무한 대기, 어떤 키든 누르면 종료. 동영상에서는 ms 단위(예: 33)로 프레임 간격 제어.

3️⃣ 색상 공간 변환 & 이진화

이진화 (Binary 이미지)

  • 목적: 픽셀을 0 또는 지정값(예: 255) 두 가지로만 표현
  • 함수: cv2.threshold(img, threshold_value, value, flag)
    • img: 그레이스케일 이미지만 가능
    • threshold_value: 기준값
    • value: 임계값 초과 시 적용할 값
    • flag:
      • cv2.THRESH_BINARY: 초과 → value, 미만 → 0
      • cv2.THRESH_BINARY_INV: 초과 → 0, 미만 → value
      • cv2.THRESH_TRUNC: 초과 → 임계값으로, 그 외 유지
      • cv2.THRESH_TOZERO: 초과 시 유지, 미만 → 0
      • cv2.THRESH_TOZERO_INV: 초과 → 0, 미만 시 유지

OTSU 이진화

  • 임계값을 자동으로 정하는 방법. 히스토그램을 두 클래스(어두운/밝은 픽셀)로 나눌 때 클래스 간 분산을 최대화하는 t를 선택.
  • cv2.threshold(img, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU) — 첫 번째 인자(0)는 OTSU가 임계값을 계산하므로 사용하지 않음. 반환값으로 계산된 임계값을 받을 수 있음.
th_val, binary_otsu = cv2.threshold(img_gray, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)

히스토그램

  • plt.hist(img_1d) — 이미지를 1차원으로 펼친 뒤 픽셀 값 분포 확인. 이진화·OTSU 이해에 활용.

4️⃣ 영역 접근·실습 요약

  • 이미지 좌표: shape은 (height, width) → [행, 열] = [y, x]. 슬라이싱은 [y1:y2, x1:x2].
  • 중심 좌표: cx, cy = width // 2, height // 2
  • 실습: 사과 이미지 중앙 사각형 영역만 이진화, 자동차 번호판 영역 크롭 후 이진화·확대하여 OCR(Tesseract) 인식률 개선 등. 전부 그레이스케일 → 이진화 흐름과 영역 슬라이싱이 핵심.

💡 핵심 정리

배운 것

  • 이미지 = NumPy 배열; shape는 (height, width) 또는 (H, W, 3)
  • OpenCV는 BGR, Matplotlib은 RGB — 표시 전 변환 필요
  • 이진화: cv2.threshold + flag; OTSU로 자동 임계값 선택
  • indexing / slicing / boolean indexing으로 영역·조건별 픽셀 접근

주의사항

  • ⚠️ cv2.threshold는 그레이스케일 입력만 지원
  • ⚠️ 이미지 인덱스는 [행, 열] = [y, x] 순서
